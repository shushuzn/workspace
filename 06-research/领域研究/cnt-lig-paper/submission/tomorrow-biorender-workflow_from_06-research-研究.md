## 🆘 Troubleshooting

### Issue: Icons not found

**Solution:**
- Try alternative keywords
- Browse icon categories
- Use similar icons
- Contact support

### Issue: Canvas too slow

**Solution:**
- Reduce browser tabs
- Clear cache
- Restart browser
- Check internet connection

### Issue: Export fails

**Solution:**
- Check file size (<10 MB)
- Try different format
- Reduce canvas size
- Contact BioRender support
