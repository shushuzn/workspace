## 🔍 问题分析

### GP R² 低的原因

1. **数据质量问题**
   - 220 样本中 120 个是真实数据
   - 100 个是合成/增强数据
   - 可能存在分布不一致

2. **特征工程问题**
   - 特征之间可能存在共线性
   - P 和 E= P/v 高度相关

3. **核函数选择**
   - 可能需要更复杂的核函数
   - 需要更多优化迭代

### 下一步改进

1. **数据清洗**
   - 检查异常值
   - 验证合成数据合理性

2. **特征选择**
   - 移除共线性特征
   - 使用 PCA 降维

3. **模型优化**
   - 尝试不同核函数
   - 增加 n_restarts_optimizer

4. **迁移学习**
   - 使用预训练模型
   - 微调适配 LIG 数据
