## 🔍 关键发现

### 1. 数据质量问题

**异常值检测 (3σ原则):**
| 特征 | 异常值数 | 占比 |
|------|----------|------|
| P_W | 1 | 0.5% |
| E_Jcm2 | 7 | 3.2% |
| sigma_Sm | 4 | 1.8% |

**结论:** 少量异常值，影响有限

### 2. 共线性问题 ⚠️

**Pearson 相关系数矩阵:**
```
        P_W   v_mms  E_Jcm2  co_ratio
P_W     1.00  -0.15   0.74     0.21
v_mms  -0.15   1.00  -0.62    -0.24
E_Jcm2  0.74  -0.62   1.00     0.24
```

**高共线性特征对:**
- **P_W ↔ E_Jcm2: r = 0.74** ⚠️

**根本原因:**
```
E_Jcm2 = P_W / (v_mms * 0.01)
E_Jcm2 与 P_W 高度相关 (数学必然)
```

**建议:** 移除 E_Jcm2 特征

## 🎯 根本原因分析

### 为什么 220 样本反而更差？

**1. 数据分布不一致**
```
120 样本：真实数据 + 高质量合成
220 样本：加入了大量低质量增强数据
```

**2. 噪声累积**
```
原始数据：15% 噪声
增强数据：每次增强累积噪声
最终：噪声可能>30%
```

**3. 特征工程问题**
```
E_Jcm2 = P_W / v_mms
与 P_W 共线性 r=0.74
导致 GP 核函数失效
```
