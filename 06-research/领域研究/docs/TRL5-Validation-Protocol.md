## 🔬 实验设计

### 实验 1: 猪模型神经探针植入 (90 天)

#### 实验动物
| 参数 | 规格 |
|------|------|
| **物种** | 小型猪 (Yucatan minipig) |
| **数量** | 6 只 (3 雄 3 雌) |
| **年龄** | 6-8 个月 |
| **体重** | 25-35 kg |
| **饲养条件** | SPF 级设施，12h 光暗循环 |

#### 植入方案
| 参数 | 规格 |
|------|------|
| **植入位点** | 初级运动皮层 (M1) + 初级体感皮层 (S1) |
| **探针数量** | 每只 4 通道 × 2 位点 = 8 通道 |
| **对照组** | 商业探针 (Blackrock NeuroPort) |
| **植入方式** | 立体定位手术， dura 下植入 |

#### 数据采集
| 时间点 | 检测项目 |
|--------|----------|
| **术前** | 基线神经活动、血液学、生化 |
| **术后 1 天** | 急性反应、阻抗测试 |
| **术后 7 天** | 组织学 (n=2 安乐死) |
| **术后 30 天** | 神经信号记录、阻抗测试 |
| **术后 60 天** | 神经信号记录、阻抗测试、MRI |
| **术后 90 天** | 终末检测 (组织学 + 免疫组化) |
