## 📈 材料体系演进对比

### 性能演进路径

| 体系 | 电导率 (S/m) | 协同效应 | 相对提升 |
|------|--------------|----------|----------|
| **单一 CNT** | 6.99×10⁵ | - | 基线 |
| **二元 (CNT-LIG)** | 4.35×10⁵ | +29% | 柔性提升 |
| **三元 (CNT-LIG-G)** | 5.86×10⁵ | +67% | 石墨烯桥接 |
| **四元 (CNT-LIG-G-MXene)** | 8.61×10⁵ | +140% | MXene 赝电容 |

### 关键洞察

**演进规律:**
1. **单一→二元:** 柔性提升，但电导率略降 (LIG 稀释)
2. **二元→三元:** 石墨烯桥接，+34.8%
3. **三元→四元:** MXene 赝电容效应，+47%

**四元优势:**
- MXene 表面官能团 (-O, -OH, -F) 提供赝电容
- 2D MXene 与 2D 石墨烯形成异质结
- 1D CNT 连接 2D 材料，形成三维网络
- LIG 填充空隙，提供机械柔性

## 🔬 四元协同机制

### 1. 多尺度导电网络

```
宏观 (LIG 3D) ←→ 介观 (MXene/石墨烯 2D) ←→ 微观 (CNT 1D)
```

**优势:**
- LIG: 连续三维网络 (宏观连通)
- MXene/石墨烯：二维面内高导 (介观传输)
- CNT: 一维弹道输运 (微观快速通道)

### 2. 界面工程

**四相界面:**
```
CNT ──┬── π-π 堆叠 ── 石墨烯
      ├── 范德华力 ── MXene
      └── 机械互锁 ── LIG
```

**MXene 独特作用:**
- 表面官能团 (-O/-OH/-F) 与 CNT 共价结合
- 与石墨烯形成 2D-2D 异质结
- 赝电容贡献额外电荷存储

### 3. 电荷传输机制

**四元传输路径:**
```
电子 → CNT(弹道) → 石墨烯 (面扩散) → MXene(赝电容) → LIG(基体)
```

**协同增强:**
- CNT 提供快速长程通道
- 石墨烯提供面内扩散
- MXene 提供电荷存储/释放
- LIG 确保整体连通性
