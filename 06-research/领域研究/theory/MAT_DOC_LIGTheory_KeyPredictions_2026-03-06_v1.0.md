## 🎯 理论预测总结

### 预测 1: 功率密度标度律

**公式:**
$$\sigma \propto (P/(v d))^\alpha$$

**验证方法:**
1. 收集文献数据 (P, v, d, sigma)
2. 计算功率密度 X = P/(v*d)
3. 绘制 log(sigma) vs log(X)
4. 拟合斜率 = alpha

**预期:**
- alpha ≈ 1-2
- R² > 0.75
- 线性关系明显

---

### 预测 2: 速度依赖性

**高功率极限:**
$$\sigma \approx \sigma_0 \cdot [1 - \exp(-A d/v)]^t$$

**预测:**
- 低速 → 高电导率 (饱和)
- 高速 → 低电导率
- 存在特征速度 v_c = A*d

**验证:**
- 固定 P, d
- 改变 v
- 观察 sigma(v) 曲线

---

### 预测 3: 温度阈值

**石墨化起始温度:**
$$T_{graph} \approx 1000°C$$

**对应最小功率密度:**
$$(P/(v d))_{min} \approx \frac{k T_{graph}}{\alpha}$$

**预测:**
- 低于阈值 → sigma 急剧下降
- 高于阈值 → sigma 快速上升

**验证:**
- 查找文献中低温实验
- 确认阈值存在

---

### 预测 4: 光斑尺寸效应

**固定 P, v:**
$$\sigma \propto d^{-\alpha}$$

**预测:**
- 小光斑 → 高功率密度 → 高 sigma
- 大光斑 → 低功率密度 → 低 sigma

**验证:**
- 收集不同光斑尺寸数据
- 验证 sigma(d) 关系

2. 计算 X = P/(v*d)
3. 绘制 log-log 图
4. 线性拟合求 alpha

**预期结果:**
```
log(sigma) = alpha * log(P/(v*d)) + C

拟合优度: R² > 0.75
alpha 范围：1.0 - 2.0
```

---

### 方法 2: 全公式拟合

**步骤:**
1. 使用完整公式
2. 非线性最小二乘拟合
3. 拟合参数：A, B, t, sigma_0

**Python 代码:**
```python
from scipy.optimize import curve_fit

def conductivity_model(P, v, d, sigma_0, A, B, t):
    chi = 1 - np.exp(-(A*d/v) * np.exp(-B*d*v/P))
    return sigma_0 * chi**t

# 拟合
params, covariance = curve_fit(
    conductivity_model,
    (P_data, v_data, d_data),
    sigma_data
)
```
