## 📋 Project Organization Rules

### New Projects Go To:
1. **Active development** → `50-projects/[project-name]/`
2. **Web projects** → `51-web/[project-name]/`
3. **Experiments** → `92-tests/[project-name]/`

### Project Structure:
```
50-projects/[project-name]/
├── README.md           # Project overview
├── src/                # Source code
├── docs/               # Documentation
├── tests/              # Tests
├── package.json        # Dependencies
└── .env.example        # Config template
```

## 💡 Tips

1. **Use `50-projects/` for main projects** - Centralized location
2. **Keep `projects/` for templates only** - Don't mix
3. **Archive completed projects** - Move to `99-archive/` when done
4. **One README per project** - Clear overview
5. **Update this index** - When adding new projects
