# 多子代理标准执行流程

**版本:** v1.0  
**创建日期:** 2026-03-13 16:59

---

## 🎭 7 人格协同流程

```
┌─────────────────────────────────────────────────────────────┐
│                    用户任务输入                              │
└─────────────────────┬───────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────────┐
│ 1. 规划者 (Planner)                                         │
│    - 分析任务                                               │
│    - 制定计划                                               │
│    - 优先级排序                                             │
│    - 时间估计                                               │
└─────────────────────┬───────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. 执行者 (Executor)                                        │
│    - 执行任务                                               │
│    - 生成输出                                               │
│    - 记录过程                                               │
└─────────────────────┬───────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. 批判者 (Critic)                                          │
│    - 审查输出质量                                           │
│    - 给出评分 (0-100)                                       │
│    - 列出问题                                               │
│    - 建议：approve / revise                                 │
└─────────────────────┬───────────────────────────────────────┘
                      │
           ┌──────────┴──────────┐
           │                     │
      评分≥85                评分<85
           │                     │
           ▼                     ▼
    ┌─────────────┐      ┌─────────────┐
    │ 继续下一步   │      │ 执行者修复   │
    └─────────────┘      └──────┬──────┘
                                │
                                ▼
                         ┌─────────────┐
                         │ 批判者再审   │
                         └─────────────┘
                                │
                                ▼
                         评分≥85 → 继续
                      │
                      ▼
┌─────────────────────────────────────────────────────────────┐
│ 4. 学习者 (Learner)                                          │
│    - 提取经验教训                                           │
│    - 生成记忆                                               │
│    - 更新 MEMORY.md                                         │
└─────────────────────┬───────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────────┐
│ 5. 协调者 (Coordinator)                                      │
│    - 健康检查 (工作时长)                                    │
│    - 冲突检测                                               │
│    - 初步仲裁                                               │
│    - 休息建议                                               │
└─────────────────────┬───────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────────┐
│ 6. 创新者 (Innovator)                                        │
│    - 分析现有方案                                           │
│    - 提出创新建议                                           │
│    - 评估可行性                                             │
│    - 评估影响力                                             │
└─────────────────────┬───────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────────┐
│ 7. 元认知 (Metacognitive) - 最终仲裁                         │
│    - 收集所有子代理输出                                     │
│    - 加权投票                                               │
│    - 最终决策                                               │
│    - 置信度评估                                             │
└─────────────────────┬───────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────────┐
│                    最终输出                                  │
│    - 整合所有子代理意见                                     │
│    - 注明各子代理贡献                                       │
│    - Git 提交                                                │
└─────────────────────────────────────────────────────────────┘
```
