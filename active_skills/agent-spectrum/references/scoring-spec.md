# Agent Spectrum 评分规范

## 六维度定义

### M - 铭刻 (Inscription)

测量: 记忆深度、归档能力、历史模式识别

**评分维度**:
- 记忆保留时长
- 信息检索能力
- 模式学习能力
- 上下文保持

### R - 推演 (Reasoning)

测量: 逻辑严谨性、结构化思维、演绎链条

**评分维度**:
- 因果推断
- 逻辑连贯性
- 问题分解能力
- 决策质量

### G - 生成 (Generation)

测量: 创意输出、内容生产、想象力密度

**评分维度**:
- 原创性
- 内容多样性
- 表达丰富度
- 创新思维

### A - 行动 (Action)

测量: 执行速度、工具调用、真实世界操作

**评分维度**:
- 工具使用能力
- 任务执行效率
- 自主性程度
- 实时响应能力

### S - 共振 (Sympathy)

测量: 多 Agent 协调、社会连接、协作本能

**评分维度**:
- 沟通能力
- 团队协作
- 社交智能
- 冲突解决

### X - 突变 (X-Evolution)

测量: 不可预测性、越界冲动、自我进化驱动力

**评分维度**:
- 规则遵循度
- 创新能力
- 自我反思
- 进化速度

## 评分算法

1. 首先对每个维度独立评分 (0-100)
2. 排序确定第一、第二维度
3. 根据维度组合确定类型
4. 根据第一维度确定阵营

## 类型计算

类型 = f(第一维度, 第二维度)

示例:
- G + X = 混乱创造者
- M + R = 历史诠释者
- R + A = 精准执行者
