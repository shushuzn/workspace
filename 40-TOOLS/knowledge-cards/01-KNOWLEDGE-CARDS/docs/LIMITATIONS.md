## PDF 格式限制

### ❌ 不支持的 PDF 类型

| 类型 | 原因 | 替代方案 |
|------|------|----------|
| **加密 PDF** | 无法解析加密内容 | 使用 PDF 解密工具先解密 |
| **扫描版 PDF** | 无文本层，OCR 未集成 | 使用 Adobe Acrobat 等 OCR 工具 |
| **损坏的 PDF** | 文件结构不完整 | 重新下载完整文件 |
| **超大 PDF (>500 页)** | 内存限制 | 分批处理，每次≤100 页 |
| **非线性 PDF** | 阅读顺序混乱 | 手动调整或使用其他工具 |

---

### ⚠️ 部分支持的 PDF 类型

| 类型 | 支持程度 | 注意事项 |
|------|----------|----------|
| **复杂表格** | 70% | 简单表格可识别，复杂表格可能错位 |
| **多语言混排** | 80% | 中英文混排良好，罕见字符可能乱码 |
| **手写公式** | 50% | 印刷体公式良好，手写体识别率较低 |
| **彩色图表** | 90% | 可提取，但颜色信息可能丢失 |
| **3D 结构图** | 60% | 2D 投影可提取，3D 信息丢失 |

---

### ✅ 完全支持的 PDF 类型

| 类型 | 支持程度 | 说明 |
|------|----------|------|
| **单栏学术论文** | 100% | 标准 arXiv/期刊格式 |
| **双栏会议论文** | 100% | IEEE/ACM 等会议格式 |
| **LaTeX 生成 PDF** | 100% | 公式、参考文献完美支持 |
| **标准期刊 PDF** | 95% | Nature/Science/Cell 等主流期刊 |

## 参考文献验证限制

### ❌ 无法验证的文献类型

| 类型 | 原因 | 建议 |
|------|------|------|
| **书籍章节** | CrossRef 覆盖不全 | 手动核实 ISBN |
| **会议摘要** | 数据库收录延迟 | 等待正式发表 |
| **预印本 (无 arXiv)** | 未公开数据库 | 联系作者获取信息 |
| **非英文文献** | API 支持有限 | 手动搜索本地数据库 |
| **非常古老的文献** | 数字化程度低 | 使用 Google Scholar |

---

### ⚠️ 验证成功率统计

| 文献类型 | 成功率 | 说明 |
|----------|--------|------|
| **DOI 文献 (2020-2026)** | 85% | 近期文献覆盖良好 |
| **DOI 文献 (2010-2019)** | 70% | 部分早期文献缺失 |
| **DOI 文献 (<2010)** | 50% | 早期文献数字化不全 |
| **arXiv 预印本** | 95% | arXiv API 覆盖良好 |
| **无 DOI/arXiv** | 0% | 必须人工核实 |

---

### API 速率限制

| API | 限制 | 影响 | 解决方案 |
|-----|------|------|----------|
| **CrossRef** | 600 请求/小时 | 大批量验证需等待 | 使用缓存，分批次处理 |
| **arXiv** | 600 请求/小时 | 同上 | 同上 |
| **无密钥模式** | 10 请求/分钟 | 速度较慢 | 注册 API 密钥提升配额 |

## 性能限制

### 处理时间

| PDF 页数 | 预计时间 | 说明 |
|----------|----------|------|
| **1-10 页** | <10 秒 | 快速处理 |
| **11-30 页** | 10-30 秒 | 标准处理 |
| **31-50 页** | 30-60 秒 | 中等处理 |
| **51-100 页** | 1-2 分钟 | 较慢处理 |
| **>100 页** | >2 分钟 | 建议分批处理 |

**注意:** 以上时间为不含参考文献验证的时间。验证时间取决于文献数量和缓存命中率。

---

### 内存使用

| 场景 | 内存使用 | 建议 |
|------|----------|------|
| **单篇 PDF (<30 页)** | <200 MB | 无需优化 |
| **单篇 PDF (30-100 页)** | 200-400 MB | 关闭图像处理 |
| **批量处理 (10 篇)** | 400-800 MB | 减少并发线程数 |
| **批量处理 (>50 篇)** | >1 GB | 分批处理，每批≤20 篇 |

---

### 并发限制

| 线程数 | 速度提升 | 内存使用 | 推荐场景 |
|--------|----------|----------|----------|
| **1 (串行)** | 1x | 最低 | 低配置电脑 |
| **5 (默认)** | 3-5x | 中等 | 日常使用 |
| **10** | 5-8x | 较高 | 批量处理 |
| **20 (最大)** | 8-10x | 最高 | 高性能服务器 |

**注意:** 线程数超过 10 后，速度提升边际效应明显，但内存使用线性增长。

## 功能限制

### ❌ 不支持的功能

| 功能 | 原因 | 替代方案 |
|------|------|----------|
| **OCR 文字识别** | 未集成 OCR 引擎 | 使用 Adobe Acrobat/AABBYY |
| **语音朗读** | 超出范围 | 使用 TTS 工具 |
| **自动翻译** | 未集成翻译 API | 使用 DeepL/Google Translate |
| **图表数据分析** | 需要计算机视觉 | 使用 ChartOCR 等工具 |
| **公式计算** | 需要符号计算引擎 | 使用 Wolfram Alpha |
| **参考文献全文下载** | 版权限制 | 使用机构订阅/Sci-Hub |
