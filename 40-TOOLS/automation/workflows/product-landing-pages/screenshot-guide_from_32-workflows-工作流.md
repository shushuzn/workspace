# 知识卡片生成器 - 截图指南

**目标:** 5 张产品截图，用于知乎文章  
**用时:** 10 分钟

## 📋 截图清单

| 编号 | 内容 | 尺寸 | 用途 |
|------|------|------|------|
| 1 | Landing Page 首页 | 1920x1080 | 知乎文章头图 |
| 2 | 上传界面 | 800x600 | 展示易用性 |
| 3 | 处理进度 | 800x600 | 展示实时反馈 |

## 🛠️ 截图步骤

### 准备：本地运行 Web UI

**步骤:**
```
1. 打开命令行
2. cd "30-scripts-脚本工具/01-KNOWLEDGE-CARDS"
3. py core/knowledge-card-webui.py --port 5000
4. 浏览器打开 http://127.0.0.1:5000
```

---

### 截图 1: Landing Page 首页

**操作:**
1. 打开浏览器
2. 访问：http://127.0.0.1:5000
3. 全屏 (F11)
4. 截图 (Win+Shift+S 或 PrintScreen)

**画面内容:**
- 标题："从 PDF 到知识卡片，一键生成"
- 副标题："自动提取、结构化、验证参考文献"
- CTA 按钮："免费试用"
- 功能图标 (4 个)

**保存为:** `screenshot-01-landing-page.png`

---

### 截图 2: 上传界面

**操作:**
1. 点击"上传 PDF"按钮
2. 显示文件选择对话框
3. 截图

**画面内容:**
- 拖拽上传区域
- "或点击选择文件"文字
- 支持格式提示 (PDF)
- 最大文件大小 (100MB)

**保存为:** `screenshot-02-upload.png`

---

### 截图 3: 处理进度

**操作:**
1. 选择测试 PDF (如 2603.09753v1.pdf)
2. 开始处理
3. 截图进度条

**画面内容:**
- 进度条 (显示百分比)
- 当前步骤 (提取元数据/章节/参考文献)
- 文件名
- 预计剩余时间

**保存为:** `screenshot-03-processing.png`

---

### 截图 4: HTML 卡片结果

**操作:**
1. 等待处理完成
2. 打开生成的 HTML 卡片
3. 滚动到中间位置
4. 截图

**画面内容:**
- 论文标题
- 作者/年份信息
- 摘要部分
- 章节列表 (Introduction/Methods 等)
- 参考文献 (带验证状态颜色)

**保存为:** `screenshot-04-result.png`

---

### 截图 5: 导出选项

**操作:**
1. 找到"导出"按钮
2. 点击显示导出选项
3. 截图

**画面内容:**
- HTML 导出选项
- BibTeX 导出选项
- Zip 导出选项
- 下载按钮

**保存为:** `screenshot-05-export.png`

## 📤 用于知乎

**知乎文章插入图片:**
1. 打开知乎写文章
2. 复制草稿内容
3. 在对应位置插入图片:
   - 开头：截图 1 (首页)
   - "上传 PDF"段落：截图 2
   - "处理过程"段落：截图 3
   - "展示结果"段落：截图 4
   - "导出功能"段落：截图 5

## ⚠️ 注意事项
