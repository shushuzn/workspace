# BiliBili 收集器 - 复用指南

## 复用方式

### 1. 命令行复用

```bash
# 热门排行
py reusable_bilibili_001.py hot tech

# 搜索
py reusable_bilibili_001.py search AI

# UP主
py reusable_bilibili_001.py up 123456

# 视频
py reusable_bilibili_001.py video BV1xx411c7mD
```

### 2. 代码复用

```python
from reusable_bilibili_001 import BilibiliCollector

# 创建实例
c = BilibiliCollector()

# 热门排行
data = c.task_hot("tech", 50)

# 搜索
data = c.task_search("AI")

# UP主
data = c.task_up_info("123456")

# 视频
data = c.task_video("BV1xx411c7mD")

# 保存
c.save(data, "my_data")
c.save_csv(data, "my_data")
```

### 3. 扩展复用

```python
# 添加新的抓取任务
class MyCollector(BilibiliCollector):
    
    def task_my_task(self):
        url = "https://..."
        fields = {
            "field1": {"selector": ".class1"},
            "field2": {"selector": ".class2"}
        }
        return self.crawl_list(url, ".item", fields)

# 使用
c = MyCollector()
c.task_my_task()
```
