# 股票分析工具 - 复用指南

## 快速开始

```bash
# 查看帮助
py sa_base_001.py help

# 策略推荐
py sa_base_001.py strategy recommend moderate

# 股票分析
py sa_base_001.py analyzer analyze AAPL

# 回测
py sa_base_001.py backtest run ma_cross 2024-01-01 2024-12-31
```

---

## 代码复用

### 1. 继承基类

```python
from sa_base_001 import SA_Base

class MyTool(SA_Base):
    def __init__(self):
        super().__init__("my_tool", {
            "param1": "default"
        })
    
    def run(self, input_data):
        self.logger.info("Running my tool")
        result = {"data": input_data}
        return self.format_result("success", result)
```

### 2. 使用统一接口

```python
from sa_base_001 import SA_Main

main = SA_Main()

# 调用任何工具
result = main.run("strategy", "recommend", "moderate")
result = main.run("analyzer", "analyze", "AAPL")
result = main.run("backtest", "run", "ma_cross")
```

### 3. 添加新工具

```python
class SA_Main:
    def __init__(self):
        self.tools = {
            # 现有工具...
            "my_tool": MyTool()  # 添加新工具
        }
```

## 配置复用

```python
# 保存配置
config = SA_Config("my_tool")
config.save("param", value)

# 读取配置
value = config.get("param", default_value)
```
