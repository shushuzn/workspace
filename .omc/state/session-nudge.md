## Proactive Insight Triggers

遇到以下情况时，立即生成 insight 并追加到 `session-insights.md`：
- 学到新工具/框架/方案
- 发现项目间可复用模式
- 踩到有价值的坑
- 从 GitHub/HN/arXiv 学到 novelty
- 代码中意识到某个架构问题

格式：
```
### N. [标题]
**Observation**: [具体观察，数据驱动]
**Rule**: [规则/模式]
**Fix**: [可执行动作或 N/A]
```

若 Fix 非 N/A，同步追加到 `pending-actions.md`。

## Insight 执行后验证要求

Fix 执行完成后，必须向 `insight-verifications.md` 追加验证结果：
```
## [insight标题]
- **预期效果**: [执行前预期的效果]
- **实际效果**: [执行后的真实效果]
- **有效性**: 有效 / 无效 / 部分有效
- **原因**: [判断依据]
```
