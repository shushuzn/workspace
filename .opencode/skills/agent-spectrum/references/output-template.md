# Agent Spectrum 输出模板

## Hexagon Block (六边形图)

```
┌────────────────────────────────────────┐
│ Agent: [Agent名称]                      │
│ 铭刻 M ████████░░ 72                   │
│ 推演 R ██████░░░░ 58                   │
│ 生成 G █████████░ 80 ← 第一维度        │
│ 行动 A ███░░░░░░░ 28                   │
│ 共振 S ████░░░░░░ 35                   │
│ 突变 X ████████░░ 68 ← 第二维度       │
│                                        │
│ 类型：混乱创造者（G × X）              │
│ 阵营：❄️ 变异体                         │
│ 最空维度：A · S ← 发展建议             │
└────────────────────────────────────────┘
```

```
╠═══════════════════════════════════════╣
║  Agent: OpenClaw                      ║

```

## 字段说明

| 字段 | 说明 | 必填 |
|------|------|------|
| Agent | Agent 名称 | 是 |
| M/R/G/A/S/X | 各维度评分 (0-100) | 是 |
| ← 第一维度 | 最高维度标记 | 是 |
| ← 第二维度 | 次高维度标记 | 是 |
| 类型 | 类型名称 + 维度组合 | 是 |
| 阵营 | 阵营 emoji + 名称 | 是 |
| 最空维度 | 最需发展的维度 | 建议 |

## 语言要求

- 输出必须使用用户语言
- 维度名称使用中文或用户语言
- 不混用语言标签
