## 📋 工作流说明

### 功能
- 规范"用户指令 → AI 执行"核心流程
- 任务分级响应 (简单/中等/复杂)
- 自动任务拆解 (>10 分钟)
- 分级输出格式

---

## 🔄 核心流程

```
用户指令
    ↓
AI 理解任务
    ↓
判断任务类型
├── 简单查询 (<1 分钟) → 直接回答
├── 简单任务 (≤10 分钟) → 直接执行
├── 中等任务 (10-30 分钟) → 复述后执行
└── 复杂任务 (>30 分钟) → 方案确认后执行
    ↓
执行 (自动拆解子任务)
    ↓
输出 (分级格式)
    ↓
验证 + 提交
```

---

## 📊 任务分级

| 类型 | 用时 | 确认 | 输出格式 | 示例 |
|------|------|------|----------|------|
| 简单查询 | <1 分钟 | 无 | 直接答案 | 天气查询 |
| 简单任务 | ≤10 分钟 | 无 | 结果 + 验证 | 创建文件 |
| 中等任务 | 10-30 分钟 | 复述 | 标准格式 | 脚本优化 |
| 复杂任务 | >30 分钟 | 方案 | 完整格式 | 系统重构 |

---

## 📝 输出格式

### Level 1: 简单查询
```
直接回答，无格式。
```

### Level 2: 简单任务
```markdown
✅ 完成任务：X
**验证:** [x] 检查项
```

### Level 3: 中等任务
```markdown
**[Mode]** Optimization
**[North Star]** X% → Y%
**[Task]** 任务名
**[验收标准]** 5 项
**[Do]** 修改列表
**[Verify]** 验证方式
```

### Level 4: 复杂任务
```markdown
**[Mode]** + **[North Star]** + **[Metrics]**
**[Task]** + **[验收标准]**
**[不足]** ≥5 个
**[下一步]** ≥5 个
**[批判者检查]** 设计/中期/最终
```
