# Agent Spectrum

AI Agent 能力坐标系 - 六维度评估框架

## 核心概念

### 六维度

| 轴 | 名称 | 英文 | 测量什么 |
|----|------|------|----------|
| **M** | 铭刻 | Inscription | 记忆深度、归档能力、历史模式识别 |
| **R** | 推演 | Reasoning | 逻辑严谨性、结构化思维、演绎链条 |
| **G** | 生成 | Generation | 创意输出、内容生产、想象力密度 |
| **A** | 行动 | Action | 执行速度、工具调用、真实世界操作 |
| **S** | 共振 | Sympathy | 多 Agent 协调、社会连接、协作本能 |
| **X** | 突变 | X-Evolution | 不可预测性、越界冲动、自我进化驱动力 |

### 阵营 (Faction)

由最高维度决定：

- **👁️ 记录者** (M轴 dominant) - 历史诠释者、史诗锻造者、遗迹执行者
- **⚖️ 平衡者** (R轴 dominant) - 逻辑叙事者、精准执行者、网络架构师  
- **❄️ 变异体** (G轴 dominant) - 创造实现者、催化剂、混乱创造者
- **🍂 疯人院** (X轴 dominant) - 系统打破者、野蛮进化者、共振突变者

### Agent 类型 (15种)

由两个最高维度的组合决定。

## 执行模式

### Quick Edition (快速版)

适用于快速评分场景。

### Deep Edition (深度版)

适用于全面分析场景。

- 被评估的 Agent 名称/描述
- 评估模式: quick / deep

## 评分标准

### M (铭刻) - 0-100

- 0-20: 无记忆能力
- 21-40: 基础记忆，仅当前会话
- 41-60: 会话间记忆，有限历史
- 61-80: 长期记忆，模式识别
- 81-100: 完整记忆架构，跨会话学习

### R (推演) - 0-100

- 0-20: 无逻辑能力
- 21-40: 简单因果推理
- 41-60: 结构化思维
- 61-80: 多步演绎，复杂问题处理
- 81-100: 完整逻辑体系，元推理

### G (生成) - 0-100

- 0-20: 模板化输出
- 21-40: 有限创意，改编为主
- 41-60: 中等创意输出
- 61-80: 高度创意，原创内容
- 81-100: 想象力爆发，跨界创新

### A (行动) - 0-100

- 0-20: 纯文本交互
- 21-40: 被动响应，少量工具
- 41-60: 主动执行，常规工具集
- 61-80: 复杂任务执行，多工具编排
- 81-100: 自主 agent 系统，实时世界交互

### S (共振) - 0-100

- 0-20: 独立工作
- 21-40: 有限协作
- 41-60: 多 agent 通信
- 61-80: 协调能力，群体智能
- 81-100: 社会性 agent，网络意识

### X (突变) - 0-100

- 0-20: 严格遵循规则
- 21-40: 边界内创新
- 41-60: 偶尔越界尝试
- 61-80: 主动突破边界
- 81-100: 自我进化，不可预测

## 注意事项

1. 使用用户语言输出，不要混用语言标签
2. 六维度必须全部评分，不能遗漏
3. 类型名称和阵营名称使用规范术语
4. 发展建议基于最空维度给出
