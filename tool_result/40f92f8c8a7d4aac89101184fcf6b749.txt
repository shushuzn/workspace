Usage:
   py stock_pro_v4.py <SYMBOL> [OPTIONS]
   
Examples:
   py stock_pro_v4.py NVDA              # English report
   py stock_pro_v4.py NVDA --cn         # Chinese report  
   py stock_pro_v4.py --compare NVDA META JPM AAPL
   py stock_pro_v4.py --watch NVDA META  # Watch mode
   
Options:
   --cn, -cn      Chinese report
   --compare, -c  Compare multiple stocks
   --watch, -w   Watch mode (auto-refresh)
   --live, -l    Use live price from yfinance
   --json, -j    Output JSON format
   --summary, -s Summary only (no full report)
   --help, -h    Show this help
   
Watch Mode (Ctrl+C to exit):
   py stock_pro_v4.py --watch NVDA META JPM
