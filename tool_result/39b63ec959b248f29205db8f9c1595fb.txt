### Technical Issues Fixed

| Issue | Solution |
|-------|----------|
| NapCat HTTP not enabled | Edit config to enable httpServers |
| subprocess encoding error | Use `errors='ignore'` in decode |
| Feishu output detection | Check both stdout and stderr |
| Message spam | Merge 5 news into 1 message |

### Key Lessons

1. **NapCat requires HTTP enabled** in config
2. **Windows subprocess** needs explicit encoding handling
3. **Merge messages** to avoid spam in groups
4. **Financial sources only** - user specifically requested
5. **No links** - user requested text-only
