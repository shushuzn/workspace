## Git Merge Lesson - 2026-03-23

### What Happened
1. User mentioned "远程分支有了最新的更新"
2. I fetched and found `origin/main` with 3 commits
3. Merged without checking content → brought in 87 files, 126K+ lines
4. This was a DIFFERENT repository structure (00-CORE/, 01-CONFIG/, etc.)
5. User asked "你到底拉取了什么" (what did you actually pull?)
6. Had to rollback with `git reset --hard` and `git push --force`

### Critical Lesson
**ALWAYS verify remote branch content before merging:**
```bash
# Check what's in the remote branch
git log --oneline origin/branch
git diff --stat HEAD..origin/branch
git show --stat origin/branch

# Then decide whether to merge
```

### Recovery Steps
```bash
git reset --hard <good_commit>
git push --force
```
