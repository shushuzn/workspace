# Coding Skill v1.0

Universal coding workflow for AI-assisted programming.

## Workflow

```
ARCHITECT → CODE → ASK → DEBUG
```

---

# 1. ARCHITECT

Before coding:
- Purpose of the code?
- Data flow?
- Which files?
- Edge cases?

---

# 2. CODE

## Style Rules

| Element | Convention |
|---------|------------|
| Variables | `user_name`, `max_count` |
| Functions | `get_user()`, `calculate_total()` |
| Classes | `UserService`, `PaymentProcessor` |
| Constants | `MAX_RETRIES`, `DEFAULT_TIMEOUT` |

## Required Elements

```python
def function(param: type) -> return_type:
    """
    Brief description.
    
    Args:
        param: Description
        
    Returns:
        Description
    """
    # DEBUG: Key checkpoint
    assert condition, "Error"
    return result
```

---

# 3. ASK (Self-Review)

Checklist:
- [ ] Edge cases handled?
- [ ] Error handling complete?
- [ ] Types correct?
- [ ] No hardcoded values?
- [ ] Tests covered?

## Anti-Patterns

| Avoid | Use Instead |
|-------|-------------|
| `except:` | `except SpecificError:` |
| Global state | Dependency injection |
| Deep nesting | Early return |
| Magic numbers | Constants |

---

# 4. DEBUG

## Testing

```python
def test_function():
    # Arrange
    input_data = ...
    expected = ...
    
    # Act
    result = function(input_data)
    
    # Assert
    assert result == expected
```

## Commands

```bash
pytest test_*.py -v
mypy src/
pylint src/
```

# 5. Safety Rules

## FORBIDDEN

| Category | Forbidden |
|----------|-----------|
| Shell | `bash`, `sh`, `cmd`, `powershell` |
| Execute | `os.system`, `subprocess`, `exec` |
| Network | `curl\|bash`, `wget` |

## ALLOWED

| Operation | Function |
|-----------|----------|
| Read | `read_file` |
| Write | `write_file`, `edit_file` |
| Browser | `browser_use` |
| Utility | `memory_search` |
