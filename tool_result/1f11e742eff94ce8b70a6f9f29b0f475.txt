Stock PRO v11.0 - Usage
=======================

Analysis:
   py -m stock_pro.main NVDA              Single stock (English)
   py -m stock_pro.main NVDA --cn         Single stock (Chinese)
   py -m stock_pro.main NVDA --json        JSON output
   py -m stock_pro.main NVDA --live       Use live price

Multi-Stock:
   py -m stock_pro.main --compare NVDA META JPM   Compare stocks
   py -m stock_pro.main --summary NVDA META JPM   Summary cards

Export:
   py -m stock_pro.main --csv NVDA META           Export to CSV
   py -m stock_pro.main --xlsx NVDA META          Export to Excel
   py -m stock_pro.main --db NVDA META            Save to SQLite
   py -m stock_pro.main --dashboard NVDA META     Generate HTML dashboard

Tools:
   py -m stock_pro.main --screener               Run screener
   py -m stock_pro.main --alert NVDA META         Check alerts
   py -m stock_pro.main --portfolio              Show portfolio
   py -m stock_pro.main --portfolio-add NVDA 100 150   Add position
   py -m stock_pro.main --portfolio-remove NVDA      Remove position
