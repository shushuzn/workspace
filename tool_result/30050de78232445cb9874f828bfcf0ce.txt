usage: tool_executor.py [-h] [--list] [--tool TOOL] [--workflow WORKFLOW]
                        [--task TASK] [--phase PHASE] [--context CONTEXT]
                        [--flow_id FLOW_ID] [--validate-compliance]
                        [--output-json]

Tool Executor - 工具执行引擎

options:
  -h, --help            show this help message and exit
  --list                List all registered tools
  --tool TOOL           Tool ID to execute
  --workflow WORKFLOW   Workflow ID to execute
  --task TASK           Task name (for auto-critic)
  --phase PHASE         Phase: start/mid/final
  --context CONTEXT     Context JSON (for workflows)
  --flow_id FLOW_ID     Flow ID for isolation
  --validate-compliance
                        Validate compliance rules
  --output-json         Output result as JSON

Examples:
  # List all tools
  py tool_executor.py --list
  
  # Execute single tool
  py tool_executor.py --tool auto-critic --task "my-task" --phase final
  
  # Execute workflow
  py tool_executor.py --workflow session-end --context "{"commit_message": "Task complete"}"
  
  # Validate compliance
  py tool_executor.py --validate-compliance
