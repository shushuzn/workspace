## 📋 标准格式

```markdown

**[Verify]** ...
**[Next]** ...
```

---

## 🎯 模式说明

| 模式 | 触发条件 | 策略 |
|------|----------|------|
| **Acceleration** | North Star < 50% | 快速推进，优先完成核心功能 |
| **Optimization** | 50% ≤ NS < 85% | 平衡速度与质量 |
| **Hardening** | NS ≥ 85% 或 Risk = 高 | 质量优先，严格验证 |
| **Recovery** | 核心指标下降 | 恢复稳定，修复问题 |

## 🔬 TRL (技术成熟度) 评估模板

**适用范围:** 材料科学/生物医学/硬件领域论文分析

```markdown
### TRL 评估

| TRL 级别 | 描述 | 证据 | 状态 |
|----------|------|------|------|
| **TRL 1** | 基本原理观察 | 理论分析 | ❌ |
| **TRL 2** | 技术概念形成 | 提案/综述 | ❌ |
| **TRL 3** | 概念验证 | 实验室原理验证 | ✅ |
| **TRL 4** | 组件验证 | 实验室环境测试 | ✅ |
| **TRL 5** | 相关环境验证 | 模拟环境测试 | ⏸️ |
| **TRL 6** | 原型演示 | 相关环境原型 | ❌ |
| **TRL 7** | 系统原型 | 运行环境原型 | ❌ |
| **TRL 8** | 系统完成 | 通过测试认证 | ❌ |
| **TRL 9** | 实际应用 | 商业部署 | ❌ |

**当前 TRL:** 4 (实验室组件验证)

**下一步里程碑:** TRL 5 (大型动物实验)

**关键风险:**
- 长期生物相容性未验证
- 量产工艺未开发
- 监管路径不明确
```

### TRL 评分标准

| 证据类型 | TRL 贡献 |
|----------|----------|
| 体外细胞实验 | +1 (TRL 3) |
| 小动物体内实验 (小鼠) | +1 (TRL 4) |
| 大型动物实验 | +1 (TRL 5) |
| 原型系统集成 | +1 (TRL 6) |
| 临床试验 I 期 | +1 (TRL 7) |
| 临床试验 II/III 期 | +1 (TRL 8) |
| FDA/CE 批准 | +1 (TRL 9) |

### 领域特定指标

#### 材料科学

| 指标 | 评估标准 | 数据来源 |
|------|----------|----------|
| **制造可扩展性** | lab (实验室直写) / pilot (中试) / mass (量产) | 制造方法章节 |
| **批次一致性** | CV < 5% (优) / < 10% (良) / < 20% (合格) | 补充数据/方法验证 |
| **长期稳定性** | > 30 天 (短期) / > 90 天 (中期) / > 1 年 (长期) | 稳定性测试章节 |
| **机械性能** | 拉伸强度、弹性模量、断裂伸长率 | 材料表征数据 |
| **电学性能** | 电导率、方块电阻、载流子迁移率 | 电学测试数据 |
| **表面特性** | 接触角、粗糙度 (Ra)、比表面积 | 表面表征数据 |

**示例:**
```markdown
### 材料科学指标

| 指标 | 值 | 评价 |
|------|-----|------|
| 制造可扩展性 | lab (CO₂激光直写) | 🟡 中 (需 R2R 工艺) |
| 批次一致性 | CV = 8% (n=10) | 🟢 良 |
| 长期稳定性 | 30 天阻抗变化 < 10% | 🟡 中 (需>90 天) |
| 电导率 | 1.2 × 10⁴ S/m | 🟢 优 |
| 接触角 | 95° (疏水) | 🟢 优 |
```

---

#### 生物医学

| 指标 | 评估标准 | 数据来源 |
|------|----------|----------|
| **生物相容性** | ISO 10993 全套 / 部分 / 未测试 | 生物相容性章节 |
| **细胞毒性** | ISO 10993-5 (Grade 0-4) | 细胞实验数据 |
| **体内反应** | 炎症反应评分、纤维化厚度 | 组织学分析 |
| **药代动力学** | ADME (吸收/分布/代谢/排泄) | PK/PD 研究 |
| **毒性** | LD50, NOAEL (未观察到不良反应剂量) | 毒理学研究 |
| **降解性** | 可降解/不可降解，降解产物安全性 | 降解研究 |

**示例:**
```markdown
### 生物医学指标

| 指标 | 值 | 评价 |
|------|-----|------|
| 生物相容性 | ISO 10993 部分测试 | 🟡 中 (需全套) |
| 细胞毒性 | Grade 1 (轻微) | 🟢 优 |
| 炎症反应 | 7 天轻度炎症，30 天消退 | 🟢 优 |
| 降解性 | 不可降解 (碳基材料) | ⚪ N/A |
```

#### 硬件/设备

| 指标 | 评估标准 | 数据来源 |
|------|----------|----------|
| **MTBF** | > 10,000 小时 (优) / > 1,000 小时 (良) | 可靠性测试 |
| **环境适应性** | 温度 (-40~85°C)、湿度 (5-95% RH)、振动 | 环境测试报告 |
| **认证状态** | CE / FCC / UL / FDA / 无 | 认证文档 |
| **功耗** | mW 级 (优) / W 级 (中) / 10W+ (高) | 电学测试 |
| **尺寸/重量** | 便携式 / 台式 / 固定式 | 产品规格 |
| **防护等级** | IP65 / IP67 / IP68 / 无 | 防护测试 |

**示例:**
```markdown
### 硬件指标

| 指标 | 值 | 评价 |
|------|-----|------|
| MTBF | 5,000 小时 (估算) | 🟡 中 (需实测) |
| 工作温度 | 0-50°C | 🟡 中 (需 -20~70°C) |
| 认证状态 | 无 | 🔴 未开始 |
| 功耗 | 50 mW | 🟢 优 |
| 防护等级 | IP54 (防尘溅) | 🟡 中 (需 IP67) |
```

**评分说明:**
- 5.0: 完全满足，行业领先
- 4.0: 良好， minor issues
- 3.0: 可接受，需要改进
- 2.0: 有重大缺陷
- 1.0: 不可接受

## ✅ 验收标准规则

- 必须 ≥5 个具体要求
- 每个要求可验证 (是/否)
- 使用 ✅/⏸️/❌ 标记状态

**示例:**
```
**[验收标准]**
1. 文件完整性验证 ✅
2. URL 有效性检查 ✅
3. Git 提交成功 ✅
4. 报告生成完成 ✅
5. 索引更新完成 ✅
```

---

## ⚠️ 不足规则

- 必须 ≥5 个
- 具体、可操作
- 避免模糊描述

**示例:**
```
**[不足]**
1. 未提前配置 .gitignore
2. 未自动化清理流程
3. 未检查其他目录
4. 未文档化清理流程
5. 未添加清理脚本
```

---

## 📋 下一步规则

- 必须 ≥5 个
- 按优先级排序
- 可执行、可追踪

**示例:**
```
**[下一步]**
1. 更新 MEMORY.md
2. 检查其他目录临时文件
3. 添加自动清理脚本
4. 文档化清理规范
5. 结束今日工作
```

## 🎨 输出风格

### 简洁原则
- 避免冗长段落
- 使用列表和表格
- 关键信息前置

### 结构化
- 使用标准章节
- 保持一致的标记
- 清晰的层次

### 指标驱动
- North Star 百分比
- 具体数值
- 趋势箭头 (→ +-)
