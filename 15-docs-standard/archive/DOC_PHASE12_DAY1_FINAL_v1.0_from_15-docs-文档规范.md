### 已实现

| 措施 | 配置 | 效果 |
|------|------|------|
| 线程限制 | intra=4, inter=2 | 只用部分核心 |
| 并发控制 | max=1 | 单任务处理 |
| CPU 监控 | 阈值 70% | 超限自动等待 |
| 缓存系统 | 500 条 LRU | 重复查询 0 秒 |
