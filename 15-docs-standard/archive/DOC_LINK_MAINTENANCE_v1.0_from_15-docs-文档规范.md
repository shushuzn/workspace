## 🔧 维护任务

### 每周任务

#### 1. 断链检查
**命令:**
```powershell
.\30-scripts\check-broken-links.ps1 -Verbose
```

**操作:**
1. 查看 `broken-links-report.md`
2. 识别真实断链 (排除模板占位符)
3. 修复或归档断链文档
4. 更新本报告

**定时:** 每周日 06:00

---

#### 2. 热度分析
**命令:**
```powershell
.\30-scripts\analyze-link-heat.ps1
```

**操作:**
1. 查看 `link-heat-report.md`
2. 识别 TOP 10 热门文档
3. 确保热门文档内容最新
4. 考虑为热门文档创建镜像/快捷方式

**定时:** 每月 1 号 07:00

---

### 每月任务

#### 3. 链接网络审查
**检查项:**
- [ ] 新增文档是否添加了反向链接
- [ ] 删除文档是否更新了引用
- [ ] 热门文档是否需要优化
- [ ] 冷门文档是否需要归档

**输出:** 更新 `LINK_INDEX.md` 统计

---

#### 4. 文档结构优化
**基于热度分析:**
- 超热门文档 (10+ 次) → 放在易访问位置
- 热门文档 (5-9 次) → 添加详细说明
- 冷门文档 (1 次) → 评估价值，考虑归档

## 📝 最佳实践

### 创建新文档时

1. **添加正向链接**
   ```markdown
   ## 🔗 相关链接
   - [[相关文档 1]] - 说明
   - [[相关文档 2]] - 说明
   ```

2. **添加反向链接**
   ```markdown
   ## 🔙 反向链接
   **链接到本文档的文件:**
   - [[引用文档 1]] - 引用位置
   - [[引用文档 2]] - 引用位置
   ```

3. **更新总索引**
   - 在 `LINK_INDEX.md` 添加新链接
   - 更新链接统计

---

### 删除文档时

1. **搜索引用**
   ```powershell
   Select-String -Path *.md -Pattern "被删除的文档"
   ```

2. **更新引用文档**
   - 移除或替换断链
   - 添加归档说明

3. **更新索引**
   - 从 `LINK_INDEX.md` 移除
   - 更新统计

---

### 移动文档时

1. **创建重定向** (可选)
   ```markdown
   # 文档已移动

   本文档已移动到：[[新位置]]
   ```

2. **更新所有引用**
   - 使用搜索替换
   - 更新索引

## 🔍 常见问题

### Q: 断链率高怎么办？

**A:** 
1. 区分真实断链和模板占位符
2. 优先修复高频引用的断链
3. 规范模板文件格式

### Q: 如何识别核心文档？

**A:** 
- 运行热度分析
- TOP 10 热门文档是核心
- 确保核心文档内容最新

### Q: 冷门文档需要处理吗？

**A:**
- 64% 冷门是正常的 (长尾分布)
- 评估内容价值
- 有价值的保留，过期的归档
