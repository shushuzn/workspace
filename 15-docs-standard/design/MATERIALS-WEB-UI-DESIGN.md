## 📊 界面设计

### 首页 Dashboard

**功能模块:**
1. **关键指标卡片**
   - 材料总数
   - 今日收集论文数
   - 数据库连接状态
   - 系统运行状态

2. **最近材料**
   - 最新添加的材料
   - 快速预览晶体结构

3. **性能预测入口**
   - 上传 CIF 文件
   - 输入化学式
   - 查看预测结果

4. **合成路径推荐**
   - 输入目标材料
   - 查看推荐路径
   - 成本估算

---

### 材料浏览页面

**功能:**
1. **搜索框**
   - 化学式搜索
   - 材料名称搜索
   - 性能范围筛选

2. **列表视图**
   - 材料卡片展示
   - 关键性能指标
   - 快速操作按钮

3. **详情页面**
   - 晶体结构 3D 展示
   - 性能数据表格
   - 相关论文链接
   - 合成路径信息

---

### 性能预测页面

**输入:**
- CIF 文件上传
- 化学式输入
- 结构参数调整

**输出:**
- 带隙预测值
- 弹性模量预测
- 稳定性评估
- 置信度分数

**可视化:**
- 能带结构图
- 态密度图
- 电子密度图

---

### 合成路径页面

**输入:**
- 目标材料化学式

**输出:**
- 推荐合成路径 (Top 3)
- 反应条件 (温度、时间、气氛)
- 成本估算
- 安全性评分

**可视化:**
- 反应流程图
- 成本饼图
- 安全性雷达图

## 🔧 技术实现

### 前端技术栈
- **框架:** React / Vue.js
- **3D 可视化:** 3Dmol.js, NGL Viewer
- **图表:** Chart.js, Plotly
- **UI 组件:** Ant Design / Material UI

### 后端技术栈
- **框架:** FastAPI / Flask
- **数据库:** MongoDB (材料数据), Neo4j (知识图谱)
- **ML 模型:** scikit-learn, PyTorch
- **任务队列:** Celery + Redis

### API 设计
```yaml
/materials:
  GET: 获取材料列表
  POST: 添加新材料

/materials/{id}:
  GET: 获取材料详情
  PUT: 更新材料信息
  DELETE: 删除材料

/materials/{id}/structure:
  GET: 获取晶体结构 (CIF)

/materials/{id}/properties:
  GET: 获取性能数据
  POST: 预测性能

/materials/{id}/synthesis:
  GET: 获取合成路径
  POST: 推荐合成路径
```
