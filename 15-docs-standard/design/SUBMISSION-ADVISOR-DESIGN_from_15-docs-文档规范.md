## 📋 功能概述

基于论文内容自动推荐合适的投稿期刊/会议

---

## 🗄️ 数据库设计

### 1. 期刊/会议数据库

**字段:**
```json
{
  "name": "期刊/会议名称",
  "type": "journal|conference",
  "field": ["AI", "ML", "CV", "NLP"],
  "ccf_rank": "A|B|C",
  "impact_factor": 5.2,
  "acceptance_rate": 0.25,
  "submission_deadline": "2026-06-30",
  "website": "https://...",
  "notes": "备注信息"
}
```

**数据来源:**
- CCF 推荐列表
- 各期刊官网
- 历史录用数据

---

## 🔍 匹配算法

### 1. 关键词匹配

**步骤:**
1. 提取论文关键词 (标题 + 摘要)
2. 与期刊领域标签匹配
3. 计算匹配度分数

**公式:**
```
match_score = (重叠关键词数 / 论文关键词总数) * 100
```

### 2. 影响力匹配

**逻辑:**
- 高影响力论文 → 推荐高 IF 期刊
- 中等影响力 → 推荐中等 IF 期刊

### 3. 历史数据分析

**数据:**
- 类似论文的录用期刊
- 同作者的投稿历史
