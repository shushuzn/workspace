## 📊 使用前说明

### 1. 复制模板

将上述模板复制到新文件，按命名规范命名:
```
DRAFT_卷 X_第 X 章_标题_日期_v0.1.md
```

### 2. 填写概要

在动笔前，先填写"本章概要"部分，明确:
- 时间、地点、人物
- 核心事件 (一句话)
- 与前章的衔接
- 为本章设定的目标

### 3. 按结构写作

按照开场→发展→高潮→收尾的结构，每部分控制字数:
- 开场：500-800 字
- 发展：1500-2000 字
- 高潮：1500-2000 字
- 收尾：500-800 字

### 4. 提炼金句

写作完成后，提炼 1-2 句核心金句，放在"核心金句"部分

### 5. 检查关联

填写"前后关联"部分，确保:
- 与前章衔接自然
- 为下章埋下伏笔
- 与前文有呼应 (如有)

### 6. 修订迭代

按版本迭代规范，逐步完善:
- v0.1 → v0.2: 补充细节描写
- v0.2 → v0.3: 优化对话与节奏
- v0.3 → v1.0: 定稿

## 🎯 写作技巧

### 开场技巧

1. **环境切入:** 以环境描写开场，烘托氛围
   > "暮色四合，巷口路灯昏黄，将林砚的影子拉得老长。"

2. **动作切入:** 以人物动作开场，直接进入场景
   > "林砚盯着手机屏幕，手指在屏幕上飞快滑动。"

3. **对话切入:** 以对话开场，快速引入冲突
   > "'林砚，你作业写完了吗？'陈舟问道。"

4. **心理切入:** 以心理活动开场，展现内心状态
   > "林砚心中烦躁，明明知道该学习了，却怎么也提不起劲。"

### 发展技巧

1. **冲突升级:** 逐步加大冲突强度
2. **多线并进:** 主线 + 副线同时推进
3. **人物互动:** 通过对话和行动展现人物关系
4. **细节描写:** 用细节增强画面感

### 高潮技巧

1. **情绪顶点:** 让人物情绪达到顶点
2. **关键抉择:** 让人物面临重要选择
3. **冲突爆发:** 矛盾集中爆发
4. **节奏加快:** 用短句加快节奏

### 收尾技巧

1. **事件结果:** 交代事件结果
2. **人物成长:** 展现人物成长或反思
3. **下章伏笔:** 为下章埋下伏笔
4. **余韵悠长:** 留有余韵，让读者期待下章
