## 🎭 主角

### 林砚

| 属性 | 描述 |
|------|------|
| **身份** | 主角，江南市井寻常人家子弟 |
| **天资** | 中上，非天才型 |
| **性格** | 少年贪玩，喜新奇，缺乏定力，后转变为沉稳坚韧 |
| **家庭** | 父为机械厂技工，母为社区服务者 |
| **修行路径** | 启蒙→筑基→专精→架构→管理→操盘→战略→自由→传承 |
| **核心心魔** | 怠惰、浮躁、焦虑、畏难、自满、功利、短视 |
| **最终成就** | 尘世传承宗师，实现三重自由，泽被后世 |

**成长弧线:**
```
懵懂少年 → 有心向学 → 技术行家 → 架构师 → 管理者 → 
资源操盘手 → 战略制定者 → 自由修行者 → 传承宗师
```
