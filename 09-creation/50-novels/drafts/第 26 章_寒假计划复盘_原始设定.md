# 第 26 章 寒假计划复盘

**字数目标:** 3000 字  
**核心事件:** 寒假 60 天复盘，制定新学期计划  
**场景:** 家中/书房  
**认知进展:** 【专注力】+5 XP (55/100)  
**AI 率:** 接受现状 (~0.60)

---

开学第七周。

晚上八点，林砚在做题。

第二十六道，函数压轴题。

写到一半，母亲敲门。

"进来。"

母亲端着一杯牛奶，走进来。

"喝了。"

"哦。"

林砚接过牛奶，一口气喝完。

母亲没走。

她站在书桌旁，看着练习册。

"七十六天了。"

"嗯。"

"寒假六十天，新学期十六天。"

"嗯。"

母亲拿起练习册，翻了翻。

一页，两页，三页......

七十六页，全是演算。

每一道题，都有详细步骤。

做对的，打勾。

做错的，用红笔订正。

旁边还有注：

```
"错误原因：计算粗心"
"错误原因：概念不清"
"下次注意：先化简再计算"
```

母亲看着，很久。

"小砚。"

"嗯？"

"寒假......收获大吗？"

林砚顿了顿。

"大。"

"多大？"

"从 45 分到 78 分。"

"从 40% 到 85%。"

"从一千道题。"

母亲看着他，没说话。

那眼神，很复杂。

有骄傲，有心疼，还有......信任。

"那新学期呢？"

"目标前十。"

"现在多少？"

"十二。"

"差两名。"

"嗯。"

母亲不说话了。

她继续翻。

翻到最后一页，停住了。

那里有一行字：

```
"新学期计划：
每天二十道题。
每周十篇英语阅读。
每月一次总结。
期末考试 120 分。
班级前十。"
```

母亲的手，抖了一下。

"能完成吗？"

"能。"

"这么肯定？"

"嗯。"林砚说，"因为......我已经坚持七十六天了。"

母亲看着他，很久。

然后，笑了。

那笑容里，有骄傲，有心疼，还有......释然。

"好。"她说，"妈妈支持你。"

"谢谢。"

"不用谢。"母亲说，"这是应该的。"

她端起空杯子，走到门口。

"妈。"

"嗯？"

"如果......我完成了呢？"

母亲停住了。

她转过身，看着林砚。

"完成了又怎样？"

"我......"

"完成了，就奖励你。"

"什么奖励？"

"你想要什么？"

林砚想了想。

"我想......"

"去一次北京。"

"看看清华。"

母亲看着他，没说话。

那眼神，很复杂。

有骄傲，有心疼，还有......信任。

"好。"她说，"完成了，就去。"

"嗯。"

母亲走出去，关上门。

林砚坐在书桌前，很久。

然后，继续做题。

第七十七天的第一道。
