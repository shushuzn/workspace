# 第 103 章 第一轮复习

**字数目标:** 3000 字  
**核心事件:** 高三第一轮复习启动，林砚和陈舟一起学习  
**场景:** 教室/图书馆  
**认知进展:** 【学习力】+5 XP (115/100)  
**AI 率:** 接受现状 (~0.60)

---

开学第四十周。

周三早自习。

班主任走进教室。

"同学们。"

"从今天开始。"

"第一轮复习。"

"为期三个月。"

"所有知识点。"

"全部过一遍。"

全班安静了。

"林砚。"

"到。"

"你基础好。"

"帮助同学。"

"好。"

班主任看着他，没说话。

那眼神，很复杂。

有骄傲，有心疼，还有......信任。

"坐下。"

"嗯。"

---

放学，图书馆。

三楼，老位置。

陈舟已经到了。

"来了？"

"嗯。"

林砚坐下，摊开计划表。

"第一轮复习。"

"嗯。"

"准备好了吗？"

"准备好了。"

"那......"

"一起努力。"

"好。"

"约定。"

"约定。"

两人伸出手，击掌。

"啪。"

清脆的声音。

---

"这道题。"

陈舟指着试卷。

"怎么做？"

林砚拿过来，看了看。

"用导数。"

"导数？"

"嗯。"

林砚拿起笔，在草稿纸上写。

"先看函数。"

"f(x) = x³ - 3x + 1。"

"求导。"

"f'(x) = 3x² - 3。"

"令 f'(x) = 0。"

"得 x = ±1。"

陈舟看着他，没说话。

那眼神，很复杂。

有惊讶，有佩服，还有......欣赏。

"然后......"

"判断单调性。"

"x < -1 时，f'(x) > 0，递增。"

"-1 < x < 1 时，f'(x) < 0，递减。"

"x > 1 时，f'(x) > 0，递增。"

"所以......"

"极小值在 x = 1 处。"

"极大值在 x = -1 处。"

陈舟不说话了。

她看着林砚，很久。

"你怎么会？"

"你爸爸教的。"

"你爸爸？"

"嗯。"

"他是大学教授。"

"教数学的。"

陈舟看着他，没说话。

那眼神，很复杂。

有惊讶，有佩服，还有......信任。

"那......"

"以后，有不会的，问我。"

"好。"

"谢谢。"

"不用谢。"林砚说，"朋友嘛。"

"对，朋友。"

---

晚上，回到家。

母亲在客厅等他。

"回来了？"

"嗯。"

"今天，怎么晚了？"

"第一轮复习。"

"嗯。"

"准备好了吗？"

"准备好了。"

母亲看着他，没说话。

那眼神，很复杂。

有骄傲，有心疼，还有......信任。

"好。"她说，"妈妈相信你。"

"谢谢。"

"不用谢。"母亲说，"这是应该的。"

她转身走进厨房。

"今晚，做你爱吃的。"

"嗯。"

林砚走进房间，关上门。

他坐在书桌前，拿出那张计划表。

一百八十三个勾，很整齐。

"明天，第一百八十 四天。"

"继续。"
