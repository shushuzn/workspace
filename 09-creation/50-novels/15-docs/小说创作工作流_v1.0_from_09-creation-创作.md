## 🎯 写作质量标准

### 1. 对话质量标准

#### ❌ 错误示范
```
"来了？"
"嗯。"
"准备好了吗？"
"准备好了。"
"那......"
"一起努力。"
"好。"
```

#### ✅ 正确示范
```
"你今天怎么来这么晚？"林砚放下笔，抬头看向门口。

陈舟把书包放在桌上，拉开椅子坐下："昨晚刷题到两点，闹钟没响。"

"145 分还这么拼？"

"比你聪明的人比你还努力，怕不怕？"她瞥了他一眼，嘴角微扬。

林砚笔尖顿了顿："怕。所以更要追。"
```

#### 对话规则
| 规则 | 要求 | 案例 |
|------|------|------|
| **长度变化** | 对话有长有短 | 短句 5-10 字，长句 20-40 字 |
| **动作穿插** | 对话中穿插动作 | "......"他放下笔 |
| **个性区分** | 不同角色说话方式不同 | 林砚沉稳，江越活泼 |
| **潜台词** | 话里有话 | "比你聪明的人比你还努力" |
| **避免重复** | 不重复使用相同句式 | 不用连续 3 次"那眼神复杂" |

### 2. 场景描写标准

#### ❌ 错误示范
```
放学，图书馆。
三楼，老位置。
陈舟已经到了。
```

#### ✅ 正确示范
```
下午五点，放学铃声刚响，林砚就背起书包往图书馆跑。

三楼靠窗的位置，陈舟已经坐在那里了。夕阳从窗外斜射进来，在她马尾辫上镀了一层金边。她正低头做题，草稿纸上密密麻麻写满了公式。

林砚在对面坐下，书包拉链的声音在安静的图书馆里格外清晰。

陈舟抬起头，推了推眼镜："今天晚了三分钟。"
```

#### 场景描写规则
| 要素 | 要求 | 案例 |
|------|------|------|
| **时间** | 具体时间 | 下午五点，放学铃声刚响 |
| **地点** | 具体位置 | 三楼靠窗的位置 |
| **光线** | 光影描写 | 夕阳镀了一层金边 |
| **声音** | 环境声音 | 拉链声格外清晰 |
| **动作** | 细节动作 | 推了推眼镜 |

### 3. 心理描写标准

#### ❌ 错误示范
```
林砚愣住了。
"145 分？"
"嗯。"
"那......"
"我以前的学校，比较简单。"
```

#### ✅ 正确示范
```
林砚笔尖一顿，墨水在试卷上晕开一个小黑点。

145 分。

比他高出整整 27 分。

他抬起头，重新打量这个新转来的女生。马尾辫，清秀的五官，眼神沉稳得不像同龄人。校服穿在她身上格外整洁，袖口连个褶皱都没有。

"你以前的学校，比较简单？"他声音平静，心里却掀起惊涛骇浪。

"嗯。"陈舟低头继续做题，仿佛刚才说的只是"今天天气不错"。
```

#### 心理描写规则
| 要素 | 要求 | 案例 |
|------|------|------|
| **身体反应** | 用身体反应表现心理 | 笔尖一顿，墨水晕开 |
| **内心独白** | 简短有力 | 145 分。比他高出 27 分。 |
| **观察细节** | 通过观察表现心理 | 重新打量这个女生 |
| **对比反差** | 表面平静内心波动 | 声音平静，心里惊涛骇浪 |

### 4. 章节结构标准

#### 标准章节结构 (3000 字)
```
开头 (500 字)
├── 场景设定 (时间、地点、人物)
├── 引出本章核心事件
└── 制造小悬念

发展 (1500 字)
├── 核心事件展开
├── 人物互动 (对话 + 动作)
├── 冲突或转折
└── 情感推进

高潮 (700 字)
├── 关键对话或行动
├── 认知进展或情感突破
└── 本章核心目标达成

结尾 (300 字)
├── 简短总结
├── 埋下伏笔
└── 引出下一章
```

#### ❌ 错误结构
```
学校 → 图书馆 → 家 (每章都一样)
```

#### ✅ 正确结构变化
| 章节 | 场景组合 | 变化 |
|------|----------|------|
| 101 | 教室→天台→家 | 加入天台场景 |
| 102 | 教室→实验室→操场 | 加入实验室 |
| 103 | 图书馆→食堂→回家路上 | 加入食堂 |
| 104 | 教室→办公室→公园 | 加入公园 |
| 105 | 考场→庆祝地点→家 | 加入庆祝场景 |

## 🔧 写作流程

### 步骤 1: 章节大纲 (写作前)
```markdown
## 第 X 章 章节名

**字数目标:** 3000 字
**核心事件:** 一句话概括
**场景:** 2-3 个不同场景
**人物:** 出场人物列表
**情感线:** 本章情感进展
**伏笔:** 埋下的伏笔

### 详细大纲
1. 开头 (500 字): 场景 + 悬念
2. 发展 (1500 字): 事件 + 冲突
3. 高潮 (700 字): 突破 + 进展
4. 结尾 (300 字): 伏笔 + 引出
```

### 步骤 2: 初稿创作 (写作中)
- 按照大纲写作
- 不追求完美，先完成
- 标记需要修改的地方
- 字数控制在 2800-3200 字

### 步骤 3: 自我审核 (写作后)
```markdown
## 审核清单

### 对话审核
- [ ] 对话有长有短
- [ ] 动作穿插自然
- [ ] 人物个性区分
- [ ] 无重复句式

### 场景审核
- [ ] 时间具体
- [ ] 地点具体
- [ ] 有光影描写
- [ ] 有声音描写

### 心理审核
- [ ] 有身体反应
- [ ] 有内心独白
- [ ] 有观察细节
- [ ] 有对比反差

### 结构审核
- [ ] 开头有悬念
- [ ] 发展有冲突
- [ ] 高潮有突破
- [ ] 结尾有伏笔
```

### 步骤 4: 修改优化 (审核后)
- 根据审核清单修改
- 重点修改对话和场景
- 删除重复句式
- 增加细节描写

### 步骤 5: 最终审核 (修改后)
- 通读全文
- 检查流畅度
- 确认字数达标
- 提交创作

## 🚫 AI 痕迹规避指南

### 1. 避免重复句式

#### ❌ AI 常用
- "那眼神，很复杂。有...有...还有..."
- "......" + 人名 + 说
- "嗯。"单独成段

#### ✅ 人类写法
- 变化表达方式："目光深邃"、"眼神闪烁"、"眸光复杂"
- 多样化对话标记：他顿了顿、她轻声道、话音未落
- 丰富回应方式：点头、沉默、反问

### 2. 避免过于工整

#### ❌ AI 常用
```
"学习。"
"工作。"
"生活。"
```

#### ✅ 人类写法
```
"学习不能落下，每天都要做题。"
"工作也要兼顾，毕竟要赚钱。"
"至于生活......"他苦笑，"挤时间吧。"
```

### 3. 避免直白情感

#### ❌ AI 常用
"他很难过。"
"她很高兴。"

#### ✅ 人类写法
"他低下头，盯着地面，很久没说话。"
"她嘴角上扬，眼睛弯成月牙。"

## 📊 质量评分标准

### 每章评分 (100 分制)

| 项目 | 分值 | 评分标准 |
|------|------|----------|
| **对话质量** | 30 分 | 自然度、个性区分、潜台词 |
| **场景描写** | 25 分 | 细节、光影、声音、动作 |
| **心理描写** | 20 分 | 身体反应、内心独白、对比 |
| **章节结构** | 15 分 | 开头悬念、高潮突破、结尾伏笔 |
| **AI 规避** | 10 分 | 无重复句式、无直白情感 |

### 评分等级
- **90-100 分:** 优秀，可直接发布
- **80-89 分:** 良好，小修后发布
- **70-79 分:** 合格，需要修改
- **60-69 分:** 不合格，重写
- **60 分以下:** 严重问题，删除重写
