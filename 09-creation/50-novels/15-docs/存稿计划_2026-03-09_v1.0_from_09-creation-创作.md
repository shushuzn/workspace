## 📊 存稿目标

### 核心目标

| 阶段 | 存稿量 | 用途 | 完成时间 |
|------|--------|------|----------|
| **开书前** | 50 章 | 应对突发，保证不断更 | 开书前 1 周 |
| **连载期** | 保持 20 章 | 缓冲意外，调整状态 | 持续维护 |
| **后期** | 逐步减少 | 根据读者反馈调整 | 完本前 2 个月 |

### 为什么需要 50 章存稿？

| 原因 | 说明 | 风险等级 |
|------|------|----------|
| **突发情况** | 生病/有事/灵感枯竭 | 🔴 高 |
| **质量波动** | 状态不好时不强行更新 | 🟡 中 |
| **读者反馈** | 根据反馈调整后续剧情 | 🟡 中 |
| **推荐位** | 上架/推荐时需要爆更 | 🟢 低 |
| **心态稳定** | 有存稿不焦虑，写作更从容 | 🟢 低 |

## 📅 写作节奏

### 单章写作时间估算

| 环节 | 时间 | 说明 |
|------|------|------|
| **大纲细化** | 30 分钟 | 将 500 字大纲扩展为详细场景 |
| **初稿写作** | 90 分钟 | 5000 字，约 55 字/分钟 |
| **伏笔检查** | 15 分钟 | 检查伏笔/小巧思/引用植入 |
| **文白调整** | 15 分钟 | 调整文白比例至 7:3 |
| **校对修改** | 30 分钟 | 错别字/语病/逻辑检查 |
| **合计** | **3 小时/章** | 理想状态 |

### 日写作计划

| 模式 | 每日章节 | 每日时间 | 适合状态 |
|------|----------|----------|----------|
| **全职模式** | 3 章/天 | 9 小时 | 辞职写作 |
| **兼职模式** | 2 章/天 | 6 小时 | 下班后写作 |
| **业余模式** | 1 章/天 | 3 小时 | 碎片时间 |
| **周末模式** | 10 章/周末 | 30 小时 | 仅周末写作 |

### 推荐模式：兼职模式

**理由:**
- 稳定可持续 (不影响工作)
- 50 章存稿约需 25 天 (近 1 个月)
- 连载期每日 2 章可维持

## 📝 写作流程

### 单章写作 SOP

```
1. 复习大纲 (5 分钟)
   ↓
2. 细化场景 (30 分钟)
   - 本章核心事件
   - 爽点/伏笔/小巧思/引用
   - 与前章衔接
   ↓
3. 初稿写作 (90 分钟)
   - 开场 (500-800 字)
   - 发展 (1500-2000 字)
   - 高潮 (1500-2000 字)
   - 收尾 (500-800 字)
   ↓
4. 伏笔检查 (15 分钟)
   - 使用检查清单
   - 标注伏笔编号
   ↓
5. 文白调整 (15 分钟)
   - 检查文白比例 (7:3)
   - 调整过度文言/白话
   ↓
6. 校对修改 (30 分钟)
   - 错别字/语病
   - 逻辑检查
   - 时代错乱检查
   ↓
7. 保存归档
   - 文件名：DRAFT_卷 X_第 X 章_标题_日期_v0.1.md
   - 备份至云盘
```

## ✅ 质量检查清单

### 写前检查 (动笔前)

- [ ] 本章核心事件是什么？
- [ ] 本章爽点是什么？(每 10 章必须有大爽点)
- [ ] 本章小吸引点是什么？(每 3 章必须有)
- [ ] 与前章衔接是否自然？
- [ ] 为下章埋了什么伏笔？
- [ ] 本章植入什么伏笔/小巧思/引用？

### 写后检查 (完稿后)

- [ ] 字数是否达标 (5000±500)？
- [ ] 文白比例是否合理 (7:3)？
- [ ] 对话是否符合人物身份？
- [ ] 环境描写是否有意境？
- [ ] 心理描写是否有深度？
- [ ] 核心金句是否凝练？
- [ ] 是否有过度文言或过度白话？
- [ ] 是否有时代错乱？
- [ ] 风格是否统一？

### 伏笔检查 (专项)

- [ ] 本章植入了什么伏笔？(1-2 个)
- [ ] 本章回收了什么伏笔？(如有)
- [ ] 伏笔是否隐蔽 (不刻意)？
- [ ] 伏笔是否多义 (不单一)？
- [ ] 伏笔是否情感绑定 (非事件对应)？

### 引用检查 (专项)

- [ ] 引用是否自然融入？
- [ ] 是否点明出处 (❌ 不应点明)？
- [ ] 是否解释含义 (❌ 不应解释)？
- [ ] 是否刻意 (❌ 应随口而出)？

### 主角缺陷检查 (专项)

- [ ] 本章是否体现主角缺陷？(情感障碍/较真/工作狂)
- [ ] 缺陷是否自然 (不刻意)？
- [ ] 缺陷是否服务于情节？

### 陈舟独立设定检查 (专项)

- [ ] 陈舟是否有独立目标/行动？
- [ ] 陈舟是否不是依附角色？
- [ ] 陈舟是否有独立困境/成长？

## 🔄 反馈调整机制

### 读者反馈收集

| 渠道 | 频率 | 处理方式 |
|------|------|----------|
| **章节评论** | 每日 | 标记关键意见 |
| **书评区** | 每周 | 整理共性问题 |
| **读者群** | 每周 | 直接互动，收集建议 |
| **数据后台** | 每周 | 分析留存/订阅数据 |

### 反馈处理原则

| 反馈类型 | 处理方式 | 示例 |
|----------|----------|------|
| **错别字/语病** | 立即修改 | 评论区指出后 24 小时内修正 |
| **逻辑漏洞** | 评估后修改 | 如影响后续剧情，发单章说明 |
| **剧情建议** | 选择性采纳 | 符合核心设定的采纳 |
| **人物批评** | 评估合理性 | 如普遍反映，调整人物塑造 |
| **更新要求** | 坚持节奏 | 不盲目加更，保证质量 |

### 剧情调整流程

```
读者反馈 → 评估影响 → 决定是否调整 → 
→ 如需调整：修改大纲 → 调整后续章节 → 发单章说明
→ 如不调整：书评区解释 → 坚持原设定
```

## 💪 心态管理

### 写作低谷期应对

| 情况 | 应对方法 |
|------|----------|
| **灵感枯竭** | 暂停 1-2 天，看存稿，不强行写 |
| **状态不好** | 降低目标 (2 章→1 章)，保证质量 |
| **读者批评** | 区分建设性/恶意，采纳前者，忽略后者 |
| **数据波动** | 关注长期趋势，不纠结短期波动 |
| **卡文** | 跳过卡点，写后续场景，回头补 |

### 防止 burnout

| 方法 | 说明 |
|------|------|
| **每周休息 1 天** | 周日不写作，完全放松 |
| **每月复盘** | 回顾进度，调整计划 |
| **运动锻炼** | 每天 30 分钟，保持身体状态 |
| **社交活动** | 每周至少 1 次线下社交 |
| **奖励机制** | 每完成 50 章，给自己一个小奖励 |
