### 场景重构 1：孟瑶的技术能力

**旧场景:**
```
孟瑶擅长整理笔记，帮助林砚。
```

**新场景:**
```
第 260 章：孟瑶的算法

"这个算法，我优化了 30%。"

孟瑶指着屏幕。

林砚愣住，"你......懂算法？"

"为什么不懂？"孟瑶笑，"女生就不能懂技术？"

"不是......"

"我自学了两年。"孟瑶说，"Python，机器学习，深度学习。"
"我都懂。"

"只是......没人问过。"

林砚沉默。

"以后，技术部分我来负责。"
"你负责业务。"

"好。"

不是"女生也能"。
是"人就能"。
```

---

### 场景重构 2：陈舟的独立决策

**旧场景:**
```
陈舟支持林砚的决定。
```

**新场景:**
```
第 400 章：陈舟的选择

"林砚，你的公司，我不去了。"

林砚愣住，"为什么？"

"不是因为你不好。"陈舟说，"是因为我要证明自己。"

"证明什么？"

"证明我不靠你。"
"证明我能自己去闯。"

林砚沉默。

"你生气吗？"陈舟问。

"不。"林砚说，"我尊重你的选择。"

"谢谢。"陈舟笑，"不是谁支持谁。"
"是各自成长，然后相遇。"

"好。"

"等我成功了，我们再合作。"

"好。"

不是依附。
是独立。

不是支持。
是共同成长。
```

| **顺从价值** | 顺从=美德 | 顺从=懒惰 |

---

### 场景重构：质疑不是叛逆

**旧场景:**
```
林砚听老师的话，不质疑。
```

**新场景:**
```
第 140 章：质疑的价值

"老师，这个解法不对。"

教室里，瞬间安静。

"我有另一种解法。"

老师愣住。

然后，笑了。

"你说。"

林砚走上讲台，写下解题步骤。

每一步都清晰明了。

老师看完，沉默。

然后，鼓掌。

"你说得对。"
"我错了。"

"质疑不是不尊重。"
"是尊重真理，胜过尊重权威。"

"以后，有问题就提。"
"不要盲从。"

"盲从是懒惰。"
"质疑是思考。"

教室里，掌声雷动。

这才是真正的教育。
```
