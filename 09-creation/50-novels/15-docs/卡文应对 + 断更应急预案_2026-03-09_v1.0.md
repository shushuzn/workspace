## 📋 卡文应对方案

### 卡文类型诊断

| 类型 | 症状 | 原因 | 解决方案 |
|------|------|------|----------|
| **情节卡** | 不知道写什么 | 大纲不清晰 | 回顾大纲，确认本章核心事件 |
| **文风卡** | 写出来不对味 | 文白比例失调 | 参考样章，找感觉 |
| **情感卡** | 情感戏写不好 | 共情不足 | 回忆自身经历，或跳过 |
| **专业卡** | 专业场景露怯 | 知识不足 | 查资料，或模糊处理 |
| **状态卡** | 就是不想写 | 身体/心理疲劳 | 休息，不强行写 |

---

### 卡文应对流程

```
第 1 步：诊断卡文类型
    ↓
第 2 步：选择对应解决方案
    ↓
第 3 步：执行解决方案
    ↓
第 4 步：还是卡？→ 跳过卡点，写后续
    ↓
第 5 步：标记卡点，回头补
```

---

### 具体解决方案

#### 情节卡

**症状:** 不知道本章写什么

**解决:**
1. 回顾大纲，确认本章核心事件
2. 问自己：本章爽点是什么？
3. 问自己：本章伏笔是什么？
4. 问自己：与前章如何衔接？
5. 还是不知道？→ 写人物对话推进

**示例:**
```
不知道写什么 → 回顾大纲 → 本章是"月考逆袭"
→ 爽点是"成绩公布" → 伏笔是"父亲收藏成绩单"
→ 与前章衔接"林砚备考" → 写"林砚查成绩"
```

---

#### 文风卡

**症状:** 写出来不对味，文白比例失调

**解决:**
1. 打开文白样章 (第 1 章/第 100 章)
2. 朗读样章，找语感
3. 检查对话是否全白话
4. 检查环境描写是否有文言韵味
5. 检查心理活动是否文白相间

**检查清单:**
- [ ] 对话是否自然 (全白话)
- [ ] 环境是否有意境 (可文言)
- [ ] 心理是否有深度 (文白相间)
- [ ] 是否过度文言 (影响阅读)
- [ ] 是否过度白话 (失去韵味)

---

#### 情感卡

**症状:** 情感戏写不好，共情不足

**解决:**
1. 回忆自身类似经历
2. 参考名场面详细设计
3. 写对话，少写心理
4. 用道具承载情感 (成绩单/茶杯)
5. 还是写不好？→ 跳过，回头补

**示例 (父子和解):**
```
不知道怎么写 → 回忆自己和父亲 → 想起父亲沉默的爱
→ 参考名场面设计 → 用"成绩单背后的字"承载
→ 写对话"这都留着干嘛""扔了可惜"
→ 情感自然流露
```

---

#### 专业卡

**症状:** 专业场景露怯，怕写错

**解决:**
1. 查基础资料 (维基百科/百度百科)
2. 模糊处理 (不写具体参数)
3. 用比喻 (像游戏里的 XX)
4. 问专业人士 (如有认识的人)
5. 还是不会？→ 跳过专业细节，写人物反应

**示例 (数据科学):**
```
不知道怎么写算法 → 模糊处理 → "陈舟敲下代码"
→ 用比喻 → "像搭积木一样，把数据模块组合"
→ 写人物反应 → "林砚看不懂，但觉得很厉害"
```

---

#### 状态卡

**症状:** 就是不想写，身体/心理疲劳

**解决:**
1. **立即停笔**，不强行写
2. 休息 30 分钟 - 1 天
3. 运动/散步/听音乐
4. 看存稿，找信心
5. 还是不想写？→ 请假 1 天，发单章说明

**预防:**
- 每周休息 1 天 (周日不写作)
- 每天运动 30 分钟
- 保证睡眠 (不熬夜写作)
- 每周至少 1 次线下社交

---

### 卡文急救包

**如果以上方法都无效，使用急救包:**

#### 急救 1: 写对话

```
不知道写什么 → 写人物对话

示例:
"作业写完了吗？"
"快了。"
"别骗我。"
"......"
```

**效果:** 对话容易写，且能推进情节

---

#### 急救 2: 写环境

```
不知道写什么 → 写环境描写

示例:
暮色四合，巷口路灯昏黄。
青石板路被露水打湿，反射着光。
```

**效果:** 环境描写容易写，且能烘托氛围

---

#### 急救 3: 写心理

```
不知道写什么 → 写人物心理

示例:
林砚心中烦躁。
明明知道该学习了，可就是提不起劲。
```

**效果:** 心理描写容易写，且能展现人物

---

#### 急救 4: 跳过卡点

```
还是写不出来 → 跳过，写后续

示例:
第 50 章卡住了 → 写第 51 章
→ 第 50 章标记"[待补]"
→ 写完第 51 章，回头补第 50 章
```

**效果:** 保证进度，回头补质量更高

## 📋 断更应急预案

### 断更预防措施

| 措施 | 说明 | 执行方式 |
|------|------|----------|
| **存稿缓冲** | 保持 20 章存稿 | 周末补稿 |
| **提前写作** | 状态好时多写 | 每日目标 2 章，状态好写 3 章 |
| **规律作息** | 不熬夜写作 | 每晚 23:00 前睡觉 |
| **健康第一** | 生病立即休息 | 不强行写作 |

---

### 断更分级应对

| 级别 | 断更时长 | 应对措施 | 公告模板 |
|------|----------|----------|----------|
| **一级** | 1 天 | 正常更新，不公告 | 无 |
| **二级** | 2-3 天 | 发单章说明 | "临时有事，明天补上" |
| **三级** | 4-7 天 | 发单章 + 补偿 | "生病/有事，周末爆更补偿" |
| **四级** | 7 天 + | 发单章 + 详细计划 | "长期断更说明 + 复更计划" |

---

### 断更公告模板

#### 模板 1: 短期断更 (2-3 天)

```
【断更说明】

各位书友，临时有点事，今天断更一天。

明天补上，抱歉。

——杉树之南
```

---

#### 模板 2: 中期断更 (4-7 天)

```
【断更说明 + 补偿】

各位书友，因为 [生病/家里有事]，需要断更几天。

预计 [X 月 X 日] 恢复更新。

补偿方案：恢复后一周内，每日 3 章爆更。

抱歉，感谢理解。

——杉树之南
```

---

#### 模板 3: 长期断更 (7 天+)

```
【长期断更说明 + 复更计划】

各位书友，因为 [具体原因]，需要长期断更一段时间。

预计 [X 月 X 日] 恢复更新。

复更计划：
1. 恢复后每日 2 章，保证稳定
2. 存稿补到 20 章后再开书
3. 绝不烂尾，请放心

抱歉，感谢理解。

——杉树之南
```

---

### 断更补偿方案

| 断更时长 | 补偿方案 | 说明 |
|----------|----------|------|
| 2-3 天 | 次日补更 | 断 1 补 1 |
| 4-7 天 | 一周内爆更 | 每日 3 章，持续一周 |
| 7 天 + | 番外/加更 | 写番外或加更补偿 |

## 📋 负面评价处理

### 评价分类

| 类型 | 特征 | 处理方式 |
|------|------|----------|
| **建设性** | 指出具体问题，有建议 | 采纳，感谢，修改 |
| **主观喜好** | "我不喜欢 XX" | 尊重，不争论 |
| **恶意攻击** | 人身攻击，无具体内容 | 忽略，拉黑 |
| **剧透党** | "后面 XX 情节不好" | 感谢，不剧透 |
| **催更党** | "怎么还不更新" | 理解，说明情况 |

---

### 处理流程

```
第 1 步：判断评价类型
    ↓
第 2 步：选择处理方式
    ↓
第 3 步：执行处理
    ↓
第 4 步：调整心态
```

### 回复模板

#### 回复 1: 建设性评价

```
感谢书友的建議！

[具体问题] 我会在后续章节改进。

欢迎继续监督！

——杉树之南
```

---

#### 回复 2: 主观喜好

```
感谢书友的反馈！

每个人喜好不同，我尽量平衡。

如有具体建议，欢迎提出！

——杉树之南
```

---

#### 回复 3: 催更

```
感谢书友支持！

每日 2 章稳定更新，特殊情况会公告。

请理解，保证质量更重要！

——杉树之南
```

---

### 心态调整

**被负面评价影响时:**

1. **深呼吸**，不要立即回复
2. **区分类型**，建设性采纳，恶意忽略
3. **看正面评价**，找信心
4. **休息 30 分钟**，平复心情
5. **继续写作**，用作品说话

**记住:**
- 不可能让所有人满意
- 负面评价是常态，正面评价是惊喜
- 用作品说话，不是用嘴辩解
