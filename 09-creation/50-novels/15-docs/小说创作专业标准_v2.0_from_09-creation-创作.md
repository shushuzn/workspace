# 📝 小说创作专业标准 v2.0 (提高版)

**创建日期:** 2026-03-10  
**版本:** v2.0 (专业提高版)  
**状态:** 标准制定

---

## 🎯 核心原则

### 1. 展示而非告知 (Show, Don't Tell)

#### ❌ 告知 (低级)
```
他很紧张。
```

#### ✅ 展示 (高级)
```
林砚手心出汗，在裤子上擦了擦。喉咙发干，他咽了咽口水，却发现连吞咽都变得困难。讲台上，老师的目光扫过来，他立刻低下头，盯着课桌上那道划痕——那是上周走神时用圆规刻的。

"林砚，你来回答。"

他站起来，椅子腿和地面摩擦出刺耳的声音。全班目光聚焦，他能感觉到自己的心跳在加速，一下，两下，越来越快。

"我......"声音卡在喉咙里。
```

**规则:** 永远不用形容词直接描述情绪，用身体反应、动作、细节展示。

---

### 2. 对话必须有目的

#### ❌ 无效对话
```
"来了？"
"嗯。"
"坐。"
"好。"
```

#### ✅ 有效对话
```
"你今天迟到了三分钟。"陈舟没抬头，笔尖在草稿纸上飞快移动。

林砚拉开椅子："闹钟没响。"

"这是本周第三次。"她终于抬起头，推了推眼镜，"华夏大学的自主招生，还有 180 天。你觉得你的闹钟，会因为你紧张就响吗？"

林砚沉默了。

陈舟把一张写满公式的纸推到他面前："昨晚我整理了错题本，你看看。"

"你......每天都几点睡？"

"两点。"她顿了顿，"比你多三个小时。所以，你打算怎么追？"
```

**规则:** 每段对话必须推进以下至少一项：
- 情节发展
- 人物关系
- 角色性格
- 埋下伏笔

---

### 3. 场景必须有五感

#### ❌ 单感官
```
图书馆里很安静。
```

#### ✅ 五感俱全
```
图书馆里弥漫着旧书特有的霉味，混合着隔壁女生桌上的柑橘味护手霜。

林砚翻动书页，纸张摩擦的沙沙声在寂静中被放大。隔壁传来轻微的咳嗽声，压抑着，闷闷的。

空调出风口呼呼作响，冷风扫过他的后颈，他缩了缩脖子。

窗外的蝉鸣断断续续，像是随时会断气。

他舔了舔干裂的嘴唇，尝到了早上喝的咖啡的苦味。
```

**规则:** 每个重要场景至少包含 3 种感官描写（视觉/听觉/嗅觉/触觉/味觉）。

---

### 4. 人物必须有独特声音

#### ❌ 所有人说话一样
```
"你好。"
"你好。"
"学习吗？"
"学习。"
```

#### ✅ 不同角色不同说话方式
```
**林砚 (沉稳内敛)**
- 短句为主
- 少用感叹号
- 习惯先思考再回答

"嗯。"
"可能吧。"
"我想想。"

**江越 (阳光外向)**
- 长句，爱用感叹号
- 喜欢拍肩膀
- 说话带玩笑

"兄弟！今天怎么来这么晚？"
"我跟你说，昨天那题我有个更简单的解法！"
"怕什么？有哥在！"

**陈舟 (冷静理性)**
- 精准，不带情绪
- 喜欢用数据
- 直接，不拐弯

"你迟到了三分钟。"
"145 分，比你高 27 分。"
"效率太低，你的方法有问题。"

**王雨薇 (温柔坚定)**
- 语气温和
- 善于倾听
- 关键时刻坚定

"没关系，慢慢来。"
"我相信你可以的。"
"但是，这件事你不能放弃。"
```

**规则:** 遮住角色名字，读者应该能分辨出是谁在说话。

---

### 5. 节奏必须有张有弛

#### ❌ 平铺直叙
```
早上起床。
去学校。
上课。
放学。
写作业。
睡觉。
```

#### ✅ 张弛有度
```
**紧张场景 (短句，快节奏)**
铃声响起。

林砚手心出汗。

试卷发下来。

第一题，不会。

第二题，还是不会。

心跳加速。一下，两下。

时间一分一秒流逝。

**舒缓场景 (长句，慢节奏)**
夕阳从窗外斜射进来，在课桌上投下斑驳的光影。林砚靠在椅背上，看着空气中飞舞的尘埃，一粒，两粒，无数粒，像是夜空中的繁星，缓慢地，优雅地，跳着无声的舞蹈。

窗外传来篮球撞击地面的声音，咚，咚，咚，不紧不慢，像是某种古老的节拍器，记录着这个平凡下午的每一秒。
```

**规则:** 紧张场景用短句 (5-15 字)，舒缓场景用长句 (30-60 字)，交替使用。

## 🔧 高级写作技巧

### 1. 伏笔与呼应

#### 伏笔 (第 81 章)
```
陈舟转学第一天，坐在林砚旁边。她打开书包，里面除了一本崭新的笔记本，还有一张皱巴巴的照片。

照片上是一个穿校服的男生，站在华夏大学校门口，笑得很灿烂。

林砚瞥了一眼，没问。
```

#### 呼应 (第 150 章)
```
"那是你哥哥？"林砚指着照片。

陈舟沉默了很久，久到林砚以为她不会回答。

"嗯。"她终于开口，声音很轻，"三年前，他站在这里，说要在华夏大学等我。"

"现在呢？"

"现在......"她抬起头，眼眶微红，"现在换我来兑现承诺。"
```

**规则:** 重要伏笔必须在 50 章内呼应，否则删除。

---

### 2. 冲突升级

#### 第一层：内部冲突
```
林砚盯着试卷上的 45 分，手心出汗。

"我真的行吗？"他问自己。
```

#### 第二层：人际冲突
```
"45 分？"父亲把试卷摔在桌上，"你让我在同事面前怎么抬头？"

林砚低下头，没说话。
```

#### 第三层：环境冲突
```
"今年高考改革，难度增加 30%。"班主任的话在教室里回荡，"你们这届，是地狱模式。"

教室里一片死寂。
```

#### 第四层：命运冲突
```
医生摘下口罩："先天性心脏病，不能剧烈运动，不能熬夜，不能......"

"不能高考？"林砚问。

医生沉默了。
```

**规则:** 每 10 章一个小冲突升级，每 50 章一个大冲突升级。

---

### 3. 细节象征

#### ❌ 直白
```
他们关系变好了。
```

#### ✅ 象征
```
陈舟把柑橘味护手霜放在桌子中间。

"你用吧。"她说。

林砚看了看护手霜，又看了看她。

"我不喜欢柑橘味。"

"我知道。"陈舟低头做题，"但它能提神。"

林砚拿起护手霜，挤了一点在手上。柑橘的清香在空气中弥漫开来，他闻了闻，其实，也没那么难闻。

第二天，他买了一管同样的护手霜，放在桌子中间。

陈舟瞥了一眼，嘴角微扬，没说话。
```

**规则:** 用具体物品象征抽象关系，避免直白陈述。

---

### 4. 留白艺术

#### ❌ 说得太满
```
林砚很感动，他决定一定要考上华夏大学，不辜负陈舟的期望，不辜负母亲的支持，不辜负老师的信任。
```

#### ✅ 适当留白
```
林砚看着陈舟的背影，很久。

"为什么？"他问。

陈舟没回头："因为......"

话没说完，她挥了挥手，消失在走廊尽头。

林砚低下头，看着桌上的错题本。封面上，陈舟的字迹清秀有力："一起加油。"

他合上错题本，放进书包最外层。

明天，早点去图书馆。
```

**规则:** 关键情感不要说破，让读者自己体会。

## 📊 严格评分标准 (100 分制)

### 对话质量 (35 分)
| 分数 | 标准 |
|------|------|
| **31-35** | 对话自然，个性鲜明，每段都有目的，有潜台词 |
| **26-30** | 对话自然，有个性区分，大部分有目的 |
| **21-25** | 对话基本自然，个性区分不明显 |
| **16-20** | 对话生硬，缺乏个性 |
| **0-15** | 对话严重 AI 化，无目的 |

### 场景描写 (30 分)
| 分数 | 标准 |
|------|------|
| **27-30** | 五感俱全，细节丰富，有象征意义 |
| **21-26** | 三种以上感官，细节充足 |
| **16-20** | 两种感官，基本细节 |
| **11-15** | 单一感官，缺乏细节 |
| **0-10** | 无感官描写，纯叙述 |

### 心理描写 (20 分)
| 分数 | 标准 |
|------|------|
| **18-20** | 身体反应 + 内心独白 + 对比反差，层次丰富 |
| **14-17** | 两种以上描写方式 |
| **10-13** | 基本心理描写 |
| **6-9** | 直白情感陈述 |
| **0-5** | 无心理描写 |

### 章节结构 (10 分)
| 分数 | 标准 |
|------|------|
| **9-10** | 开头悬念 + 发展冲突 + 高潮突破 + 结尾伏笔，完美 |
| **7-8** | 结构完整，有悬念和伏笔 |
| **5-6** | 基本结构完整 |
| **3-4** | 结构不完整 |
| **0-2** | 无结构 |

### AI 规避 (5 分)
| 分数 | 标准 |
|------|------|
| **5** | 无重复句式，无直白情感，无 AI 痕迹 |
| **4** | 轻微 AI 痕迹 |
| **3** | 明显 AI 痕迹 |
| **0-2** | 严重 AI 化 |

## 🎯 发布标准

### 必须达到 85 分以上才能发布

| 等级 | 分数 | 处理方式 |
|------|------|----------|
| **S 级** | 95-100 | 直接发布，作为范文 |
| **A 级** | 85-94 | 小修后发布 |
| **B 级** | 70-84 | 大修后重新审核 |
| **C 级** | 60-69 | 重写 |
| **D 级** | 0-59 | 删除，重新创作 |

---

## 📋 审核流程

### 第一步：自我审核 (创作后立即)
- 按照评分标准自评
- 标记需要修改的地方
- 记录分数

### 第二步：冷却 (至少 1 小时)
- 离开作品，做其他事
- 让大脑重置

### 第三步：二次审核 (冷却后)
- 重新阅读
- 二次评分
- 确认修改

### 第四步：朗读审核
- 大声朗读全文
- 检查对话流畅度
- 标记拗口地方

### 第五步：最终确认
- 确认分数≥85 分
- 确认无 AI 痕迹
- 提交发布

## 🚫 零容忍清单 (出现即重写)

1. **连续 3 次以上"那眼神，很复杂"**
2. **连续 5 次以上"嗯。"单独成段**
3. **直白情感陈述 ("他很难过"/"她很高兴")**
4. **无目的对话 (纯寒暄)**
5. **单一场景超过 1000 字无变化**
6. **所有人说话方式一样**
7. **无五感描写的场景**
8. **平铺直叙无节奏变化**
