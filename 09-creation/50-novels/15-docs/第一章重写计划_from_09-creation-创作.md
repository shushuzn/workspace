## 📊 v3.0 标准检查清单

### 文字精炼度 (25 分)
- [ ] 无一字冗余
- [ ] 每字都有意义
- [ ] 删除所有"慢慢地"、"非常"、"真的"等

### 画面感 (25 分)
- [ ] 每句话都有画面
- [ ] 电影级描写
- [ ] 五感俱全 (视觉/听觉/嗅觉/触觉/味觉)

### 节奏韵律 (20 分)
- [ ] 每段都有节奏
- [ ] 短句 + 长句交替
- [ ] 诗一般的韵律

### 情感深度 (20 分)
- [ ] 情感克制而深刻
- [ ] 用动作代替直白
- [ ] 让读者自己体会

### 结构完整 (10 分)
- [ ] 开头悬念
- [ ] 发展冲突
- [ ] 高潮突破
- [ ] 结尾伏笔

## 🔧 重写策略

### 1. 开篇 (500 字)
**目标:** 制造悬念，建立画面

**原稿:**
```
"林砚，45 分。"
老师念出分数的时候停了一下。
```

**重写:**
```
后门在身后关上，咔哒一声。

林砚站在门口，看着教室。

高三 (1) 班。

黑板右上角，红色粉笔写着：距离高考 180 天。

180。

他默念这个数字，像是念某种咒语。

走向座位，第三排靠窗。路过陈舟的座位时，他停顿了一下。

空的。

她还没来。

拉开椅子，坐下。书包放在桌上，不轻不重，刚好。

书本翻开，第 1 页。新的学期，新的开始。

也是......最后的冲刺。
```

### 2. 发试卷 (800 字)
**目标:** 展示情感，克制表达

**原稿:**
```
他很紧张。
手心出汗。
```

**重写:**
```
试卷发下来了。

林砚看着那个数字。

45。

红色墨水，很大，很刺眼。像是某种嘲讽。

他舔了舔嘴唇，尝到了早上喝的咖啡的苦味。

手心在出汗。他在裤子上擦了擦，又擦，还是湿的。

"林砚，45 分。"老师的声音从讲台上飘过来，"下次努力。"

下次。

还有几次下次？

180 天，5 次月考，3 次模拟，1 次高考。

他折好试卷，放进书包最里层。

那是他最不想面对，却又必须面对的东西。
```

## 📖 重写流程

### 第一步：通读原稿 (10 分钟)
- 理解原稿内容
- 标记需要修改的地方

### 第二步：逐段重写 (60 分钟)
- 按照 v3.0 标准
- 每段都检查五感
- 每句都检查节奏

### 第三步：朗读审核 (15 分钟)
- 大声朗读全文
- 标记拗口地方
- 检查节奏韵律

### 第四步：冷却 (30 分钟)
- 离开作品
- 做其他事情
- 让大脑重置

### 第五步：二次审核 (15 分钟)
- 重新阅读
- 按照 100 分制评分
- 确认≥90 分

### 第六步：提交 (5 分钟)
- Git 提交
- 写 commit message
- 推送

**总耗时:** 约 2 小时
