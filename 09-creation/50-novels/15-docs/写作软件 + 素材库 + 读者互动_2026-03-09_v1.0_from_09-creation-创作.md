## 💻 写作软件推荐

### 电脑端写作软件

#### 1. Word / WPS (传统推荐)

| 项目 | 说明 |
|------|------|
| **优点** | 功能强大，格式丰富，兼容性好 |
| **缺点** | 付费 (WPS 有免费版)，云同步需付费 |
| **适合** | 习惯传统写作的作者 |
| **价格** | Word: ¥398/年 WPS: 免费/¥89/年会员 |

**推荐配置:**
- 开启自动保存 (每 5 分钟)
- 开启云同步 (OneDrive/WPS 云)
- 使用大纲视图 (方便章节管理)

---

#### 2. Scrivener (专业写作)

| 项目 | 说明 |
|------|------|
| **优点** | 专为长篇设计，卡片管理，研究资料整合 |
| **缺点** | 付费，学习曲线陡 |
| **适合** | 专业作家，长篇创作 |
| **价格** | $49.99 (一次性) |

**特色功能:**
- 卡片式章节管理
- 研究资料整合
- 写作目标设定
- 导出多种格式

---

#### 3. 纯纯写作 (国产推荐)

| 项目 | 说明 |
|------|------|
| **优点** | 国产，便宜，功能齐全，云同步 |
| **缺点** | 知名度低 |
| **适合** | 网文作者 |
| **价格** | ¥68 (一次性) |

**特色功能:**
- 字数统计
- 写作目标
- 云同步
- 章节管理

---

#### 4. 作家助手 (起点官方)

| 项目 | 说明 |
|------|------|
| **优点** | 官方，直接发布，数据查看 |
| **缺点** | 功能简单，只能写起点 |
| **适合** | 起点作者 |
| **价格** | 免费 |

**特色功能:**
- 直接发布章节
- 查看数据 (收藏/订阅/推荐票)
- 回复评论
- 合同管理

### 互动策略

#### 策略 1: 书评区回复

**原则:**
- 每日回复 (至少 10 条)
- 回复建设性评论
- 忽略恶意攻击
- 感谢支持

**回复模板:**
```
感谢书友支持！
[具体问题] 我会在后续章节改进。
欢迎继续监督！
——杉树之南
```

---

#### 策略 2: 章说互动

**原则:**
- 选择有趣章说回复
- 剧透不回复
- 恶意不回复
- 感谢支持

**回复示例:**
```
书友说得对！
这里确实需要改进。
后面会解释，敬请期待！
```

---

#### 策略 3: 读者群运营

**原则:**
- 适度互动 (每日 1 小时)
- 不剧透
- 不承诺
- 感谢支持

**群活动:**
- 每周一次群聊
- 角色命名活动
- 剧情讨论
- 番外征集

---

#### 策略 4: 单章互动

**原则:**
- 偶尔发单章
- 说明情况
- 感谢支持
- 不频繁

**单章类型:**
- 请假单章
- 感谢单章
-  milestone 单章 (收藏破万等)
- 完本单章
