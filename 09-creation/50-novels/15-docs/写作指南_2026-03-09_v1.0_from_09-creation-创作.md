### 人物缺陷 (增加共情点)

| 缺陷 | 说明 | 体现方式 | 爆发章节 |
|------|------|----------|----------|

| **老城区/高新区** | 城区 | 虚构 |

| **江南大学** | 高校 | 虚构 |

**原则:** 所有地名均为虚构，如有雷同纯属巧合

### 时代原则 (模糊年份)

| 元素 | 处理方式 | 示例 |
|------|----------|------|
| **时间** | 用季节/时辰，不用年份 | "春日"/"暮色"而非"2020 年 3 月" |
| **科技** | 用功能描述，不用产品名 | "通讯工具"而非"手机" |
| **制度** | 用本质描述，不用具体名 | "升学考核"而非"高考" |
| **职业** | 用通用名，不用具体职位 | "技工/教师"而非"工程师/教授" |

### 伏笔三原则

| 原则 | 说明 | 示例 |
|------|------|------|
| **隐蔽性** | 伏笔像生活细节，不像设计 | 拇指滑动动作，读者第一次看觉得正常 |
| **多义性** | 一个伏笔多个解读，不单一 | 茶杯=师道/念旧/时间 |
| **情感性** | 绑定情感记忆，非事件对应 | 炸串=回忆非怀旧 |

### 伏笔禁忌

| 禁忌 | 说明 | 避免方法 |
|------|------|----------|
| 太明显 | 读者一眼看穿 | 融入日常细节 |
| 回收太刻意 | 为回收而回收 | 水到渠成，不刻意呼应 |
| 寓意点明 | 说教式点明 | 让读者自己体会 |
| 只埋不收 | 读者失望 | 建立伏笔追踪表 |

## 📝 写作风格

### 文体风格

| 项目 | 设定 |
|------|------|
| **整体风格** | 文白相融，文言写意，白话叙事 |
| **文白比例** | 七分白话，三分文言 |
| **环境描写** | 40% 文言 (烘托意境) |
| **心理活动** | 40% 文言 (内心独白) |
| **对话** | 10% 文言 (符合身份) |
| **动作描写** | 10% 文言 (简洁有力) |
| **核心金句** | 80% 文言 (点题升华) |

### 文白相融技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| 文言点题，白话展开 | 金句文言，解释白话 | "学贵有恒。"苏秉文说，"不是一时兴起，而是日日坚持。" |
| 环境文言，叙事白话 | 环境烘托用文言 | 暮色四合，巷口路灯昏黄，将林砚的影子拉得老长。 |
| 心理文言，动作白话 | 内心活动用文言 | 林砚心中郁结，自忖资质愚钝。他盯着试卷，拳头握紧。 |
| 对话依身份，旁白有韵味 | 对话符合身份 | "林砚，作业写完了吗？"陈舟问道。林砚支吾不语。 |

### 写作禁忌

| 禁忌 | 说明 | 示例 |
|------|------|------|
| 过度文言 | 影响阅读 | ❌"砚行于巷，心甚戚" ✅"林砚走在巷子里，心中失落" |
| 过度白话 | 失去韵味 | ❌"林砚很不开心" ✅"林砚心中郁结" |
| 对话文言化 | 不符合身份 | ❌"汝作业可完？" ✅"作业写完了吗？" |
| 时代错乱 | 现代场景用古代用语 | ❌"飞鸽传书" ✅"发消息" |
| 风格不统一 | 同一段落风格跳跃 | ❌"暮色四合，他心里超级郁闷" ✅"暮色四合，心中郁结" |
