## ✅ 写作检查清单

### 基础检查
- [ ] 字数达标 (5000±500)
- [ ] 章节标题对仗工整
- [ ] 文白比例合理 (7:3 或 8:2)
- [ ] 无明显错别字
- [ ] 时代背景准确 (无真实地名)

### 爽点检查
- [ ] 本章有爽点/吸引点
- [ ] 距离上次爽点不超过 3 章
- [ ] 爽点类型明确 (逆袭/成长/认可等)
- [ ] 爽点前有压抑铺垫

### 伏笔检查
- [ ] 本章植入了什么伏笔 (1-2 个)
- [ ] 本章回收了什么伏笔 (如有)
- [ ] 伏笔是否隐蔽 (不刻意)
- [ ] 伏笔追踪表已更新

### 引用检查
- [ ] 引用是否自然融入
- [ ] 是否点明出处 (❌ 不应点明)
- [ ] 是否解释含义 (❌ 不应解释)
- [ ] 是否刻意 (❌ 应随口而出)

### 主角缺陷检查
- [ ] 本章是否体现主角缺陷
- [ ] 缺陷是否自然 (不刻意)
- [ ] 缺陷是否服务于情节

### 陈舟独立设定检查
- [ ] 陈舟是否有独立目标/行动
- [ ] 陈舟是否不是依附角色
- [ ] 陈舟是否有独立困境/成长

### 文风检查
- [ ] 对话是否符合人物身份
- [ ] 环境描写是否有意境
- [ ] 心理描写是否有深度
- [ ] 风格是否与样章一致

## 📊 使用说明

### 写作流程

1. **复制模板** → 新建文件，粘贴模板
2. **填写概要** → 明确本章核心事件/爽点/伏笔
3. **按结构写作** → 开场→发展→高潮→收尾
4. **填写检查清单** → 逐项检查
5. **修订完善** → v0.1→v0.2→v0.3→v1.0
6. **保存归档** → 按命名规范保存

### 文件命名

```
草稿：DRAFT_卷 X_第 X 章_标题_日期_v0.X.md
定稿：FINAL_卷 X_第 X 章_标题_日期_v1.0.md
```

### 版本说明

| 版本 | 状态 | 说明 |
|------|------|------|
| **v0.1** | 初稿 | 完成基本情节 |
| **v0.2** | 二稿 | 补充细节描写 |
| **v0.3** | 三稿 | 优化对话与节奏 |
| **v1.0** | 定稿 | 通过所有检查，可发布 |

## 🎯 写作技巧

### 开场技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| **环境切入** | 以环境描写开场 | "暮色四合，巷口路灯昏黄" |
| **动作切入** | 以人物动作开场 | "林砚盯着手机屏幕，手指飞快滑动" |
| **对话切入** | 以对话开场 | "'林砚，作业写完了吗？'陈舟问道" |
| **心理切入** | 以心理活动开场 | "林砚心中烦躁，明明知道该学习了" |

### 发展技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| **冲突升级** | 逐步加大冲突强度 | 从口头争执到行动对抗 |
| **多线并进** | 主线 + 副线同时推进 | 学习线 + 感情线 |
| **人物互动** | 通过对话展现关系 | 林砚与陈舟的对话 |
| **细节描写** | 用细节增强画面感 | "拇指不自觉滑动" |

### 高潮技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| **情绪顶点** | 让人物情绪达到顶点 | "林砚终于爆发了" |
| **关键抉择** | 让人物面临重要选择 | "去玩游戏，还是学习？" |
| **冲突爆发** | 矛盾集中爆发 | "团队背叛" |
| **节奏加快** | 用短句加快节奏 | "跑。不停地跑。" |

### 收尾技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| **事件结果** | 交代事件结果 | "月考成绩公布，林砚中游" |
| **人物成长** | 展现人物成长 | "林砚终于明白了" |
| **下章伏笔** | 为下章埋下伏笔 | "巷口，一个身影看着他" |
| **余韵悠长** | 留有余韵 | "月光很好，照在两个人身上" |

## 📋 常见问题

### Q1: 写不够 5000 字怎么办？

**A:** 
1. 增加环境描写 (增加 200-300 字)
2. 增加心理描写 (增加 300-500 字)
3. 增加对话细节 (增加 500-800 字)
4. 增加伏笔/小巧思 (增加 200-300 字)

### Q2: 写超了怎么办？

**A:**
1. 删减冗余环境描写
2. 精简对话 (去掉废话)
3. 合并相似场景
4. 拆分到下一章

### Q3: 卡文怎么办？

**A:**
1. 跳过卡点，写后续场景
2. 回顾大纲，确认本章核心事件
3. 参考样章，找文风感觉
4. 休息 30 分钟，再回来写

### Q4: 文白比例把握不好怎么办？

**A:**
1. 参考文白样章 (第 1 章/第 100 章)
2. 对话始终用白话
3. 环境描写可用文言
4. 心理活动文白相间
