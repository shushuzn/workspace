---

#### 关键场景

**第 120 章：农村出身的自卑**
```
陈舟问："孟瑶，你周末怎么不回家？"
孟瑶低头，"太远，车费贵。"
林砚没说话，但记住了。

周末，林砚说："我家近，一起去吧。"
孟瑶："不用了......"
"走吧。"林砚说，"我爸妈说多个人热闹。"

孟瑶眼眶湿润，"谢谢。"
```

**第 400 章：独立决策**
```
林砚："来我公司吧，给你最好的待遇。"
孟瑶摇头，"我想自己去闯闯。"
林砚愣住，"为什么？"
"因为......"孟瑶说，"我想证明自己，不靠任何人。"

林砚笑，"好，我等你。"
```

**第 550 章：职场性别歧视**
```
面试官："女性不适合做技术。"
孟瑶站起来，"适不适合，做了才知道。"
"给我一个月，我证明给你看。"

一个月后，孟瑶完成项目。
面试官："你赢了。"
孟瑶："不是赢，是证明。"
```

**第 800 章：回归公益**
```
林砚："来帮我吧。"
孟瑶："为什么找我？"
"因为......"林砚说，"你懂那些孩子的苦。"
孟瑶沉默，"好，我来。"

"不为别的，为当年的自己。"
```

"好。"林砚说，"一起干。"
