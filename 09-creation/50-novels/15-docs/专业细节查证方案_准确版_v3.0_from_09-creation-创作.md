## 📊 核心原则

### 不模糊，写准确

| 维度 | 旧方案 (模糊) | 新方案 (准确) |
|------|--------------|--------------|
| **参数** | ❌ "效率很高" | ✅ "时间复杂度 O(nlogn)" |
| **数据** | ❌ "效果很好" | ✅ "准确率 97.3%" |
| **金额** | ❌ "融资一笔钱" | ✅ "融资 500 万，出让 10% 股份" |
| **态度** | ❌ 模糊处理 | ✅ 查证准确，写具体 |

**原则:**
- ✅ 查证准确，写具体细节
- ✅ 不确定的，查证后再写
- ✅ 不模糊，不糊弄读者

## 📋 查证流程

### 写作前

```
1. 列出本章涉及的专业内容
2. 确定查证来源 (书籍/知乎/实际体验)
3. 查证并记录具体数据/参数/流程
4. 确认理解正确
```

### 写作中

```
1. 使用查证的具体数据/参数
2. 不确定的地方，停下查证
3. 不糊弄，不模糊
```

### 写作后

```
1. 检查专业内容是否准确
2. 如有错误，立即修正
3. 记录查证来源 (备查)
```

## 🎯 写作原则

### 三不写

| 原则 | 说明 | 示例 |
|------|------|------|
| **不确定的不写** | 查证后再写 | 不凭印象写 |
| **一知半解的不写** | 理解了再写 | 不装懂 |
| **过时的不写** | 查证最新版本 | 不写旧数据 |

### 三要写

| 原则 | 说明 | 示例 |
|------|------|------|
| **要具体** | 写具体数据/参数 | "准确率 94.7%" |
| **要准确** | 查证后写 | 不凭印象 |
| **要专业** | 用专业术语 | "XGBoost""PID 控制" |
