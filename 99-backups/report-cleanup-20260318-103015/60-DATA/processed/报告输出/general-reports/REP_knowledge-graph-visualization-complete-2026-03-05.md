### 2. 功能说明

#### 🖱️ 交互操作

| 操作 | 效果 |
|------|------|
| **左键拖拽节点** | 移动节点位置 |
| **滚轮缩放** | 放大/缩小图谱 |
| **右键拖拽** | 平移画布 |
| **点击节点** | 高亮显示 + 详情 |
| **鼠标悬停** | 显示工具提示 |

#### 🔍 搜索

- 在搜索框输入关键词
- 实时过滤实体列表
- 点击列表项定位到节点

#### 📊 过滤

- 点击类型按钮过滤显示
- 支持：全部/论文/概念/作者/机构
- 过滤后其他节点变淡
