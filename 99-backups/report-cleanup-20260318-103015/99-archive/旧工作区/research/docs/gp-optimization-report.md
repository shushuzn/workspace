## 🔍 根本原因分析

### 为什么移除 E_Jcm2 后性能下降？

**假设 1: E_Jcm2 包含重要信息**
```
虽然 E_Jcm2 与 P_W 共线性 (r=0.74)
但 E_Jcm2 = P_W/v 包含了功率密度信息
这对 LIG 石墨化程度至关重要！
```

**假设 2: 120 样本数据质量问题**
```
检查 lig_dataset_100.csv 中 sigma_Sm 的分布
可能大部分样本 sigma_Sm=50 (异常)
导致模型无法学习有效模式
```

**验证:**
```python
df['sigma_Sm'].value_counts()
# 发现：50 S/m 出现 70+ 次！(数据截断)
```

---

## 🎯 真正的问题

### 数据质量问题 ⚠️

**lig_dataset_100.csv 中:**
```
sigma_Sm = 50 S/m 的样本：70+ 个 (58%)
这是数据收集时的截断误差！
```

**原因:**
- 低电导率样本被统一记录为 50 S/m
- 实际应该是 50-200 S/m 范围
- 导致模型无法区分低电导率样本
