## 🚀 新技能使用方法

### 1. free-ride (免费 AI 模型管理)

**用途:** 管理和使用免费 AI 模型

**示例:**
```bash
# 列出可用模型
free-ride list

# 使用模型
free-ride use --model <model_name>
```

### 2. api-gateway (连接 100+ APIs)

**用途:** 统一访问各种 API 服务

**示例:**
```bash
# 列出可用 API
api-gateway list

# 调用 API
api-gateway call --service <service_name> --endpoint <endpoint>
```

### 3. humanizer (去除 AI 写作痕迹)

**用途:** 优化 AI 生成文本，使其更自然

**示例:**
```bash
# 优化文本
humanizer optimize --input "AI 生成的文本" --output "humanized.txt"

# 检查 AI 痕迹
humanizer check --input "text.txt"
```
