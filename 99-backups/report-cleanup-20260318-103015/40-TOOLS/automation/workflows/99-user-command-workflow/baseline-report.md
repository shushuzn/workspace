### 1. 确认环节过多

- **影响:** 增加对话轮次 40%
- **示例:** todo-037 确认 3 次 (方案/格式/提交)

### 2. 任务拆解不足
- **现状:** 复杂任务未自动拆分
- **影响:** 中途返工率高 (复杂任务 100%)
- **示例:** todo-036 执行到一半发现缺少 Docker 配置

### 3. 验收标准模糊
- **现状:** 60% 任务验收标准不可量化
- **影响:** 完成后需要补充修改
- **示例:** "优化工作流" → 未定义具体优化指标

### 4. 进度不透明
- **现状:** 70% 任务无中间进度汇报
- **影响:** 用户不知道执行状态
- **示例:** todo-034 执行 60 分钟，用户中途询问 3 次进度

### 5. 输出格式冗长
- **现状:** 简单任务也使用完整格式
- **影响:** 增加阅读负担
- **示例:** "创建文件"任务输出 500 字格式文本
