## ⚠️ 已知问题

### 问题 1: 复杂公式识别

**现象:** 多行公式/矩阵识别准确率下降 (~75%)  
**原因:** pix2tex 模型训练数据偏差  
**影响:** 低 (仅影响复杂公式)  
**解决:** 微调模型或使用商业 API

---

### 问题 2: 低质量图表提取

**现象:** 低分辨率图表分类错误 (~15%)  
**原因:** 图像质量影响 CLIP 嵌入  
**影响:** 中 (影响搜索准确率)  
**解决:** 添加质量过滤阈值

---

### 问题 3: 大数据集存储

**现象:** >1000 个图表时加载时间 >5 秒  
**原因:** 前端渲染性能瓶颈  
**影响:** 中 (影响用户体验)  
**解决:** 分页加载 + 虚拟滚动
