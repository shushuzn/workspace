## 🔧 使用流程

1. **打开工具** → 自动加载示例图谱
2. **选择格式** → PNG 或 SVG
3. **选择分辨率** → 1x/2x/3x/4x
4. **选择背景** → 白色/透明/渐变
5. **勾选选项** → 图例/标题/统计
6. **点击导出** → 自动下载文件

## ⚠️ 注意事项

1. **浏览器兼容性**
   - ✅ Edge/Chrome (推荐)
   - ✅ Firefox
   - ⚠️ Safari (部分功能受限)

2. **大图谱性能**
   - 100+ 节点：建议使用 1x/2x 分辨率
   - 4x 分辨率可能导致浏览器卡顿

3. **透明背景**
   - PNG 透明背景在部分软件显示为黑色
   - 建议：使用白色背景或 SVG 格式
