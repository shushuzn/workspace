## 🔧 使用流程

### 应用预设模板

1. 打开工具 → 默认显示预设模板
2. 点击分类筛选 (可选)
3. 点击模板卡片 → 预览数据
4. 确认应用 → 存储到 localStorage
5. 打开主程序 → 自动加载模板

### 保存自定义模板

1. 打开主程序 → 创建/加载图谱
2. 打开模板库 → 创建模板标签
3. 点击"加载当前图谱"
4. 填写名称/描述/标签
5. 点击"保存模板"

### 导入模板

1. 打开导入模板标签
2. 选择 JSON 文件
3. 点击"导入"
4. 预览确认
5. 保存到自定义模板

## ⚠️ 注意事项

1. **localStorage 限制**
   - 单域名约 5MB 存储
   - 清除浏览器数据会丢失

2. **模板大小**
   - 建议 <100 节点
   - 过大会影响性能

3. **兼容性**
   - 需要与主程序版本匹配
   - 数据格式 v1
