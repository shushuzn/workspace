## 💡 关键决策

### 1. 模块化设计

**决策:** 将功能分离为独立模块

**理由:**
- 职责清晰
- 易于测试
- 便于维护
- 可单独替换

---

### 2. 统一 API

**决策:** MemoryCore 作为单一入口

**理由:**
- 简化使用
- 隐藏复杂性
- 便于扩展
- 向后兼容

---

### 3. 质量驱动

**决策:** 5 维度质量评估

**理由:**
- 全面评估
- 可解释性强
- 支持决策
- 易于调整权重

---

### 4. 缓存策略

**决策:** LRU + TTL + 搜索缓存

**理由:**
- 平衡性能与内存
- 自动过期
- 减少重复计算
- 命中率可监控
