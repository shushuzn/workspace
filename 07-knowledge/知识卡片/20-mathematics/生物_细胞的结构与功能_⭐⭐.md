**更新日期:** 2026-03-10

## 📖 定义

**细胞:** 生物体结构和功能的基本单位。

**细胞学说:**
1. 细胞是一个有机体，一切动植物都由细胞发育而来
2. 细胞是一个相对独立的单位
3. 新细胞可以从老细胞中产生

**来源:** 普通高中教科书·生物 必修 1

---

## 🔑 核心要点

### 1. 细胞膜
| 项目 | 内容 |
|------|------|
| **成分** | 脂质 (50%)、蛋白质 (40%)、糖类 (2-10%) |
| **结构** | 流动镶嵌模型 |
| **功能** | 控制物质进出、信息交流 |
| **特点** | 选择透过性、流动性 |

### 2. 细胞器
| 细胞器 | 结构 | 功能 |
|--------|------|------|
| 线粒体 | 双层膜 | 有氧呼吸主要场所 |
| 叶绿体 | 双层膜 | 光合作用场所 |
| 内质网 | 单层膜 | 蛋白质合成和加工 |
| 高尔基体 | 单层膜 | 蛋白质加工、分类、包装 |
| 核糖体 | 无膜 | 蛋白质合成场所 |
| 溶酶体 | 单层膜 | 分解衰老、损伤的细胞器 |
| 液泡 | 单层膜 | 调节细胞内环境 |
| 中心体 | 无膜 | 与细胞有丝分裂有关 |

### 3. 细胞核
- **核膜:** 双层膜，有核孔
- **核仁:** 与某种 RNA 的合成有关
- **染色质:** DNA 和蛋白质组成
- **功能:** 遗传信息库，代谢和遗传的控制中心

## 💡 理解技巧

### 记忆口诀
> "膜包质，质包核，细胞结构要记牢；
> 线粒体，供能量，叶绿体，光合忙；
> 内质网，运输忙，高尔基，加工强"

### 理解方法
1. **工厂模型:** 细胞=工厂，各细胞器=车间
2. **结构决定功能:** 膜结构→控制物质进出

### 易错点
- ⚠️ 植物细胞有细胞壁，动物细胞没有
- ⚠️ 原核细胞没有核膜包被的细胞核
- ⚠️ 哺乳动物成熟红细胞没有细胞核

## 📝 典型例题

### 例题 1 (基础)
**题目:** 下列细胞器中，具有双层膜结构的是 (  )

A. 线粒体  B. 内质网  C. 高尔基体  D. 核糖体

**解析:**
```
具有双层膜的细胞器：线粒体、叶绿体
具有单层膜的细胞器：内质网、高尔基体、溶酶体、液泡
无膜结构的细胞器：核糖体、中心体

答案：A
```

---

### 例题 2 (中等)
**题目:** 分泌蛋白的合成和分泌过程中，依次经过的细胞器是？

**解析:**
```
分泌蛋白合成和分泌路径：
核糖体 (合成) → 内质网 (加工) → 高尔基体 (再加工) → 细胞膜 (分泌)

答案：核糖体→内质网→高尔基体→细胞膜
```

---

### 例题 3 (困难)
**题目:** 为什么哺乳动物成熟红细胞没有细胞核？

**解析:**
```
1. 为血红蛋白腾出更多空间，提高携氧能力
2. 减少自身代谢消耗，延长寿命
3. 是长期自然选择的结果

答案要点：
- 空间优化
- 代谢优化
- 进化适应
```
