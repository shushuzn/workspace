# 一元二次方程

## 📖 定义

**一元二次方程:** 只含有一个未知数，且未知数的最高次数为 2 的整式方程。

**一般形式:** ax²+bx+c=0 (a≠0)

**来源:** 普通高中教科书·数学 必修第一册

---

## 🔑 核心要点

### 1. 解法汇总
| 方法 | 适用情况 | 步骤 |
|------|----------|------|
| 直接开平方法 | x²=p 或 (x-h)²=k | 直接开方 |
| 配方法 | 所有一元二次方程 | 配方→开方 |
| 公式法 | 所有一元二次方程 | 代入求根公式 |
| 因式分解法 | 能分解的方程 | 分解→令各因式为 0 |

### 2. 求根公式
```
x = [-b ± √(b²-4ac)] / (2a)

判别式 Δ = b²-4ac
- Δ > 0：两个不相等的实数根
- Δ = 0：两个相等的实数根
- Δ < 0：无实数根
```

### 3. 根与系数的关系 (韦达定理)
```
若 x₁, x₂ 是 ax²+bx+c=0 的两个根，则：
x₁ + x₂ = -b/a
x₁ · x₂ = c/a
```

---

## 💡 理解技巧

### 记忆口诀
> "一化二判三代入，两根之和负 b/a，两根之积 c/a"

### 解法选择
1. **先看能否直接开方** (最简单)
2. **再看能否因式分解** (较快)
3. **最后用公式法** (通用)

### 易错点
- ⚠️ 注意 a≠0 的条件
- ⚠️ 判别式要先计算
- ⚠️ 韦达定理只适用于有实根的情况

## 📝 典型例题

### 例题 1 (基础)
**题目:** 解方程 x²-4=0

**解析:**
```
方法 1：直接开平方法
x²=4
x=±2
∴ x₁=2, x₂=-2

方法 2：因式分解法
(x+2)(x-2)=0
x+2=0 或 x-2=0
∴ x₁=-2, x₂=2

答案：x₁=2, x₂=-2
```

---

### 例题 2 (中等)
**题目:** 解方程 x²-5x+6=0

**解析:**
```
方法 1：因式分解法
(x-2)(x-3)=0
x-2=0 或 x-3=0
∴ x₁=2, x₂=3

方法 2：公式法
a=1, b=-5, c=6
Δ=b²-4ac=25-24=1
x=[5±√1]/2=[5±1]/2
∴ x₁=3, x₂=2

答案：x₁=2, x₂=3
```

---

### 例题 3 (困难)
**题目:** 已知关于 x 的方程 x²-2x+m=0 有两个不相等的实数根，求 m 的取值范围。

**解析:**
```
∵ 方程有两个不相等的实数根
∴ Δ > 0

Δ = b²-4ac
  = (-2)²-4×1×m
  = 4-4m

∴ 4-4m > 0
   -4m > -4
   m < 1

答案：m < 1
```
