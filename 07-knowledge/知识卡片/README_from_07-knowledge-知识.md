## 📋 参考文献格式规范

### 教材 [M] - 优先使用
```
[序号] 编写组。书名 [M].出版地：出版社，年份.

真实示例：
[1] 人民教育出版社课程教材研究所。普通高中课程标准实验教科书·数学 1[M].北京：人民教育出版社，2019.
[2] 赵凯华，陈熙谋。新概念物理教程·力学 [M].北京：高等教育出版社，2006.
```

### 课程标准 [S] - 必须使用
```
[序号] 中华人民共和国教育部。普通高中课程标准 (2017 年版)[S].北京：人民教育出版社，2018.

真实示例：
[1] 中华人民共和国教育部。普通高中数学课程标准 (2017 年版)[S].北京：人民教育出版社，2018.
[2] 中华人民共和国教育部。普通高中物理课程标准 (2017 年版)[S].北京：人民教育出版社，2018.
```

### 学术著作 [M] - 真实存在
```
[序号] 作者。书名 [M].出版地：出版社，年份.

真实示例：
[1] 张景中。数学与哲学 [M].北京：科学出版社，2018.
[2] 费曼。费曼物理学讲义 [M].上海：上海科学技术出版社，2013.
```

### 期刊论文 [J] - 谨慎使用
```
⚠️ 如无法确认论文真实性，请使用教材和课程标准代替！

真实示例：
[1] 张景中。函数单调性的一种新判据 [J].数学通报，2007, 46(10): 1-4. (真实存在)
```

### 电子资源 [EB/OL]

## 🎯 使用规范

### 1. 文件命名
```
[细分领域]_[知识点]_[难度].md

示例：
函数_函数单调性_⭐⭐⭐.md
力学_牛顿第二定律_⭐⭐⭐⭐.md
```

### 2. 参考文献要求
- ✅ **至少 2 篇参考文献**
- ✅ **优先使用真实教材**
- ✅ **必须使用课程标准**
- ✅ **期刊论文必须真实可查**
- ❌ **严禁虚构任何文献信息**

### 3. 知识点来源
- ✅ **教材:** 人教版、北师大版等主流教材
- ✅ **课程标准:** 教育部发布标准
- ✅ **学术著作:** 知名学者真实专著
- ⚠️ **期刊论文:** 必须真实存在，否则不用

### 4. 更新频率
- **新知识点:** 学习当天创建
- **复习更新:** 每周复习时更新掌握程度
- **文献核实:** 发现文献不实时立即修正
- **日期记录:** 记录最后复习时间
