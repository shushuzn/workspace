**用途:** APK 图标

```

```

```

(Knowledge Card)
```

---

## 🛠️ 快速生成

### 使用 Emoji (最快)

**工具:** emoji.com 或 系统自带

**图标:** 📇 (名片夹) 或 📱 (手机)

**步骤:**
1. 打开画图工具
2. 创建 512x512 画布
3. 填充蓝色背景
4. 添加 📇 Emoji
5. 保存为 PNG
