# 知识卡片生成器 - Android APK

**版本:** 1.0.0  
**平台:** Android 5.0+  
**大小:** ~10MB (WebView 封装)

---

## 📱 功能

- ✅ PDF 上传
- ✅ 自动提取元数据
- ✅ 生成知识卡片
- ✅ 参考文献验证
- ✅ 批量处理
- ✅ HTML/BibTeX 导出

---

## 🚀 使用方式

1. 打开 App
2. 上传 PDF 文件
3. 等待处理
4. 下载知识卡片

---

## 📥 安装

1. 下载 APK
2. 允许"未知来源"
3. 安装
4. 打开使用

---

## ⚠️ 注意

- 需要网络连接
- PDF 文件需存储在手机存储
- 免费额度：5 张卡片/月
