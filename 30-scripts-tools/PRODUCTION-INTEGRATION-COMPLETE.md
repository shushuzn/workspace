### 2. 问题修复

#### 问题 1: 搜索模块命名冲突

**症状:**
```
TypeError: 'SearchModule' object is not callable
```

**原因:**
- `self.search` 属性 (SearchModule 实例)
- `search()` 方法
- 命名冲突导致方法被属性覆盖

**解决方案:**
```python
# 修改前
self.search = SearchModule(self.config, self.cache)

# 修改后
self.search_module = SearchModule(self.config, self.cache)
```

**验证:**
```python
core.search("测试")  # ✓ 现在正常工作
```

---

#### 问题 2: Windows 控制台编码

**症状:**
```
UnicodeEncodeError: 'gbk' codec can't encode character '\u2713'
```

**原因:**
- Windows 控制台使用 GBK 编码
- Unicode 符号 (✓ ✗) 无法显示

**解决方案:**
```python
# 修改前
print("✓ MemoryCore 导入成功")
print("✗ 导入失败")

# 修改后
print("[OK] MemoryCore 导入成功")
print("[FAIL] 导入失败")
```

**验证:**
```
[OK] MemoryCore 导入成功  # ✓ 正常显示
```

## 📖 使用指南

### 快速开始

```python
from memory_core import MemoryCore

# 初始化
core = MemoryCore()

# 处理记忆
memory = core.process("今天学习了记忆系统架构")
print(f"分数：{memory.score:.2f}")

# 搜索
results = core.search("记忆系统", limit=5)
for r in results:
    print(f"- {r.content[:50]}...")

# 统计
stats = core.get_stats()
print(f"总记忆数：{stats['total']}")
```

### CLI 使用

```bash
# 处理记忆
python memory_core_cli.py --process "今天学习了 Python"

# 搜索记忆
python memory_core_cli.py --search "Python"

# 查看统计
python memory_core_cli.py --stats

# 批量处理
python memory_core_cli.py --batch memories.txt
```
