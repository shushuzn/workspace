# P-Note 自动化生成器

**激光诱导石墨烯 (LIG) 论文→P-Note 自动转换工具**

**版本:** 1.0  
**日期:** 2026-03-09  
**作者:** Claw (AI Research OS)

---

## 📋 功能概述

将 PubMed/arXiv 论文自动转换为标准化 P-Note 格式，包含 12 维度深度解析。

### 输入
- PubMed PMID 或 arXiv ID
- 或 PDF 文件路径

### 输出
- 标准化 P-Note Markdown 文件
- 质量评分报告
- 审核工作流状态

---

## 🔧 技术架构

```
┌─────────────────────────────────────────────────────────┐
│                    P-Note Generator                      │
├─────────────────────────────────────────────────────────┤
│  1. 数据获取层                                           │
│     ├─ PubMed API (efetch)                              │
│     ├─ arXiv API                                        │

│     └─ TRL 评估 (规则 + AI)                             │
├─────────────────────────────────────────────────────────┤
│  3. 质量评估层                                           │
│     ├─ 完整性检查 (必填字段)                            │
│     ├─ 一致性验证 (数据矛盾检测)                        │
│     └─ 置信度评分 (0-1)                                 │
├─────────────────────────────────────────────────────────┤
│  4. 输出层                                               │
│     ├─ P-Note Markdown 生成                            │
│     ├─ 质量报告 JSON                                    │
│     └─ Git 提交 (可选)                                  │
└─────────────────────────────────────────────────────────┘
```

## 📊 12 维度解析框架

| 维度 | 描述 | AI 提示词 |
|------|------|----------|
| **1. 核心问题** | 研究背景 + 挑战 | "这篇文章试图解决什么问题？为什么重要？" |
| **2. 核心方案** | 创新点 + 技术路线 | "作者的核心创新是什么？如何实现？" |
| **3. 技术细节** | 材料/方法/工艺 | "具体使用了什么材料和方法？" |
| **4. 验证结果** | 实验数据 + 对比 | "有哪些关键实验数据？性能如何？" |
| **5. 机制解析** | 作用原理 + 模型 | "背后的科学机制是什么？" |
| **6. 优势分析** | 对比现有方法 | "相比现有技术有什么优势？" |
| **7. 局限性** | 不足 + 边界条件 | "有哪些局限性和未解决问题？" |
| **8. TRL 评估** | 技术成熟度 | "当前技术成熟度 (TRL 1-9)？" |
| **9. 应用前景** | 潜在应用场景 | "可以应用在哪些领域？" |
| **10. 关键数据** | 核心性能指标 | "提取关键性能数据表格" |
| **11. 知识图谱** | 实体 + 关系提取 | "提取材料/器件/应用实体" |
| **12. 置信度** | 分析可靠性 | "基于摘要/全文的置信度评分" |

## 🚀 使用示例

### 单篇处理

```powershell
# PubMed 论文
py auto-pnote.py --pmid 41785089

# arXiv 论文
py auto-pnote.py --arxiv 2603.05488

# PDF 文件
py auto-pnote.py --pdf "D:\papers\lig-neural-probe.pdf"
```

### 批量处理

```powershell
# 从列表文件
py auto-pnote.py --batch pmid-list.txt --output-dir 11-research/

# 从 JSON 数据
py auto-pnote.py --batch 40-arxiv/lig-papers-cache.json
```

## 🔍 质量评分系统

### 评分维度 (0-100 分)

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| **完整性** | 30% | 12 维度全部填写 (30 分), 缺失 1 项 -3 分 |
| **一致性** | 25% | 数据无矛盾 (25 分), 发现矛盾 -5 分/处 |
| **准确性** | 25% | 与原文一致 (25 分), 错误 -5 分/处 |
| **深度** | 20% | 机制解析深入 (20 分), 表面 -5 分 |

### 质量等级

| 分数 | 等级 | 处理 |
|------|------|------|
| **90-100** | A+ (优秀) | 自动通过，无需审核 |
| **80-89** | A (良好) | 快速审核 (5 分钟) |
| **70-79** | B (可接受) | 标准审核 (15 分钟) |
| **60-69** | C (需改进) | 详细审核 + 修改 |
| **<60** | D (不合格) | 重新生成或人工撰写 |

## 🔧 配置选项

### config.yaml

```yaml
# API 配置
api:
  pubmed:
    base_url: "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/"
    rate_limit: 3  # 请求/秒
  arxiv:
    base_url: "http://export.arxiv.org/api/query"
    max_results: 100

# AI 配置
ai:
  model: "bailian/qwen3.5-plus"
  temperature: 0.3  # 低温度保证准确性
  max_tokens: 4000
  timeout: 120  # 秒

# 输出配置
output:
  dir: "11-research/"
  format: "P-YYYYMMDD-{first_author}-{keywords}.md"
  auto_git: true
  git_commit_msg: "auto: P-Note generated from {pmid}"

# 质量阈值
quality:
  auto_approve: 90  # ≥90 分自动通过
  require_review: 70  # <70 分必须审核
```
