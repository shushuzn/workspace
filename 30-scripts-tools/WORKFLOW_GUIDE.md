# Workflow Automation Guide

## Quick Start

```bash
# Run development workflow
py workflow_master_001.py --run dev

# Run brainstorm workflow
py workflow_master_001.py --run brainstorm

# Full system check
py workflow_master_001.py --run full
```

## Tools

## Naming Convention

```
File: tool_name_001.py (snake_case + _001)
Class: ToolName001 (PascalCase + 001)
```

## Workflow Execution

1. **Diagnosis** → workflow_diagnosis_001
2. **Plan** → brainstorm_workflow_001
3. **Implement** → safe_coder_001 + tool_validator_001
4. **Verify** → workflow_master_001 --run full
5. **Commit** → do_commit_001

## Statistics

# Check workflow stats
