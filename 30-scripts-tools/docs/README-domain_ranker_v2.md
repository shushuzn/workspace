# 学科学术段位评价系统 v2.1

**领域段位评估工具** - 11 维度全面评估学科发展水平

---

## 📖 简介

`domain_ranker_v2.py` 是一个科学的学科/领域段位评价系统，通过 11 个维度对任意研究领域进行量化评估，输出段位、等级、进度等指标。

### 核心特性

- **8 段位体系**: 黑铁→青铜→白银→黄金→铂金→钻石→大师→宗师
- **11 评价维度**: 理论基础、技术成熟度、学术影响力、应用广度、人才储备、资金投入、创新能力、国际合作、教育普及、开源贡献、产业转化
- **渐进式评分**: 每级 10000 XP，每个段位 1000 级，满分 8000 分
- **从零开始**: 所有领域默认从黑铁 1 级起步

## ⚙️ 配置说明

### 权重配置

权重定义在脚本的 `DomainRankerV2.__init__()` 方法中：

```python
self.weights = {
    'theory': 0.15,         # 理论基础
    'technology': 0.15,     # 技术成熟度
    'impact': 0.12,         # 学术影响力
    'application': 0.10,    # 应用广度
    'talent': 0.08,         # 人才储备
    'funding': 0.05,        # 资金投入
    'innovation': 0.10,     # 创新能力
    'collaboration': 0.08,  # 国际合作
    'education': 0.08,      # 教育普及
    'open_source': 0.07,    # 开源贡献
    'industry': 0.07        # 产业转化
}
```

### 自定义领域数据

领域数据硬编码在 `get_domain_data()` 函数中。要添加新领域：

```python
def get_domain_data(self, name: str) -> DomainDataV2:
    domains = {
        "LIG": DomainDataV2(
            name="LIG",
            theory_xp=600,
            technology_xp=550,
            # ... 其他维度
        ),
        # 添加新领域
        "YourDomain": DomainDataV2(
            name="YourDomain",
            theory_xp=500,
            technology_xp=500,
            # ...
        ),
    }
    return domains.get(name, self._default_domain(name))
```

## 🔧 技术细节

### 评分算法

1. **加权总分计算**:
   ```
   total_xp = Σ(dimension_xp × weight)
   ```

2. **段位等级转换**:
   ```
   total_levels = total_xp / 10000
   rank_level = int(total_levels)
   sub_level = int((total_levels % 1) × 1000)
   ```

3. **进度计算**:
   ```
   progress = (rank_level × 1000 + sub_level) / 8000 × 100%
   ```

- Python 3.8+
- 无外部依赖 (仅使用标准库)

## 🐛 常见问题

### Q: 为什么我的领域分数很低？
A: 所有领域从黑铁 1 级 (0 分) 起步。分数反映当前发展水平，大部分新兴领域都在黑铁/青铜段位。

### Q: 如何修改权重？
A: 编辑脚本中的 `self.weights` 字典。确保权重总和为 1.0。

### Q: 可以导出评估报告吗？
A: 当前版本输出到控制台。可以修改 `print_report()` 函数支持 JSON/Markdown 导出。
