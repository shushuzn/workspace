## 📋 API 方案选择

### 方案 A: Twitter 官方 API v2

**优点:**
- 官方支持，稳定性高
- 文档完善
- 功能全面 (推文/用户/搜索)

**缺点:**
- 免费额度有限
- 需要申请开发者账号
- 审核可能需要时间

**免费额度 (估计):**
- 推文读取：~100-500 条/月
- 用户信息：~300 次/月
- 搜索：有限或不可用

---

### 方案 B: 第三方 API (推荐)

**选项:**
1. **Nitter 实例** - 免 API Key，但可能不稳定
2. **RapidAPI Twitter 服务** - 付费，但有免费额度
3. **SerpApi Twitter 搜索** - 付费，专业级

**推荐:** Nitter (免费，适合初期测试)

---

## 🔧 配置步骤

### 使用 Nitter (方案 B1)

**步骤:**
1. 选择公共 Nitter 实例
   - nitter.net
   - nitter.privacy.com.de
   - nitter.lunar.icu

2. 测试连接
   ```bash
   curl https://nitter.net/elonmusk/rss
   ```

3. 解析 RSS  feed
   - 推文内容
   - 发布时间
   - 点赞/转发数

**优点:**
- ✅ 无需 API Key
- ✅ 免费
- ✅ 简单快速

**缺点:**
- ⚠️ 实例可能不稳定
- ⚠️ 速率限制未知

---

## 📝 决策

**推荐方案:** Nitter RSS (初期测试)

**理由:**
1. 无需 API Key，立即可用
2. 适合每日 20+ 推文收集目标
3. 如不稳定，再考虑官方 API
