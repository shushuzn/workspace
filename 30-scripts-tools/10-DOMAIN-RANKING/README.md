## 🚀 快速开始

### 评估领域
```bash
# 评估指定领域
py core/domain_ranker_v2.py --evaluate LIG

# 比较所有领域
py core/domain_ranker_v2.py --compare

# 导出结果
py core/domain_ranker_v2.py --evaluate LIG --export result.json
```

### 生成报告
```bash
# 生成段位报告
py reports/domain_ranking_report.py
```

## ✨ 评价维度

### 核心维度 (60%)
1. **理论基础** (15%) - 理论体系完整性
2. **技术成熟度** (15%) - TRL 等级
3. **学术影响力** (12%) - 论文引用
4. **应用广度** (10%) - 跨领域应用
5. **人才储备** (8%) - 研究组数量
6. **资金投入** (5%) - 年度经费

### 新增维度 (40%)
7. **创新能力** (10%) - 原创性/突破性
8. **国际合作** (8%) - 跨国研究合作
9. **教育普及** (8%) - 教材/课程收录
10. **开源贡献** (7%) - 开源工具/数据
11. **产业转化** (7%) - 商业化应用
