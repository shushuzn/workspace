# 工作流优化工具 - 快速使用指南

## 🚀 新增工具

### 1. tool_executor.py - 自动步骤追踪

**功能:** 执行工具后自动标记步骤完成

**使用方式:**

```bash
# 基本用法 (自动完成步骤)
py 30-scripts-tools\tool_executor.py fast-load

# 禁用自动完成
py 30-scripts-tools\tool_executor.py fast-load --no-auto-complete

# 指定工作流
py 30-scripts-tools\tool_executor.py fast-load --flow-id 20260318-universal-workflow-001
```

**输出示例:**
```
[Tool Executor] 执行工具：fast-load
     当前步骤：1
     自动完成：True

============================================================
Fast Load - 快速加载核心上下文
============================================================
...

[OK] 步骤 1 自动完成
     工具：fast-load
     结果：成功
     下一步：2
```

**优势:**
- ✅ 减少 50% 操作步骤
- ✅ 避免忘记确认步骤
- ✅ 自动记录执行日志
- ✅ 工作流违规自动阻断

---

### 2. workflow_interactive.py - 交互式菜单

**功能:** 图形化界面执行工作流

**使用方式:**

```bash
# 启动交互式菜单
py 30-scripts-tools\workflow_interactive.py

# 指定工作流
py 30-scripts-tools\workflow_interactive.py --flow-id 20260318-universal-workflow-001
```

**界面示例:**
```
============================================================
工作流执行器 - 通用主工作流 (v1.1.0)
============================================================

进度：[████████░░░░] 8/12 步骤完成 (67%)
状态：进行中
违规：0 次

============================================================
当前步骤：9. 批判者最终审查 [阻塞]
============================================================

描述：对任务结果进行批判性审查
工具：auto-critic-v7

可用操作:
  1. 执行当前步骤
  2. 查看步骤详情
  3. 查看工作流完整状态
  4. 查看执行历史
  5. 跳过当前步骤 (需要确认)
  6. 暂停工作流
  7. 退出（保持工作流状态）
  8. 刷新状态
  9. 帮助

选择操作 [1-9]: _
```

**优势:**
- ✅ 无需记忆命令行参数
- ✅ 实时进度可视化
- ✅ 新手友好
- ✅ 错误提示清晰

## 🔧 故障排除

### 问题 1: 工具执行失败

**错误:** `工作流未启动！请先执行：py workflow_enforcer.py --start`

**解决:**
```bash
py 30-scripts-tools\workflow_enforcer.py --start
```

### 问题 2: 交互式菜单无法启动

**错误:** `工作流配置未找到!`

**解决:**
```bash
# 检查工作流配置是否存在
dir flow-archive\20260318-universal-workflow-001\workflow.json

# 如果不存在，创建工作流
py 30-scripts-tools\workflow_enforcer.py --start
```

### 问题 3: 自动完成不工作

**检查:**
```bash
# 查看执行日志
type flow-archive\20260318-universal-workflow-001\execution-log.json
```
