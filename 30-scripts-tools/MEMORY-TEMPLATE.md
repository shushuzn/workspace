# 记忆模板标准 v1.0

**用途:** 标准化 MEMORY.md 中的记忆条目格式  
**目标:** 提升一致性、机器可读性、自动化支持

---

## 标准模板

```markdown
### [CATEGORY-001] 记忆标题

**日期:** YYYY-MM-DD  
**来源:** 蒸馏/手动/自动/会议  
**置信度:** 高/中/低  
**类别:** 认知/技术/流程/洞察/决策/教训  
**状态:** 活跃/待复习/已归档  

**核心观点:**
一句话概括核心洞察（≤50 字）

**详细内容:**
- **背景:** 为什么重要
- **论据:** 支撑证据
- **结论:** 最终洞察

**可迁移模式:**
```
通用模式描述
适用于 X/Y/Z 场景
```

**关联记忆:**
- [XXX-001] 相关记忆 1 (支撑/被支撑)
- [XXX-002] 相关记忆 2 (前提/结果)

**元数据:**
- 新颖度：0-100
- 可迁移性：0-100
- 重要性：0-100
- 最后复习：YYYY-MM-DD
- 强度：0.0-1.0
- 访问次数：N

**版本历史:**
- v1.0 (YYYY-MM-DD): 初始创建
- v1.1 (YYYY-MM-DD): 更新内容
```

---

## 类别定义

| 类别 | 说明 | 示例 |
|------|------|------|
| **认知** | 认知架构、思维模型 | AG-001 认知 - 运行分离 |
| **技术** | 技术实现、工具使用 | SYS-001 Docker 容器网络 |
| **流程** | 工作流程、最佳实践 | GIT-001 Git 自动化标准 |
| **洞察** | 关键洞察、发现 | CR-001 批判者必要性 |
| **决策** | 重要决策、规则 | USER-001 禁止休息建议 |
| **教训** | 错误、反思、改进 | 细节严谨性反思 |

---

## 置信度定义

| 置信度 | 说明 | 验证要求 |
|--------|------|----------|
| **高** | 已验证、可依赖 | ≥3 次实践验证 |
| **中** | 初步验证、待观察 | 1-2 次实践验证 |
| **低** | 假设、待验证 | 未经实践验证 |

---

## 元数据评分标准

### 新颖度 (0-100)
- 90-100: 全新发现，前所未有
- 70-89: 新组合，新视角
- 50-69: 已知但有深化
- 30-49: 常规知识
- 0-29: 常识

### 可迁移性 (0-100)
- 90-100: 适用于 10+ 场景
- 70-89: 适用于 5-9 场景
- 50-69: 适用于 2-4 场景
- 30-49: 适用于 2 场景
- 0-29: 仅适用单一场景

### 重要性 (0-100)
- 90-100: 核心原则，影响全局
- 70-89: 重要规则，影响局部
- 50-69: 有用指南
- 30-49: 次要提示
- 0-29: 边缘知识

## 使用示例

```markdown
### [CR-001] 批判者必要性 - 100→0→88 分验证

**日期:** 2026-03-13  
**来源:** 批判者 v5.0 超严格审查 + 10 项修复  
**置信度:** 高  
**类别:** 洞察  
**状态:** 活跃  

**核心观点:**
没有批判者，系统会从 100 分自满跌至 0 分真相

**详细内容:**
- **背景:** 执行者容易自满，忽略问题
- **论据:** 100 分 (自满) → 0 分 (真相) → 88 分 (良好)
- **结论:** 批判者必须独立于执行者，评分目标≥85 分

**可迁移模式:**
```
任务完成 → 批判者审查 → ≥85 分 → 通过
                    ↓
                 <85 分 → 修复循环
```

**关联记忆:**
- [LR-001] 学习者触发 (支撑)
- [PS-001] 7 人格架构 (属于)
- [AUTO-001] 自主决策 (验证)

**元数据:**
- 新颖度：85
- 可迁移性：95
- 重要性：90
- 最后复习：2026-03-13
- 强度：0.95
- 访问次数：12

**版本历史:**
- v1.0 (2026-03-13): 初始创建
```

## 自动化支持

**脚本:** `memory_template_validator.py`
```bash
# 验证记忆格式
py memory_template_validator.py --check MEMORY.md

# 自动格式化
py memory_template_validator.py --format MEMORY.md

# 提取元数据
py memory_template_validator.py --extract-meta MEMORY.md
```
