## 🔗 与 Git Hook 的关系

### Git Hook (自动)

```bash
# 安装
py install-git-hooks.py

# 自动在 git commit 时执行
git commit -m "..."
# → 自动运行 pre-commit Hook
```

**特点:**
- ✅ 强制执行
- ✅ 无需手动运行
- ❌ 仅在 commit 时检查

### Git Pre-Check (手动)

```bash
# 手动运行
py git-precheck.py

# 提前发现问题
# 修复后再 commit
```

**特点:**
- ✅ 提前检查
- ✅ 可扫描全工作区
- ✅ 可保存报告
- ❌ 需手动运行

### 最佳实践

```bash
# 1. 添加文件
git add .

# 2. 手动预检查
py git-precheck.py

# 3. 修复问题 (如有)

# 4. 提交 (Hook 会自动再次检查)
git commit -m "..."
```
