```bash
start-session.bat
```
**自动检查:**
- ✅ 主工作流是否加载
- ✅ Flow ID 是否绑定

```bash

```
**自动检查:**
- ✅ 当日笔记 <5KB
- ✅ 合规性检查通过
- ✅ Git 提交成功

---

## 🔧 核心机制

### 1. 会话前强制检查
**文件:** `start-session.bat`  
**触发:** 每次会话开始  
**阻止:** 工作流未加载 → 不允许会话

### 2. Git 提交前强制检查
**文件:** `.git/hooks/pre-commit`  
**触发:** 每次 `git commit`  
**阻止:** 笔记>5KB → 不允许提交

### 3. 会话结束强制检查
**文件:** `end-session.bat`  
**触发:** 每次会话结束  
**阻止:** 笔记未压缩 → 不允许结束

---

## 📊 检查矩阵

| 检查点 | 触发时机 | 检查内容 | 阻止级别 |
|--------|----------|----------|----------|
| 会话前检查 | `start-session.bat` | 工作流配置 | 🔴 严重 |
| 任务前检查 | 执行任务前 | 步骤完成度 | 🟡 警告 |
| 提交前检查 | `git commit` | 笔记大小 | 🔴 严重 |
| 会话结束检查 | `end-session.bat` | 综合合规 | 🔴 严重 |

## ⚠️ 常见场景

### 场景 1: 忘记压缩笔记
```
[FAIL] 当日笔记过大：7200 bytes (>5KB)
[BLOCK] Git 提交被阻止！
```
**解决:**
```bash
py 30-scripts-tools\post_session_compress.py --auto
```

---

### 场景 2: 步骤未完成
```
[FAIL] 完成度：75.0%
[BLOCK] 不允许 Git 提交！
```
**解决:**
```bash
# 完成缺失步骤
# 1. 会话压缩保存
# 2. Git 提交推送
# 然后运行 end-session.bat
```
