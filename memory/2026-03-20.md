## 🔑 核心教训

1. **防护系统必须自己遵守** - 设计者绕过=系统失效
2. **验证必须检查内容** - 不能只检查步骤数量
3. **假装执行=没有执行** - 必须验证实际输出
4. **压缩必须严格执行** - <5KB/<100KB 目标必须达成
5. **工作流必须真正使用** - 不能只是"说"用工作流
6. **Windows 中文环境编码问题** - Python 输出 Unicode 需设置 PYTHONIOENCODING=utf-8
