**问题:** 直接运行 `py 30-scripts-tools/copaw_entry.py "中文会话"` 失败  
**原因:** Windows GBK 编码无法处理中文  
**解决方案:** 
```bash

```
- `chcp 65001` - 切换控制台为 UTF-8
- `-X utf8` - 让 Python 使用 UTF-8
