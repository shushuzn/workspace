## Reflection: File Size Management

### Lesson Learned
1. write_file has hard 8KB limit - cannot bypass
2. Python scripts are the only reliable way to write large files
3. Data-heavy modules should be split into multiple files
4. Generator pattern (small script → generates large file) is safest

### Best Practices
1. Pre-calculate content size before writing
2. Split large data dictionaries into separate modules
3. Use edit_file for all modifications to existing files
4. Test imports after writing large files

### Workflow for Large Modules
```python
# Step 1: Create generator (small, <8KB)
write_file("gen_module.py", '''
content = "..." * 1000
with open("module.py", "w") as f:
    f.write(content)
''')

# Step 2: Run generator
python gen_module.py

# Step 3: Verify and import
python -c "import module; print('OK')"
```

### Testing Pattern
Always verify large file creation:
```bash
# Check file exists and size
dir file.py

# Verify it's valid Python
python -c "import file; print('OK')"

# Check specific content
python -c "from file import something; print(something)"
```

### Final Rule
**write_file = <8KB only. For anything larger, use Python scripts.**
