## ⛔ write_file 8KB Limit - Final Resolution (2026-03-23 11:30)

### The Problem
`write_file` tool has an 8KB (8192 bytes) limit. Files larger than this get TRUNCATED.

### What I Tried (All Failed)
| Method | Problem |
|--------|---------|
| PowerShell heredoc | Encoding issues, syntax errors |
| `python -c "..."` | Command line too long |
| `write_helper.py` | Never actually worked correctly |
| Direct `write_file` >8KB | File truncated! |

### ✅ ONLY Solution: Generator Pattern
```python
# Step 1: Write generator (< 8KB)
write_file("gen.py", '''
content = """大文件内容放这里"""
open("output.py", "w", encoding="utf-8").write(content)
print("✅ output.py")
''')

# Step 2: Execute generator
execute_shell_command("python gen.py")
```

### Decision Rule
```python
size = len(content.encode('utf-8'))
if size < 8192:
    write_file(path, content)  # Direct
```

## Reflections & Logic

### File Handling Strategy
When user says "don't use write":
- Respect the constraint completely
- Use Python scripts with file I/O instead
- Use PowerShell as alternative if Python fails
- Never try to circumvent the constraint

### Breaking Changes Protocol
1. Always check git status before modifying files
2. Commit or stash changes before major refactoring
3. Create backup copies before destructive operations
4. If file is lost, use git checkout to restore

### Python Script Execution Issues
- Windows `cmd` doesn't support `<<` heredoc syntax
- PowerShell has different heredoc syntax `@'...'@`
- Best approach: Write Python script to file, then execute

### How to Handle Large Files
From `D:\OpenClaw\workspace\active_skills\file-handling\SKILL.md`:
- Files <8KB: Use `write_file`
- Files >8KB: Use Python generator scripts
