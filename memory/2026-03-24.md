### 自定义 RSS 支持

在 `config/sources.json` 中添加了 `custom_rss` 配置区域：

```json
"custom_rss": {
  "enabled": true,
  "sources": [
    {"name": "金十数据", "url": "YOUR_RSS_URL_HERE", "enable": true, "limit": 15}
  ]
}
```

### 经验教训

1. **Windows 环境下 Python print 不输出** - 使用 `sys.__stdout__` 或写文件调试
2. **RSS 源网络不可达** - gold.cn/eastmoney.com 等国内金融 RSS 在当前网络环境下无法访问
3. **哈希去重机制** - `.news_hashes.json` 会导致同批次新闻全部被标记为"已存在"
4. **英文新闻分类** - 英文新闻源需要对应的英文关键词才能正确分类
