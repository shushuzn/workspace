# 🗣️ OpenClaw 自然语言使用指南

**不用记命令！用自然语言告诉 Claw 你想要什么。**

---

## 💡 核心原则

```
❌ 不要记：python autonomous_research_agent.py --run
✅ 直接说："帮我研究一下最新的 AI 论文"

❌ 不要记：python memory_kg_extractor.py --extract
✅ 直接说："把 MEMORY.md 的教训整理到知识图谱"

❌ 不要记：python openclaw.py arxiv scan --categories cs.AI
✅ 直接说："扫描 arXiv 上最新的 AI 论文"
```

| 你想做什么 | 直接这样说 |
|-----------|-----------|

## 🎯 最佳实践

### ✅ 这样说 (好)
```
"帮我研究一下最新的 AI 论文"
"把最近的教训整理到知识图谱"
"现在系统怎么样？"
"创建一个能 XXX 的工具"
"提交刚才的修改"
```

### ❌ 别这样说 (不好)
```
"运行 python arxiv_scanner_v2.py --scan"
"执行 memory_kg_extractor.py --extract"
"调用 openclaw.py status"
```

**原则：告诉我你想要什么结果，不是告诉我用什么命令。**

## 🤖 Claw 的工作流程

当你用自然语言下指令时，我会：

```
1. 理解你的意图
   ↓
2. 选择合适的工具
   ↓
3. 执行工具 (自动处理参数)
   ↓
4. 展示结果 (人类可读)
   ↓
5. 询问下一步
```

**示例:**
```
你：帮我研究一下最新的 AI 论文

1. 理解 → 用户想要 arXiv 论文研究
2. 选择 → autonomous_research_agent.py
3. 执行 → python autonomous_research_agent.py --run
4. 展示 → 📊 扫描了 5 篇论文，提取 9 条洞察...
5. 询问 → 要深入分析哪篇吗？
```

## 🎓 进阶技巧

### 1. 组合指令
```
"扫描 arXiv 并分析前 3 篇论文"
"提取教训到知识图谱，然后生成可视化"
"创建工具、测试、然后部署"
```

### 2. 条件指令
```
"如果有新论文就分析，没有就跳过"
"如果压缩率低于 5x 就优化提示词"
"如果测试失败就自动修复"
```

### 3. 批量指令
```
"把所有未处理的笔记都蒸馏了"
"运行所有健康检查"
"更新所有仪表板"
```
