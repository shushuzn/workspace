## 🎓 研究笔记模板

### [[P-Note Template]]
**用途:** 单篇论文深度解析  
**场景:** 阅读 arXiv 论文后记录  
**输出:** `P-YYYY-PaperName.md`

**核心字段:**
- arxiv_id, title, authors, year
- 10 维度分析
- 对抗式审稿
- Decision (采纳/观望/拒绝)

**使用示例:**
```
1. 复制模板
2. 填写 YAML 元数据
3. 完成 10 维度分析
4. 执行对抗式审稿
5. 做出 Decision
```

---

### [[M-Note Template]]
**用途:** 多篇论文对比分析  
**场景:** 同一主题多篇论文对比  
**输出:** `M-YYYYMMDD-Topic-Comparison.md`

**核心字段:**
- 对比论文列表
- 方法论对比
- 性能对比表
- 跨论文模式识别

**使用示例:**
```
1. 选择 3-5 篇相关论文
2. 填写对比表格
3. 识别共同趋势
4. 提炼设计原则
```

## 🎯 模板使用指南

### 快速开始

1. **选择模板** - 根据内容类型选择
2. **复制模板** - 从 templates/ 目录复制
3. **填写元数据** - 完善 YAML frontmatter
4. **完成内容** - 按模板结构填写
5. **添加标签** - 便于后续检索

### 命名规范

| 类型 | 命名格式 | 示例 |
|------|----------|------|
| P-Note | `P-YYYY-PaperName.md` | `P-2026-ODAR-AdaptiveRouting.md` |
| M-Note | `M-YYYYMMDD-Topic.md` | `M-20260303-Efficiency-Optimization.md` |
| C-Note | `C-ConceptName.md` | `C-Adaptive-Routing.md` |
| 学习 | `learning-notes-YYYY-MM-DD-topic.md` | `learning-notes-2026-03-04-pokemon.md` |
| 每日 | `YYYY-MM-DD.md` | `2026-03-04.md` |
| 研究问题 | `research-question-topic.md` | `research-question-llm-efficiency.md` |

### 标签系统

```
#笔记/每日      - 每日笔记
#笔记/学习      - 学习笔记
#论文/P-Note    - 单篇论文解析
#论文/M-Note    - 多篇对比
#概念/C-Note    - 概念研究
#研究/问题      - 研究问题
```

## 🔧 模板配置

### Obsidian 设置

1. **核心插件 → 模板**
   - 模板文件夹：`templates/`
   - 日期格式：`YYYY-MM-DD`
   - 时间格式：`HH:mm`

2. **核心插件 → 每日笔记**
   - 文件夹：`memory/`
   - 模板：`templates/Daily Note Template`

3. **核心插件 → 文件恢复**
   - 启用：是
   - 检查间隔：5 分钟
