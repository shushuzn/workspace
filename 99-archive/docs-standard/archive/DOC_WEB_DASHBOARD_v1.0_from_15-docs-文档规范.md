# Web 仪表板

**版本:** v1.0  
**创建时间:** 2026-03-05 19:00  

---

## 📋 概述

Web 仪表板提供系统监控、配置管理、日志查看等功能。

---

## 🚀 功能

### 1. 实时指标

- API 请求数
- CPU/内存使用率
- 缓存命中率
- 错误率

### 2. 告警历史

- 告警列表
- 告警统计
- 告警趋势

### 3. 日志查看器

- 实时日志
- 日志搜索
- 日志导出

### 4. 配置管理

- 查看配置
- 修改配置
- 配置导出/导入

---

---

## 🔧 技术栈

- **前端:** HTML/CSS/JavaScript
- **图表:** Chart.js
- **实时数据:** WebSocket
- **后端:** Flask/FastAPI
