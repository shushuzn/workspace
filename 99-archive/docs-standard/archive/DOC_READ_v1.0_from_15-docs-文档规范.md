# READ.md - 技能/工具速查

## AI 研究工具

| 工具 | 用途 |
|------|------|
| `web_search` | 学术搜索 (Arxiv/Google Scholar) |
| `web_fetch` | 抓取论文/博客全文 |
| `browser` | 深度网页交互 |
| `memory_search` | 本地知识库检索 |
| `sessions_spawn` | 并行分析任务 |

## 技能脚本

| 技能 | 用途 |
|------|------|
| `alphaear-search` | 金融/科技 web 搜索 |
| `alphaear-reporter` | 生成研究报告 |
| `alphaear-sentiment` | 文本情感分析 |
| `openai-whisper-api` | 音频转录 |
| `openai-image-gen` | 图表生成 |

## 输出目录

| 类型 | 路径 |
|------|------|
| Obsidian 笔记 | `D:\obsidian\Vault\Medium\` |
| 文章缓存 | `D:\scripts\article_cache\` |
| 日志文件 | `D:\scripts\*.log` |
