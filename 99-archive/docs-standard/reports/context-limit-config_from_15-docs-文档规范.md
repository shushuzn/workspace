# 上下文窗口限制配置

**更新时间:** 2026-03-05 01:45  
**配置文件:** `C:\Users\华为\.openclaw\openclaw.json`

---

## 当前配置

```json
{
  "agents": {
    "defaults": {
      "contextTokens": 500000
    }
  }
}
```

**限制值:** 500,000 tokens (500k)

---

## 配置原因

1. **性能优化:** 避免长会话导致响应变慢
2. **资源控制:** 减少内存占用和 API 调用成本
3. **自动会话切换:** 超过阈值自动创建新会话

---

## 会话管理行为

**当会话达到 500k tokens 时:**
1. 自动创建新会话
2. 保留关键上下文 (最近的对话)
3. 旧会话归档到历史

**优点:**
- ✅ 保持响应速度
- ✅ 避免内存泄漏
- ✅ 降低 API 成本

**缺点:**
- ⚠️ 可能丢失早期上下文
- ⚠️ 需要频繁切换会话

## 调整建议

### 增加限制 (如需要更长上下文)
```json
"contextTokens": 700000  // 700k
```

### 减少限制 (如需更严格控制)
```json
"contextTokens": 300000  // 300k
```

### 禁用限制 (不推荐)
```json
"contextTokens": -1  // 无限制
```
