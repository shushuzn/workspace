# Task Manager Skill - 任务管理技能

**版本:** 1.0  
**创建时间:** 2026-03-04  
**用途:** 任务规划、执行跟踪、用时控制

---

## 核心规则

### ⏱️ 用时控制 (强制)

1. **单项任务 ≤10 分钟**
   - 任何预计超过 10 分钟的任务必须拆分为子任务
   - 每个子任务独立计时、独立验收

2. **细化标准**
   - 复杂任务 → 拆分为可执行的原子操作
   - 等待型任务 (如后台运行) → 计为 0 分钟主动用时
   - 批量操作 → 按批次拆分 (10/50/100 等)

3. **时间标注格式**
   ```markdown
   - [ ] 任务描述 — ⏱️ X 分钟
   ```

## 任务结构

### 标准任务模板

```markdown
## [优先级] 任务名称 → 状态 (完成时间)

- [ ] 子任务 1a. 描述 — ⏱️ 5 分钟
- [ ] 子任务 1b. 描述 — ⏱️ 5 分钟
- [ ] 子任务 1c. 描述 — ⏱️ 10 分钟

**验收标准:**
- [ ] 输出文件/结果已生成
- [ ] 用时符合预期 (≤10 分钟/项)
```

### 优先级定义

| 标识 | 含义 | 响应时间 |
|------|------|----------|
| 🔴 | 高 | 立即处理 |
| 🟡 | 中 | 24 小时内 |
| 🟢 | 低 | 本周内 |

## 任务类型

### 1. 验证类任务
- 系统状态检查
- API/服务可用性测试
- 文件/配置验证

**用时:** 5-10 分钟

### 2. 配置类任务
- 脚本配置
- 定时任务设置
- 环境变量调整

**用时:** 5-15 分钟 (超过需拆分)

### 3. 执行类任务
- 批量处理
- 数据转换
- 报告生成

**用时:** 按批次拆分 (每批 ≤10 分钟)

### 4. 等待类任务
- 后台进程监控
- 定时任务执行
- 外部依赖等待

**用时:** 0 分钟 (仅记录等待时间)

## 进度追踪

### 计算公式

```
完成率 = 已完成子任务数 / 总子任务数 × 100%
```

### 状态标记

| 标记 | 含义 |
|------|------|
| ✅ | 已完成 |
| ⏳ | 进行中 |
| ⏸️ | 已暂停 |
| ❌ | 已取消 |
| ⚠️ | 有风险/问题 |

---

## 最佳实践

### ✅ 推荐

- 任务描述清晰、可执行
- 每项任务有明确验收标准
- 用时估算保守 (预留 20% 缓冲)
- 完成后立即更新状态

### ❌ 避免

- 模糊描述 ("优化系统"、"改进性能")
- 无时限的开放任务
- 过度拆分 (<1 分钟的微任务)
- 忘记更新完成状态
