## 问题诊断

### 1. 待分析文件堆积

**现象:** 318 个 `20260302-*.md` 文件处于 `pending_analysis` 状态

**原因:**
- RSS Collector 自动抓取但未触发分析流程
- 文件仅包含元数据 Frontmatter，无实际内容
- 每个文件约 286 字节，占用空间小但数量多

**影响:**
- 目录混乱，难以定位有价值内容
- Obsidian 索引负担增加
- 无法区分已处理和未处理内容

### 2. 文件命名不一致

| 命名模式 | 含义 | 问题 |
|----------|------|------|
| `P-YYYY-MM-DD-*.md` | 论文深度解析 | ✅ 清晰 |
| `YYYY-MM-DD_*.md` | Medium 文章分析 | ✅ 清晰 |
| `YYYYMMDD-HHMMSS-*.md` | RSS 原始抓取 | ❌ 时间戳冗余 |

### 3. 缺乏归档机制

- 无历史文件归档目录
- 已完成分析与待分析文件混放
- 无定期清理策略

## 优化方案

### 阶段 1: 立即清理 (今日执行)

```powershell
# 1. 创建归档目录
New-Item -Path "D:\obsidian\Vault\Medium\archive\2026-03" -ItemType Directory -Force

# 2. 移动待分析空壳文件到归档
Get-ChildItem -Path "D:\obsidian\Vault\Medium" -Filter "20260302-*.md" | 
    Where-Object { $_.Length -lt 350 } | 
    Move-Item -Destination "D:\obsidian\Vault\Medium\archive\2026-03\"

# 3. 验证移动结果
Write-Host "已移动文件数：$((Get-ChildItem "D:\obsidian\Vault\Medium\archive\2026-03" -Filter "*.md").Count)"
Write-Host "主目录剩余文件数：$((Get-ChildItem "D:\obsidian\Vault\Medium" -File).Count)"
```

**预期结果:**
- Medium 主目录保留：~15 个文件 (5 P-Note + 3 已分析 + 其他)
- 归档目录：318 个待分析文件
