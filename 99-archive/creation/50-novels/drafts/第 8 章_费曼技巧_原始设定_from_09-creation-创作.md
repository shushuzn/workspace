课间十分钟。

江越转过身，把练习册推到林砚面前。

"这题，讲讲？"

林砚扫了一眼。

函数压轴题，他昨天刚做过。

"行。"

他拿起笔，在草稿纸上写。

```
f(x) = x² - 2x + 1
f'(x) = 2x - 2
```

"先求导。"他说。

江越点头。

"然后......"

林砚卡住了。

笔尖悬在纸上，不动了。

"然后什么？"江越问。

"然后......令导数等于零。"

"为什么？"

林砚愣住了。

为什么？

他记得老师说过，但具体为什么，说不上来。

"就是......求极值点。"

"极值点和单调性有什么关系？"

林砚不说话了。

林砚不说话了。

他看着江越的背影，心里有什么东西在翻腾。

不是难受，是一种......说不清的感觉。

像是被人戳破了一个泡泡。

泡泡里是他以为的"我会了"。

泡泡破了，里面是空的。

他看着草稿纸上的式子，突然觉得陌生。

"我......"

"算了。"江越拿回练习册，"我自己再看吧。"

---

上课铃响了。

林砚坐在座位上，脑子里还在想刚才的对话。

"我明明会做。"他想，"但为什么讲不清楚？"

同桌江越在认真听课，笔尖飞舞。

林砚低下头，看着自己的手。

手心有点出汗。

"不是真的会。"他对自己说，"只是记住了步骤。"

---

放学，图书馆。

一整节课，林砚都没听进去。

老师在讲台上讲什么，他都没听见。

脑子里只有三个词：

"不是真的会。"

下课铃响的时候，他猛地站起来。

"去哪？"江越问。

"图书馆。"

"现在？"

"嗯。"

江越看着他，没说话，只是点了点头。

三楼，老位置。

林砚摊开笔记本，开始查资料。

"费曼学习法。"他在搜索框里输入。

网页跳出来，一大堆。

他点开第一个。

```
费曼技巧四步：
1. 选择一个概念
2. 假装教给别人
3. 卡壳时返回学习
4. 简化语言
```

"教给别人......"林砚轻声念。

他想起课间的事。

"原来，能教会别人才是真懂。"

---

他合上电脑，拿起练习册。

还是那道函数题。

他重新开始，假装要教别人。

"首先，什么是单调性？"

他在纸上写：

```
单调性：x 变大时，y 的变化趋势
```

"然后，怎么判断？"

```
方法 1：定义法（比较 f(x1) 和 f(x2)）
方法 2：导数法（看 f'(x) 的正负）
```

"为什么导数能判断？"

他卡住了。

查书。

```
导数的几何意义：切线斜率
f'(x) > 0：切线向上，函数递增
f'(x) < 0：切线向下，函数递减
```

"原来如此。"

他继续写。

```
解题步骤：
1. 求导 f'(x)
2. 令 f'(x) = 0，求临界点
3. 判断临界点两侧的符号
4. 得出单调区间
```

写完了，他看了一遍。

"这次，能讲清楚了。"

---

第二天，课间。

晚上九点，回到家。

母亲在客厅看电视，见他回来，按了静音。

"回来了？"

"嗯。"

"学习怎么样？"

"今天......"林砚想了想，"学会了一个方法。"

"什么方法？"

"教别人。"

母亲愣了一下，然后笑了。

"教别人？教谁？"

"江越。"

"那挺好的。"母亲说，"互相学习。"

林砚点点头，走进房间。

他把今天的笔记摊开在桌上。

函数单调性，费曼技巧，还有那道题的三种解法。

"明天，再讲一遍。"他想。

---

第二天，课间。

江越又转过身。

"昨天那题，还想讲吗？"

"想。"林砚说。

他拿起笔，在草稿纸上画了个图。

"你看，这是个抛物线。"

"开口向上，对称轴 x=1。"

"所以在 x<1 时，函数递减。"

"在 x>1 时，函数递增。"

江越盯着图，看了几秒。

"懂了。"他说，"你讲得比老师清楚。"

林砚愣了一下。

然后笑了。

"真的？"

"嗯。"江越点头，"老师讲得太快，你一步一步来。"
