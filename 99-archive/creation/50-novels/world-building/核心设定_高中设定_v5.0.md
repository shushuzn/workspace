## 🎮 核心概念

```
学习，就是一场认知跃迁的游戏。
人的认知，分为九层。
每突破一层，解锁一个技能节点。
九层突破，技能树点亮。
```

## 🎮 游戏化学习核心创意

### 游戏技能转化学习

| 游戏技能 | 学习转化 | 对应认知层级 |
|----------|----------|--------------|
| 资源管理 | 时间管理 | 第二层·觉醒 |
| 团队协作 | 学习小组 | 第三层·精通 |
| 失败重来 | 错题本 | 第三层·精通 |
| 攻略研究 | 知识梳理 | 第四层·系统 |
| 装备升级 | 能力提升 | 第五层·人性 |

---

### 技能解锁机制

**解锁条件:**
1. 认知突破 (想通一个道理)
2. 实践验证 (用方法取得成果)
3. 持续强化 (反复使用，形成习惯)

**解锁提示:**
```
【提示：认知突破·第 X 层】
【技能解锁·XX 力】
```

## 🎯 价值观

### 核心理念

| 理念 | 说明 |
|------|------|
| **学习不是苦** | 是探索，是认知跃迁 |
| **游戏不是敌人** | 是工具，是方法来源 |
| **努力只是入场券** | 成功=努力 + 方法 + 选择 + 运气 |
| **普通人也能逆袭** | 只要找到正确的方法 |

### 反对的价值观

| 陈旧观念 | 新观念 |
|----------|--------|
| 学习=苦差事 | 学习=探索 |
| 游戏=敌人 | 游戏=工具 |
| 努力=成功 | 努力只是入场券 |
| 天赋决定论 | 方法更重要 |
