## 📍 地理背景

### 江南市 (虚构城市)

**原型:** 苏州 + 杭州融合  
**定位:** 二线城市，经济发达，文化底蕴深厚

#### 城市概况

| 属性 | 描述 |
|------|------|
| **位置** | 长江三角洲南翼，太湖流域 |
| **人口** | 约 800 万 (故事开始时) |
| **气候** | 亚热带季风气候，四季分明 |
| **特色** | 园林、水乡、丝绸、茶文化 |
| **经济** | 制造业 + 互联网 + 旅游业 |
| **教育** | 2 所 985 高校，多所重点中学 |

#### 城区划分

| 区域 | 特点 | 代表地点 |
|------|------|----------|
| **老城区** | 巷弄交错，市井气息 | 林家住所、苏秉文家 |
| **高新区** | 科技园，现代化 | 林砚工作企业 |
| **大学城** | 高校聚集区 | 林砚母校 |
| **工业园区** | 制造业基地 | 林父工作工厂 |
| **新城区** | CBD，商业中心 | 卷四 - 六职场场景 |

#### 关键地标

| 地标 | 类型 | 关联场景 |
|------|------|----------|
| **平江路** | 历史老街 | 林砚童年玩耍 |
| **金鸡湖** | 现代湖区 | 卷八自由期散步 |
| **拙政园** | 古典园林 | 卷七接待行业泰斗 |
| **太湖大桥** | 现代建筑 | 卷二高考后兜风 |
| **工业园区地标塔** | 摩天大楼 | 卷六林砚公司所在地 |
| **江南大学** | 高校 | 卷三就读 |
| **市一中** | 重点高中 | 卷二就读 |
| **老城区巷弄** | 居民区 | 林家住所 |

**位置:** 老城区巷弄深处  
**类型:** 老式居民楼，60 平米  
**布局:**
```
┌─────────────────┐
│   阳台 (晾晒)    │
├───────┬─────────┤
│ 卧室  │  卧室   │
│(父母) │ (林砚)  │
├───────┼─────────┤
│  客厅 + 餐厅      │
│   (餐桌 + 电视)   │
├───────┴─────────┤
│    厨房 + 卫生间   │
└─────────────────┘
```

**环境描写:**
- 巷口：张奶奶乘凉处、赵叔叔修车铺

- 屋内：简朴整洁，墙上贴满林砚奖状

**象征意义:** 市井生活的缩影，林砚修行起点

### 时代特征

#### 卷一 (2020-2023)·少年期

**科技:**
- 智能手机普及率 90%+
- 短视频 (抖音/快手) 盛行
- 手游 (王者荣耀/原神) 流行
- 网课兴起 (疫情后)

**社会:**
- 教育内卷初现
- 双减政策实施 (2021)
- 读书无用论偶有出现
- 市井生活气息浓厚

**林砚生活:**
- 沉迷手游、短视频
- 成绩中下，贪玩
- 巷弄里与玩伴嬉戏

---

#### 卷二 (2023-2026)·高中期

**科技:**
- AI 辅助学习工具兴起
- 在线教育成熟
- 智能手表/手环普及

**社会:**
- 高考竞争白热化
- 新高考改革 (3+1+2)
- 心理健康受重视

**林砚生活:**
- 戒游戏，专注学习
- 加入学习小组
- 接触编程、工科实践

---

#### 卷三 (2026-2030)·大学期

**科技:**
- AI 大模型爆发 (2027)
- 自动化技术成熟
- 工业互联网兴起

**社会:**
- 就业压力增大
- 考研热持续
- 创新创业热潮

**林砚生活:**
- 专业学习深耕
- 科研项目、竞赛
- 实习、职场预备

---

#### 卷四 - 六 (2030-2038)·职场期

**科技:**
- AI 与制造业深度融合
- 工业 4.0 普及
- 数字化转型加速

**社会:**
- 职场 35 岁危机
- 中年焦虑普遍
- 财富分化加剧

**林砚生活:**
- 职场晋升 (技术→管理→操盘)
- 买房、成家 (可选)
- 行业资源整合

---

#### 卷七 - 九 (2038-2045+)·传承期

**科技:**
- AI 通用智能突破
- 人机协作常态
- 生物科技兴起

**社会:**
- 延迟退休实施
- 终身学习成为必需
- 公益传承受重视

**林砚生活:**
- 实现三重自由
- 投身教育公益
- 著书立说，传承后世

## 🧭 修行体系详解

### 九境修行

| 境界 | 年龄 | 核心任务 | 破障关键 | 达成标志 |
|------|------|----------|----------|----------|
| **启蒙学徒** | 12-15 | 破蒙昧、立习惯 | 专注守心 | 成绩中游，初立向学之心 |
| **筑基熟手** | 16-18 | 固学识、练章法 | 坚持破瓶颈 | 高考成功，考入重点大学 |
| **专精行家** | 19-22 | 精一技、通原理 | 深耕原理 | 学士学位，专业技能精通 |
| **架构能手** | 23-25 | 拓视野、建体系 | 谋全局 | 技术架构师，统筹项目 |
| **驭人管理者** | 26-28 | 学驭人、通协作 | 放权赋能 | 部门经理，团队 KPI 达标 |
| **资源操盘者** | 29-31 | 通资源、善运筹 | 整合破壁垒 | 业务总监，行业资源网络 |
| **战略制定者** | 32-34 | 观大势、立规则 | 远见破短视 | 企业高管，行业标准制定 |
| **自由修行者** | 35-37 | 弃功利、守本真 | 热爱续征程 | 三重自由实现 |
| **传承宗师** | 38+ | 传智慧、育新人 | 厚德载苍生 | 精神永续，泽被后世 |

---

### 心魔体系

#### 十重心魔

| 心魔 | 出现境界 | 表现 | 破障方法 | 破障金句 |
|------|----------|------|----------|----------|
| **怠惰** | 启蒙 | 拖延、沉迷玩乐 | 定时专注、每日复盘 | "今日事，今日毕" |
| **浮躁** | 启蒙 - 筑基 | 浅尝辄止、急于求成 | 深耕原理、反复推演 | "学贵有恒，不求速成" |
| **焦虑** | 筑基 | 压力过大、自我怀疑 | 劳逸结合、专注过程 | "但问耕耘，莫问收获" |
| **畏难** | 专精 | 面对难点退缩 | 拆分问题、逐个击破 | "难者不会，会者不难" |
| **自满** | 专精 - 架构 | 小成后骄傲 | 对标顶尖、持续学习 | "山外有山，人外有人" |
| **细节执念** | 架构 | 陷入细节忽略全局 | 谋全局、不拘小节 | "全局既定，细节自明" |
| **事必躬亲** | 管理 | 不信任下属、代劳 | 放权赋能、培养团队 | "成人之美，管理者之功" |
| **功利心** | 操盘 - 战略 | 追求短期利益 | 坚守初心、长期主义 | "名利如浮云，初心是归处" |
| **短视** | 战略 | 忽视长远布局 | 观大势、谋长远 | "不谋万世者，不足谋一时" |
| **空虚** | 自由 | 自由后无所适从 | 逐热爱、续征程 | "自由非无所事事，而是有所不为" |

---

### 破障仪式

每破一重心魔，林砚会:
1. **记录修行手记** - 反思心魔根源与破障过程
2. **立新的修行目标** - 明确下一阶段方向
3. **感谢引路人** - 向帮助破障的师长/朋友致谢

**示例:**
- 第 55 章破怠惰：封存游戏机，立向学之心
- 第 78 章破浮躁：制定三年学习计划
- 第 165 章破焦虑：与陈舟夜谈，释然
- 第 650 章破功利心：拒绝资本方短期利益要求

## 🏫 社会环境

### 教育体系

#### 小学 (6 年)
- **入学年龄:** 6 岁
- **特点:** 快乐教育，作业适中
- **林砚状态:** 贪玩，成绩中下

#### 初中 (3 年)
- **入学年龄:** 12 岁
- **特点:** 中考压力初现，内卷开始
- **林砚状态:** 觉醒，从贪玩转向向学

#### 高中 (3 年)
- **入学年龄:** 15 岁
- **特点:** 高考压力，全情投入
- **林砚状态:** 专注学习，成绩稳步提升

#### 大学 (4 年)
- **入学年龄:** 18 岁
- **特点:** 专业深耕，实践与理论结合
- **林砚状态:** 专业技能精通，项目经验积累

#### 研究生 (可选)
- **学制:** 硕士 3 年/博士 4-5 年
- **林砚选择:** 直接工作 (实践经验更重要)

### 职场生态

#### 企业类型

| 类型 | 特点 | 林砚经历 |
|------|------|----------|
| **国企** | 稳定，福利好，晋升慢 | 未选择 |
| **民企** | 灵活，压力大，成长快 | 林砚选择 |
| **外企** | 规范，work-life balance | 曾考虑 |
| **创业公司** | 高风险高回报 | 卷六参与合伙 |

#### 职场晋升路径

```
初级技术员 → 资深专员 → 技术架构师 → 
团队负责人 → 部门经理 → 业务总监 → 
企业高管 → 行业顾问 → 传承宗师
```

#### 职场潜规则
- **35 岁危机:** 技术岗需转型管理或专家
- **人脉资源:** 越往上越重要
- **持续学习:** 不进步就是退步
- **平衡艺术:** 工作/生活/家庭

---

### 行业生态 (机械自动化)

#### 产业链

```
上游 (核心零部件) → 中游 (系统集成) → 下游 (应用端)
    ↓                    ↓                 ↓
伺服电机、传感器    自动化产线设计    汽车/3C/物流等行业
```

#### 技术趋势

| 时期 | 主流技术 | 林砚角色 |
|------|----------|----------|
| 2030 | 传统自动化 | 技术执行者 |
| 2033 | 工业互联网 | 架构设计者 |
| 2036 | AI+ 自动化 | 资源整合者 |
| 2040 | 通用智能协作 | 战略制定者 |
| 2043+ | 人机共生 | 传承者 |

#### 竞争格局
- **国际巨头:** 发那科、ABB、西门子 (垄断高端)
- **国内领军:** 汇川、埃斯顿 (中端突破)
- **初创企业:** 细分领域创新 (林砚卷六投资)

## 💰 经济体系

### 林砚收入变化

| 时期 | 年收入 | 来源 | 状态 |
