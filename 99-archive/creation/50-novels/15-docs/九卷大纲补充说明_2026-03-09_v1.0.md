## 📊 情感爆发点详细设计

### 情感爆发点 1：第 100 章 父子和解

**场景:** 林砚整理旧物，准备搬去高中住校

**内容:**
```
林砚翻开箱子，里面整整齐齐码着自己从小学到高中的所有成绩单。
每张背后都有一行小字："儿子真棒"、"进步了"、"继续努力"。
最后一张是月考中游的成绩单，背后写着"爸为你骄傲"。

林砚拿着成绩单，喉咙发紧。
父亲在门口站着，背对着他，"那些废纸，留着占地方。"
"爸，这都留着干嘛。"林砚听见自己说。
"扔了可惜。"父亲转身，眼眶有点红，"你学习，爸帮不上忙。"

林砚想说"谢谢"，想说"对不起"，想说"我知道"。
但张了张嘴，只说："那我带走了。"
父亲"嗯"了一声，"去吧，别迟到了。"

林砚抱着箱子出门，听见身后门轻轻关上的声音。
箱子里，成绩单最上面，多了一张纸条：
"生活费在信封里，别省着，吃好点。"
```

**情感效果:** 中国式父子关系，爱在心口难开

### 情感爆发点 2：第 350 章 表白成功

**场景:** 项目成功后，庆功宴结束

**内容:**
```
陈舟喝了一点酒，脸有点红。
"昔我往矣写完了。"她说。
林砚看着她，"后面是杨柳依依。"
"今我来思呢？"陈舟问。

林砚拿过毕业册，笔悬了很久。
"写什么？"陈舟声音很轻。
"今我来思......"林砚写，"有你在旁。"

陈舟看着那四个字，笑了。
"这就够了。"她说。
林砚也笑，"嗯，够了。"

月光很好，照在两个人身上。
不需要更多话了。
```

**情感效果:** 含蓄表白，水到渠成

---

### 情感爆发点 3：第 500 章 团队背叛

**场景:** 核心成员离职，带走关键客户

**内容:**
```
"为什么？"林砚问。
对方低着头，"林总，你很好，真的很好。"
"但你眼里只有工作。"

林砚沉默。
"我老婆生孩子那天，你在开会。"
"我爸去世，你在出差。"
"你说工作可以等，但有些事等不了。"

"所以你要走？"
"不是要走，是想活。"对方抬头，"林总，你也该活一活了。"

门关上。
林砚坐在办公室里，看着墙上的"说人话"三个字。
手机响了，是陈舟。
"今晚回来吃饭吗？"
"不了，加班。"
"......好。"

林砚挂了电话，看着窗外。
天黑了，灯亮了，城市很大，人很小。
```

**情感效果:** 工作狂的代价，引发读者反思

---

### 情感爆发点 4：第 700 章 陈舟重病

**场景:** 陈舟晕倒，医院病房

**内容:**
```
医生说需要静养，至少三个月。
林砚放下所有工作，在医院陪了三个月。

"工作怎么办？"陈舟问。
"工作可以等。"林砚削苹果，"你不行。"

陈舟看着他，眼泪突然掉下来。
"你终于说了。"
"说什么？"
"这句话。"陈舟擦眼泪，"我等了好多年。"

林砚手停了。
"对不起。"他说。
"不用说对不起。"陈舟握住他的手，"你在，就够了。"

窗外阳光很好。
林砚想，原来放下工作，天不会塌。
```

**情感效果:** 工作狂的转变，珍惜眼前人

---

### 情感爆发点 5：第 900 章 墓前对话

**场景:** 林砚墓前，陈舟一个人

**内容:**
```
陈舟整理完林砚的遗物，发现草稿箱里有 37 条未发出的消息。
最后一条是："我舍不得。"

"你骗我。"陈舟在墓前放了一杯茶。
"说好的总有好事。"
"好事来了，你不在了。"

风把纸钱吹散。
没人回答。

陈舟坐了很久。
"茶杯我留着了。"
"自行车我留着了。"
"你......我也留着了。"

起身时，陈舟回头。
"下辈子，早点说。"

墓碑上的照片在笑。
还是当年的样子。
```

**情感效果:** 生死相隔，遗憾永恒
