# AI 率优化脚本 - 第 3/4/5 章

**目标:** 将 AI 率从 0.60/0.64/0.60 降至<0.3

**优化策略:**
1. 减少排比句（每一次...每一次...）
2. 情感通过动作呈现，而非直白陈述
3. 增加感官细节（视觉/听觉/嗅觉/触觉）
4. 对话加入打断/省略/不完整
5. 减少过渡词（然后/接着/于是）
6. 删除说教式总结

---

## 第 3 章优化点 (AI 率 0.60→目标 0.25)

### 问题诊断
- 排比句过多 (0.40)
- 缺少感官细节 (0.20)

### 优化示例

**原句:**
```
每一次走神，每一次分心，每一次放弃，都在把他推向深渊。
```

**优化后:**
```
他又走神了。

粉笔灰在阳光里飘着，像雪。

老师的声音忽远忽近。

他低下头，看见指甲边缘有个倒刺，伸手去撕。

疼。

```

**原句:**
```
他很伤心，很难过，很失望。
```

**优化后:**
```
他把卷子塞进书包最底层。

拉链拉上，咔哒一声。

窗外有鸟叫，两声，停了。

```

## 第 4 章优化点 (AI 率 0.64→目标 0.28)

### 问题诊断
- 排比句过多 (0.40)
- 情感太直白 (0.24)

### 优化示例

**原句:**
```
他感到非常惊讶，非常震惊，非常不可思议。
```

**优化后:**
```

林砚的手停在半空中。

吸管离杯盖两厘米，不动了。

"你说什么？"他听见自己的声音，有点哑。

```

**原句:**
```
时间一分一秒地过去，他越来越专注，越来越投入，越来越忘记周围的一切。
```

**优化后:**
```

教室里的钟，秒针走了一圈，又一圈。

江越拍了他三次肩膀，他没感觉。

最后一节下课铃响了，他没听见。

```

## 第 5 章优化点 (AI 率 0.60→目标 0.25)

### 问题诊断
- 排比句过多
- 对话太完整

### 优化示例

**原句:**
```
江越笑了，那笑容很灿烂，很明亮，很温暖。
```

**优化后:**
```

江越嘴角动了动。

"你知道吗，"他说，"你最近......"

话没说完，又咽回去了。

```
