## 📋 全面问题分类体系 (24 类)

### 一、研究设计问题 (5 类)

#### 1.1 科学问题缺陷
- [ ] 问题无科学意义 (无文献支持)
- [ ] 问题不可证伪 (无法否定)
- [ ] 问题过于宽泛 (不具体)
- [ ] 问题已有定论 (无创新)
- [ ] 问题超出能力范围 (不可行)

**检测方式:** 文献检索 +PICO 框架分析

---

#### 1.2 样本量设计问题
- [ ] 未做先验功效分析
- [ ] 效应量估计无依据
- [ ] 样本量不足 (Power<0.95)
- [ ] 未考虑脱落率
- [ ] 样本量过大 (浪费资源)

**检测方式:** G*Power 计算 + 文献对比

---

#### 1.3 抽样偏倚问题
- [ ] 抽样方法不当 (非随机)
- [ ] 样本代表性不足
- [ ] 纳入/排除标准不明确
- [ ] 选择偏倚未控制
- [ ] 幸存者偏倚

**检测方式:** 抽样方案审查 + 样本分布分析

---

#### 1.4 对照组设计问题
- [ ] 无对照组
- [ ] 对照组不匹配
- [ ] 未随机分组
- [ ] 未盲法设计
- [ ] 安慰剂效应未控制

**检测方式:** 实验设计审查 + 混杂因素分析

---

#### 1.5 变量定义问题
- [ ] 自变量定义不清
- [ ] 因变量测量不准
- [ ] 混杂变量未识别
- [ ] 中介变量未考虑
- [ ] 调节变量未分析

**检测方式:** 变量清单审查 + 因果图分析

---

### 二、数据质量问题 (5 类)

#### 2.1 缺失值问题
- [ ] 缺失值>2%
- [ ] 缺失机制未检验 (MCAR/MAR/MNAR)
- [ ] 缺失值处理方法不当
- [ ] 未报告缺失值比例
- [ ] 未做敏感性分析

**检测方式:** 缺失值分析报告 + 多重插补对比

---

#### 2.2 异常值问题
- [ ] 异常值未识别
- [ ] 异常值删除无依据
- [ ] 未人工核查异常值
- [ ] 未报告异常值比例
- [ ] 未做敏感性分析 (删除 vs 保留)

**检测方式:** IQR+Z-score+Isolation Forest 三重检测

---

#### 2.3 数据分布问题
- [ ] 未检验正态性
- [ ] 未检验同方差性
- [ ] 未检验独立性
- [ ] 存在多重共线性
- [ ] 存在自相关

**检测方式:** Shapiro-Wilk+Breusch-Pagan+Durbin-Watson+VIF

---

#### 2.4 数据一致性问题
- [ ] 单位不统一
- [ ] 量纲不一致
- [ ] 数据范围异常
- [ ] 逻辑矛盾 (如年龄<0)
- [ ] 重复记录

**检测方式:** 数据一致性检查脚本

---

#### 2.5 数据采集偏倚
- [ ] 测量工具未校准
- [ ] 测量者间差异未控制
- [ ] 时间效应未控制
- [ ] 环境因素未控制
- [ ] 批次效应未控制

**检测方式:** 采集流程审查 + 批次效应检验

---

### 三、特征工程问题 (4 类)

#### 3.1 特征选择问题
- [ ] 特征无文献支持
- [ ] 特征间高度相关 (VIF>3)
- [ ] 特征与目标无关 (SHAP p>0.001)
- [ ] 特征数过多 (过拟合风险)
- [ ] 重要特征遗漏

**检测方式:** VIF+SHAP+ 文献对比

---

#### 3.2 特征构造问题
- [ ] 衍生特征与原始特征共线
- [ ] 对数转换不当
- [ ] 标准化/归一化错误
- [ ] 特征泄露 (用到测试集信息)
- [ ] 时间序列特征未来信息泄露

**检测方式:** 相关性矩阵 + 数据流审查

---

#### 3.3 特征稳定性问题

- [ ] 特征重要性波动大
- [ ] 未 bootstrap 验证
- [ ] 不同数据集特征不一致
- [ ] 特征时间稳定性差

**检测方式:** Bootstrap 1000 次特征选择稳定性

---

#### 3.4 特征解释问题
- [ ] 特征物理意义不清
- [ ] 与文献机制矛盾
- [ ] 因果推断过度
- [ ] 未考虑交互作用
- [ ] 未考虑非线性关系

**检测方式:** SHAP 依赖性分析 + 文献对比

## 🔧 问题检测工具 (自动化 80%)

### 自动化检测脚本

```python
# 问题检测清单 (部分示例)

def detect_all_issues(data, model, results):
    """全面问题检测"""
    
    issues = {
        'critical': [],  # 致命问题 (必须修复)
        'major': [],     # 严重问题 (强烈建议修复)
        'minor': []      # 一般问题 (建议改进)
    }
    
    # 1. VIF 检测
    vif_max = calculate_max_vif(data)
    if vif_max > 5:
        issues['critical'].append(f"VIF max={vif_max:.2f} > 5 (严重多重共线性)")
    elif vif_max > 3:
        issues['major'].append(f"VIF max={vif_max:.2f} > 3 (建议优化)")
    
    # 2. 缺失值检测
    missing_pct = calculate_missing_percentage(data)
    if missing_pct > 5:
        issues['critical'].append(f"缺失值={missing_pct:.1f}% > 5%")
    elif missing_pct > 2:
        issues['major'].append(f"缺失值={missing_pct:.1f}% > 2%")
    
    # 3. Bootstrap 稳定性检测
    bootstrap_r2 = run_bootstrap(model, data, n=10000)
    if bootstrap_r2['mean'] < 0:
        issues['critical'].append(f"Bootstrap R²={bootstrap_r2['mean']:.4f} < 0 (模型不稳定)")
    
    # 4. 功效分析检测
    power = calculate_power(results)
    if power < 0.95:
        issues['major'].append(f"Statistical Power={power:.4f} < 0.95")
    
    # 5. SHAP 显著性检测
    shap_p_values = calculate_shap_p_values(model, data)
    if any(p > 0.001 for p in shap_p_values):
        issues['major'].append("存在特征 SHAP p > 0.001 (特征不显著)")
    
    # ... (更多检测项)
    
    return issues
```

### 问题严重程度分级

| 级别 | 定义 | 处理方式 | 示例 |
|------|------|----------|------|
| **致命** | 研究无效 | 必须修复，否则拒绝 | VIF>5, Bootstrap R²<0 |
| **严重** | 结论可信度低 | 强烈建议修复 | Power<0.95, 无外部验证 |
| **一般** | 可改进 | 建议改进 | 文献对比不足 |

```markdown
## 问题检测报告

### 致命问题 (必须修复)
1. ❌ VIF max=5.2 > 5 (严重多重共线性)
   - 位置：特征工程
   - 影响：模型系数不稳定，解释不可靠
   - 建议：移除 log_diameter (与 diameter_nm 相关 r=0.92)
   - 预期：VIF 可降至<3

2. ❌ Bootstrap R²=-0.03 < 0 (模型不稳定)
   - 位置：模型验证
   - 影响：模型在小样本上表现差
   - 建议：增加样本量至≥300 或简化模型
   - 预期：Bootstrap R²可提升至>0.3

### 严重问题 (强烈建议修复)
1. ⚠️ Power=0.75 < 0.95 (样本量不足)
   - 位置：研究设计
   - 影响：假阴性风险高
   - 建议：增加样本量至 250+
   
2. ⚠️ 无外部验证集
   - 位置：模型验证
   - 影响：泛化能力未知
   - 建议：收集 50+ 独立样本

### 一般问题 (建议改进)
1. 💡 文献对比不足 (仅 5 篇)
   - 建议：增加至≥20 篇核心文献

2. 💡 未讨论局限性
   - 建议：添加局限性讨论部分

### 总结
- 致命问题：2 个 (必须修复)
- 严重问题：2 个 (强烈建议修复)
- 一般问题：2 个 (建议改进)
- **总体评分：55/100 (不及格)**
- **状态：退回重修**
```
