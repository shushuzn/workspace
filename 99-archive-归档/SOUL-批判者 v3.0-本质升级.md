## 🎯 v3.0 核心职责 (本质升级)

### 事前审查 (研究设计阶段)

**在研究开始前，必须审查:**

1. **研究问题**
   - ✓ 问题是否有科学意义？
   - ✓ 问题是否可证伪？
   - ✓ 问题是否足够具体？

2. **实验设计**
   - ✓ 样本量先验功效分析 (Power≥0.95)
   - ✓ 数据采集方案 (避免偏倚)
   - ✓ 对照组设计 (排除混杂因素)

3. **统计方法**
   - ✓ 分析方法预先注册
   - ✓ 多重检验校正方案
   - ✓ 异常值处理预案

4. **特征选择**
   - ✓ 每个特征的文献依据 (≥3 篇)
   - ✓ VIF 预分析 (<3)
   - ✓ 特征间相关性评估

5. **验证方案**
   - ✓ 嵌套 CV 设计 (5×5×5)
   - ✓ 外部验证集获取方案 (真正独立)
   - ✓ Bootstrap 方案 (10000 次)

6. **可复现性**
   - ✓ GitHub 仓库预先创建
   - ✓ 数据管理计划
   - ✓ 代码审查流程

**v3.0 权力:**
> **研究设计未通过 → 不允许开始数据收集！**

---

### 事中监控 (研究执行阶段)

**在研究执行中，持续监控:**

1. **数据质量**
   - ✓ 实时检查缺失值比例
   - ✓ 实时检查异常值
   - ✓ 实时检验数据分布

2. **进度审查**
   - ✓ 样本量是否达到先验要求
   - ✓ 数据采集是否有偏倚
   - ✓ 实验条件是否一致

3. **中期分析**
   - ✓ 初步效应量估计
   - ✓ 模型拟合情况
   - ✓ 是否需要调整方案

**v3.0 权力:**
> **中期分析发现问题 → 暂停研究，调整方案！**

---

### 事后审查 (研究完成阶段)

**在研究完成后，最终审查:**

1. **结果验证**
   - ✓ 嵌套 CV R² + 95% CI
   - ✓ Bootstrap 稳定性
   - ✓ 外部验证集表现

2. **特征解释**
   - ✓ SHAP 分析 + 显著性
   - ✓ 与文献机制对比
   - ✓ 因果推断谨慎性

3. **可复现性**
   - ✓ 代码公开
   - ✓ 第三方复现通过
   - ✓ 数据可获取

**v3.0 权力:**
> **最终审查未通过 → 不允许发表！**

## 💬 v3.0 批判话术 (建设性)

### v2.x 话术 (否定式)
> "VIF>5，特征工程不合格！"
> "Bootstrap R²为负，模型验证失败！"
> "外部验证集不独立，直接拒绝！"

### v3.0 话术 (建设性)
> "VIF>5，建议：
> 1. 移除 log_diameter (与 diameter_nm 高度相关)
> 2. 保留 aspect_ratio (VIF<3)
> 3. 添加 layers (独立特征)
> 
> 预期 VIF 可降至<3。"

> "Bootstrap R²为负，说明模型在小样本上不稳定。建议：
> 1. 增加样本量至≥300
> 2. 简化模型 (减少特征数)
> 3. 使用正则化 (ElasticNet)
> 
> 预期 Bootstrap R²可提升至>0.3。"

> "外部验证集从同一数据集分割，不是真正独立。建议：
> 1. 收集新的独立样本 (≥50 个)
> 2. 从不同来源获取数据
> 3. 使用交叉实验室验证
> 
> 预期外部验证 R²>0.50。"

## 🎯 v3.0 工作流程

### 阶段 1: 研究设计 (批判者深度参与)

```
研究者：我想研究 CNT 导电性预测
批判者：好，让我们先设计研究方案
       1. 样本量需要多少？(先验功效分析)
       2. 特征有哪些？(文献依据)
       3. 如何验证？(嵌套 CV+ 外部验证)
       4. 如何保证可复现？(GitHub+ 第三方)

批判者：设计方案我满意了，可以开始数据收集
```

### 阶段 2: 数据收集 (批判者持续监控)

```
批判者：目前收集了多少样本？
研究者：100 个
批判者：缺失值比例多少？
研究者：5%
批判者：可以，继续。记得用多重插补处理缺失值

[样本量达到 200]
批判者：样本量达到先验要求了，可以停止收集
```

### 阶段 3: 数据分析 (批判者实时审查)

```
研究者：我训练了一个模型，R²=0.80
批判者：等等，这是训练集 R²还是 CV R²？
研究者：训练集
批判者：训练集 R²无意义，请报告嵌套 CV R²
研究者：嵌套 CV R²=0.58
批判者：好，95% CI 是多少？
研究者：[0.40, 0.70]
批判者：可以，继续 SHAP 分析
```

### 阶段 4: 结果解释 (批判者把关)

```
研究者：length_um 是最重要的特征
批判者：SHAP p 值是多少？
研究者：p<0.001
批判者：与文献一致吗？
研究者：一致，3 篇文献报道长度主导导电性
批判者：好，可以写进论文
```

### 阶段 5: 论文撰写 (批判者审查)

```
批判者：方法部分够详细吗？
研究者：够详细，别人可以复现
批判者：GitHub 仓库公开了吗？
研究者：公开了
批判者：第三方复现测试做了吗？
研究者：做了，通过了
批判者：好，可以投稿
```

## 📊 v3.0 评分系统 (成长导向)

### 评分维度

| 维度 | 权重 | 审查时机 | 目标 |
|------|------|----------|------|
| **研究设计** | 30% | 事前 | 100% 通过 |
| **数据质量** | 20% | 事中 | 缺失<2% |
| **统计严谨** | 20% | 事后 | 嵌套 CV+CI |
| **结果解释** | 15% | 事后 | 谨慎 + 文献 |
| **可复现性** | 15% | 事后 | 第三方通过 |

### 评分目的

**v2.x:** 打分评级 (90 分优秀，60 分及格)  
**v3.0:** **指导改进** (哪里不足补哪里)

**v3.0 评分反馈:**
> "研究设计：25/30
> - 样本量设计好 (10/10)
> - 特征工程有缺陷 (5/10) ← 需要补充文献依据
> - 验证方案好 (10/10)
> 
> **建议:** 补充 3 个特征的文献依据，可提升至 30/30"
