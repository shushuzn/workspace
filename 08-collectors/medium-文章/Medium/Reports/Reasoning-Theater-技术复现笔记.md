**论文:** Reasoning Theater: Disentangling Model Beliefs from Chain-of-Thought  
**arXiv:** 2603.05488v1  
**阅读日期:** 2026-03-07  
**目的:** 复现信念探针早退机制

---

## 🎯 核心发现

### 表演性思维链 (Performative CoT)
- **现象:** 模型已确定答案，但继续生成 tokens
- **表现:** 最终答案可从激活中更早解码
- **问题:** CoT 不反映真实推理过程

### 关键洞察
1. **信念可提前解码:** 从激活中解码答案早于 CoT monitor
2. **任务差异:** 
   - MMLU (简单 recall): 早很多
   - GPQA-Diamond (困难多跳): 差距较小
3. **拐点真实:** 回溯、"aha"时刻与信念转变相关

---

## 🔧 技术方法

### 1. 激活探针 (Activation Probing)

**原理:**
```
隐藏状态 h_l → 探针 (线性分类器) → 预测答案
```

**实现:**
- **输入:** Transformer 中间层隐藏状态
- **探针:** 线性分类器 (可训练)
- **输出:** 答案类别概率分布
- **训练:** 用已知答案样本训练探针

**关键参数:**
- 探针位置：每层 Transformer 后
- 探针类型：线性分类器
- 训练数据：带标签的 QA 对

### 2. 早期强制回答 (Early Forced Answering)

**原理:**
```
在 token t 强制模型输出答案 → 比较与最终答案一致性
```

**实现:**
- 在 CoT 过程中强制提前回答
- 计算与最终答案的置信度差异
- 确定"信念稳定点"

### 3. CoT 监控器 (CoT Monitor)

**原理:**
```
CoT tokens → 分类器 → "模型是否已确定答案?"
```

**实现:**
- 输入：已生成的 CoT tokens
- 输出：二元分类 (已确定/未确定)
- 训练：用探针结果作为弱监督信号

## 📊 实验结果

### Token 节省率

| 数据集 | 节省率 | 准确率变化 |
|--------|--------|------------|
| MMLU | 80% | 无显著下降 |
| GPQA-Diamond | 30% | 无显著下降 |

### 信念解码时机

| 模型 | MMLU 平均提前 | GPQA 平均提前 |
|------|--------------|--------------|
| DeepSeek-R1 671B | ~60% tokens | ~25% tokens |
| GPT-OSS 120B | ~55% tokens | ~20% tokens |

### 拐点分析

| 行为 | 信念转变相关度 |
|------|----------------|
| 回溯 (backtracking) | 高 (85%+) |
| "aha"时刻 | 高 (80%+) |
| 重复检查 | 中 (60%) |
| 正常推理 | 低 (30%) |

## 🔑 可复现要点

### 必需组件
1. **模型访问:** 需要获取中间层激活 (需要开源模型)
2. **探针训练:** 需要带标签的 QA 数据集
3. **早退逻辑:** 基于探针置信度阈值

### 推荐配置
- **模型:** Llama-7B/13B (开源，易获取激活)
- **数据集:** MMLU subset (500-1000 题)
- **探针:** 线性分类器，每层一个
- **阈值:** 置信度 > 0.9 持续 3 层 → 早退

### 评估指标
- Token 节省率 = (1 - 早退 tokens / 完整 tokens) × 100%
- 准确率 = 早退答案正确率 vs 完整推理正确率
- 最佳阈值 = 节省率最高且准确率下降 < 1%
