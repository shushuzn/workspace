# Meeting Notes Assistant - 会议纪要助手

将混乱的会议记录转换为结构化的 Markdown 格式。

## 功能

- 自动识别标题、日期、参会人
- 整理讨论要点为有序列表
- 保留待办事项格式
- 支持下次会议时间记录
- 输出为整洁的 Markdown

## 使用方法

```bash
python meeting_notes.py
```

### 输入格式

```
# 项目周会
日期: 2024-01-15
参会人: 张三, 李四, 王五
讨论了A功能开发进度
讨论了B问题解决方案
- [ ] 张三：完成功能A
- [ ] 李四：修复BUG
下次会议: 2024-01-22
```

### 输出示例

```markdown
# 项目周会

## 基本信息

- **日期**: 2024-01-15
- **参会人**: 张三, 李四, 王五
- **下次会议**: 2024-01-22

## 讨论要点

1. 讨论了A功能开发进度
2. 讨论了B问题解决方案

## 待办事项

- [ ] 张三：完成功能A
- [ ] 李四：修复BUG

---
*本纪要由 Meeting Notes Assistant 自动生成*
```

## 依赖

- Python 3.6+

无需第三方库，纯标准库实现。
