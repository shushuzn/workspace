# Out-of-Domain Stress Test for Temporal Braid Group Privilege Escalation Detection

## 论文信息
- **作者**：Christophe Parisel
- **分类**：astro-ph.SR / cs.CR

## 摘要
本研究探讨了 cloud IAM Graph 中 privilege escalation 的检测方法，特别是针对出-of-domain Stress Test。我们应用了 Burau-Lyapunov exponents 来评估 privileged behavior 的典型性和可重复性，其中 LE 是一个关键指标。通过在 solar coronal magnetic fields 上使用相同的Pipeline，并且 zero-parameter retuning，我们展示了该方法能够检测出 domain-boundary privileged behavior。
