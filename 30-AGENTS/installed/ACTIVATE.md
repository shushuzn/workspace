# Agent 激活指南

## 🎯 按场景激活

### 场景 1: 代码审查
```
1. 读取 01-lens-pr-reviewer.md 的 SOUL.md
2. 提供 PR 链接或代码差异
3. 获取审查报告
```

### 场景 2: 会议准备
```
1. 读取 09-meeting-notes.md
2. 提供会议议程 + 参与者
3. 获取参会指南 + 历史要点
```

### 场景 3: 人脉管理
```
1. 读取 13-personal-crm.md
2. 添加/查询联系人
3. 获取跟进提醒
```

### 场景 4: 内容生产
```
1. 读取 15-echo-content.md
2. 提供原始内容或主题
3. 获取多平台适配版本
```
