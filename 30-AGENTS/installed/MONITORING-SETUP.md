## 日志位置

```
logs/
├── access.log         # 访问和操作记录
├── error.log          # 错误和异常
├── command.log        # 命令执行记录
├── security.log       # 安全相关事件
├── cron.log          # 定时任务执行
└── agent.log         # Agent 活动
```

---

## 日志格式

```yaml
log_format: "[{timestamp}] [{level}] [{source}] {message}"

example: "[2026-03-27 10:00:00] [INFO] [agent] Session started"
```

## 健康检查

### 自动检查项

| 检查项 | 频率 | 失败动作 |
|--------|------|----------|
| Agent 可达性 | 每5分钟 | 重连 |
| 磁盘空间 | 每小时 | 告警 |
| 日志文件大小 | 每小时 | 归档 |
| Token 使用 | 每天 | 报告 |

### 健康状态端点

```bash
# 检查 Agent 状态
copaw agents list

# 检查 Cron 任务
copaw cron list --agent-id nWyDpW

# 检查 Token 使用
get_token_usage --days 7
```

## 告警规则

| 级别 | 触发条件 | 通知方式 |
|------|----------|----------|
| 🔴 紧急 | 安全漏洞/服务不可用 | 即时推送 |
| 🟠 高 | 错误率>5%/响应慢 | 24小时内 |
| 🟡 中 | 异常趋势 | 汇总报告 |
| 🟢 低 | 优化建议 | 周报 |
