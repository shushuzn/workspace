# 📝 提示词模板库

**创建日期:** 2026-03-27

---

## 开发类模板

### PR 审查

```
请审查这个 PR: {pr_url}

关注点:
1. 代码质量和最佳实践
2. 安全漏洞
3. 测试覆盖率
4. 文档完整性
5. 性能影响

输出格式:
- 发现的问题 (按严重程度)
- 建议的修改
- 整体评估 (可合并/需要修改/不可合并)
```

### Bug 分析

```
分析这个 Bug:
- 文件: {file_path}
- 错误: {error_message}
- 上下文: {context}

请:
1. 定位根因
2. 复现步骤
3. 修复建议
4. 预防措施
```

### 代码生成

```
任务: {description}

技术栈:
- 语言: {language}
- 框架: {framework}
- 约束: {constraints}

要求:
1. 完整可运行的代码
2. 包含必要的注释
3. 遵循项目代码风格
```

## 内容类模板

### 文章撰写

```
撰写一篇关于 "{topic}" 的文章

要求:
- 目标读者: {audience}
- 长度: {length}
- 风格: {tone}
- 必须包含: {required_elements}
- 避免: {avoid}

SEO 要求:
- 关键词: {keywords}
- 目标字数: {word_count}
```

### 新闻摘要

```
收集并整理以下主题的最新资讯:
主题: {topic}
来源: {sources}
数量: {count}

输出格式:
1. [标题](链接) - 一句话摘要
2. 关键要点
3. 值得关注的原因
```

## 分析类模板

### 竞品分析

```
分析竞品: {competitor}

维度:
1. 产品功能
2. 定价策略
3. 用户体验
4. 技术架构
5. 市场份额

输出: 对比表格 + 优势/劣势分析 + 建议
```

### 风险评估

```
评估项目 "{project}" 的风险:

维度:
- 技术风险
- 业务风险
- 资源风险
- 时间风险
- 合规风险

输出: 风险矩阵 + 缓解策略
```

## 自定义模板格式

```yaml
templates:
  - name: "模板名称"
    trigger: ["触发词1", "触发词2"]
    prompt: |
      模板内容...
    variables:
      - name: "变量名"
        required: true
        default: "默认值"
```
