## 📋 常用命令

### 信息查询
| 命令 | 执行 |
|------|------|
| `时间` | 当前时间 |
| `token` | 查看 Token 使用统计 |
| `cron 列表` | 查看定时任务 |

### 文件操作
| 命令 | 执行 |
|------|------|
| `搜索 <关键词>` | 全局搜索文件内容 |
| `查看 <路径>` | 读取文件 |
| `写 <路径>` | 创建/编辑文件 |
| `列出 <目录>` | 列出目录内容 |

### Agent 操作
| 命令 | 执行 |
|------|------|
| `Agent 列表` | 查看可用 Agent |
| `PR 审查 <url>` | 执行 PR 审查 |
| `漏洞扫描` | 执行安全扫描 |
| `资讯` | 获取新闻 |
| `早报` | 执行每日早报 |

### 浏览器
| 命令 | 执行 |
|------|------|
| `打开 <url>` | 在浏览器打开页面 |
| `截图 <url>` | 网页截图 |
| `抓取 <url>` | 提取页面内容 |

```
"审查这个 PR: https://github.com/..."
"扫描项目漏洞"
"生成测试代码"
"检查依赖更新"
```

## 🔧 自定义命令

在 `agent.json` 中可添加自定义命令别名：

```json
{
  "shortcuts": {
    "pr": "执行 PR 审查",
    "scan": "执行漏洞扫描",
    "news": "获取行业资讯",
    "report": "生成工作报告"
  }
}
```

## 📝 命令格式建议

1. **模糊匹配** — 说清意图即可，不必严格按格式
   - ✅ "帮我看看这个 PR"
   - ✅ "扫一下漏洞"
   - ✅ "今天有啥新闻"

2. **上下文继承** — 在一个话题内可简化
   - ✅ "再审查另一个 PR"
   - ✅ "还有别的漏洞吗"

3. **多步任务** — 可一次说清
   - ✅ "帮我审查这个 PR，顺便扫一下依赖漏洞"
   - ✅ "写篇文章，然后发到微博和公众号"
