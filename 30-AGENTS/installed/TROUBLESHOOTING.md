# 🔧 故障排除指南

**创建日期:** 2026-03-27

---

## 常见问题

### 1. 浏览器操作失败

**问题:** `Page not found` 或元素找不到

**排查:**
```bash
# 1. 确认 URL 正确
# 2. 检查页面是否加载完成
# 3. 确认选择器有效
```

**解决:**
```
1. 使用 wait_for 等待加载
2. 重新 snapshot 获取元素
3. 调整选择器
```

---

### 2. 文件操作异常

**问题:** 无法读取/写入文件

**排查:**
```bash
# 1. 检查路径是否正确
# 2. 检查文件是否存在
# 3. 检查权限
```

**常见错误:**
| 错误 | 原因 | 解决 |
|------|------|------|
| File not found | 路径错误 | 检查路径 |
| Permission denied | 无权限 | 检查文件权限 |
| Path too long | Windows 路径限制 | 缩短路径 |

---

### 3. 命令执行失败

**问题:** `Command failed` 或超时

**排查:**
```bash
# 1. 检查命令是否正确
# 2. 检查参数是否有效
# 3. 检查工作目录
# 4. 检查超时设置
```

**解决:**
- 增加 timeout 参数
- 使用绝对路径
- 简化命令

---

### 4. Token 耗尽

**问题:** API 返回 Token 耗尽错误

**排查:**
```bash
get_token_usage --days 7
```

**解决:**
1. 等待刷新
2. 优化使用方式
3. 清理不必要的上下文

---

### 5. 内存不足

**问题:** 读取大文件失败

**排查:**
```bash
# 检查文件大小
dir file_path

# 检查内存使用
free -m
```

**解决:**
1. 分段读取大文件
2. 清理缓存
3. 使用 glob_search 代替 read_file

---

### 6. 搜索无结果

**问题:** grep_search 返回空

**排查:**
```bash
# 1. 确认关键词正确
# 2. 尝试模糊搜索
# 3. 检查路径
```

**解决:**
```
1. 使用正则表达式
2. 扩大搜索范围
3. 使用不同的关键词
```

---

### 7. Cron 任务不执行

**问题:** 定时任务没有运行

**排查:**
```bash
# 1. 检查任务状态
copaw cron list

# 2. 检查日志
tail logs/cron.log
```

**解决:**
1. 确认任务已启用
2. 检查时间配置
3. 重新创建任务

---

### 8. 多 Agent 通信失败

**问题:** 无法调用其他 Agent

**排查:**
```bash
# 1. 检查 Agent 状态
copaw agents list

# 2. 检查 session
```

**解决:**
1. 确认 Agent ID 正确
2. 传递正确的 session
3. 检查权限

---

### 9. 浏览器启动失败

**问题:** 无法启动浏览器

**排查:**
```bash
# 1. 检查 Playwright 安装
# 2. 检查端口占用
# 3. 检查权限
```

**解决:**
```bash
# 安装浏览器
browser_use(action="install")

# 使用有头模式
browser_use(action="start", headed=True)
```

---

### 10. API 调用失败

**问题:** 外部 API 返回错误

**排查:**
- 检查 API Key
- 检查网络连接
- 查看错误信息

**常见错误:**
| 错误码 | 含义 | 解决 |
|--------|------|------|
| 401 | 认证失败 | 检查 API Key |
| 403 | 权限不足 | 检查权限 |
| 429 | 限流 | 等待后重试 |
| 500 | 服务器错误 | 重试 |
