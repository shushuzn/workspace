## 安全最佳实践

1. **API Keys 不写入代码** — 使用环境变量
2. **定期轮换密钥** — 每 90 天更新
3. **日志脱敏** — 敏感信息自动掩码
4. **最小权限** — Agent 只读写必要文件
5. **审计日志** — 记录所有敏感操作
