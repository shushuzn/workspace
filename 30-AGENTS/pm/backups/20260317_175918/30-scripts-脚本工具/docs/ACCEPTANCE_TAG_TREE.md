## 验收标准

| 编号 | 功能 | 验收方法 | 预期结果 | 状态 |
|------|------|----------|----------|------|

| F2 | 父标签展开/收起 | 点击父标签 | 子标签正确显示/隐藏 | ⏳ |
| F3 | 子标签查看图片 | 点击子标签 | 显示相关图片列表 | ⏳ |
| F4 | 搜索功能 | 输入关键词搜索 | 正确过滤结果 | ⏳ |
| F5 | 统计信息 | 查看页面顶部 | 图片数/标签数正确 | ⏳ |

```powershell
# 3. 性能测试
# - F12 开发者工具查看加载时间

```
