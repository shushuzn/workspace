### OPP-001: Cu²⁺选择性积累机制解析

**来源:** 肿瘤贴片论文 (PMID: 41784393)

**科学问题:**
- 为何 Cu²⁺选择性积累于黑色素瘤细胞？
- 可能的机制：受体介导？pH 依赖？转运蛋白过表达？

**研究空白:**
- 论文未阐明 Cu²⁺肿瘤选择性的分子机制
- 影响：限制临床转化和剂量优化

**AI 可贡献:**
- 文献挖掘：提取已知的铜转运蛋白 (CTR1, ATP7A/B)
- 假设生成：基于肿瘤微环境特征 (酸性 pH、高 ROS)
- 数据分析：整合 TCGA 黑色素瘤组学数据

**验证方法:**
- 基因敲除/敲低 (CTR1, ATP7A/B)
- 抑制剂实验
- ICP-MS 定量 Cu²⁺分布

**预计工作量:** 3-6 个月  
**影响力:** 高 (机制突破)

### OPP-002: 三重细胞死亡通路相对贡献量化

**来源:** 肿瘤贴片论文 (PMID: 41784393)

**科学问题:**
- 凋亡/铜死亡/铁死亡的相对贡献比例是多少？
- 是否存在主导通路？

**研究空白:**
- 论文仅证明三种通路同时激活，未量化各自贡献
- 影响：无法优化治疗策略

**AI 可贡献:**
- 通路富集分析：RNA-seq 数据解析
- 网络建模：构建细胞死亡通路交互网络
- 预测模型：基于基因表达预测通路敏感性

**验证方法:**
- 特异性抑制剂 (Z-VAD 凋亡，ELAM-1 铜死亡，Ferrostatin-1 铁死亡)
- 基因敲除细胞系
- 单细胞测序

**预计工作量:** 2-4 个月  
**影响力:** 高 (优化治疗)

### 机会匹配算法

```python
def match_opportunity(paper_analysis, ai_capabilities):
    """匹配论文空白与 AI 能力"""
    gaps = paper_analysis["limitations"]
    matches = []
    
    for gap in gaps:
        for capability in ai_capabilities:
            if capability.can_address(gap):
                matches.append({
                    "gap": gap,
                    "capability": capability,
                    "confidence": capability.confidence(gap)
                })
    
    return sorted(matches, key=lambda x: x["confidence"], reverse=True)
```
