**最优核函数:**
```

```

**特征长度尺度:**
| 特征 | length_scale | 重要性 |
|------|--------------|--------|
| P_W | 1.2 | 高 |
| v_mms | 0.8 | 高 |
| E_Jcm2 | 1.5 | 中 |

- v_mms 长度尺度最小 → 对性能影响最大
- co_ratio 长度尺度最大 → 影响相对较小

## 🚀 使用示例

```python
import joblib
import numpy as np

# 加载模型
gp = joblib.load('research/models/gp_sigma.joblib')
scaler = joblib.load('research/models/gp_scaler.joblib')

# 预测
X = np.array([[0.30, 30, 10.0, 3.3]])
X_scaled = scaler.transform(X)
pred, std = gp.predict(X_scaled, return_std=True)

print(f"预测：{pred[0]:.0f} +/- {std[0]:.0f} S/m")
# 输出：2500 +/- 200 S/m

# 95% 置信区间
ci_95 = [pred[0] - 2*std[0], pred[0] + 2*std[0]]
print(f"95% CI: [{ci_95[0]:.0f}, {ci_95[1]:.0f}] S/m")
```
