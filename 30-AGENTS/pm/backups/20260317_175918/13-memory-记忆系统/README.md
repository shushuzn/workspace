## 🧠 记忆类型

### 长期记忆 (MEMORY.md)
- **位置:** [[MEMORY]]
- **内容:** 提炼的核心观点、重要决策、经验教训
- **更新:** 定期从日常笔记蒸馏
- **特点:** 高置信度、可交叉引用

### 日常笔记 (YYYY-MM-DD.md)
- **位置:** [[2026-03-06]], [[2026-03-05]], ...
- **内容:** 当日工作记录、对话日志、临时想法
- **更新:** 每日自动创建
- **特点:** 原始记录、详细完整

## 📊 记忆管理

### 蒸馏流程
```
日常笔记 (13-memory/YYYY-MM-DD.md)
    ↓
memory-distiller 技能 (每周日 5 AM)
    ↓
提炼核心观点
    ↓
更新长期记忆 (MEMORY.md)
```

### 记忆维护
- **定期审查:** 每心跳检查 (2-4 小时)
- **去重:** 移除重复观点
- **置信度评估:** 标记高/中/低置信度
- **交叉引用:** 建立记忆间链接

## 📝 使用指南

### 读取记忆
```markdown

根据 [[MEMORY]] 中的记录，我们之前决定...

```

### 写入记忆
```markdown
# 日常笔记格式
## 🎯 重大成就
- 完成 X 项目

## 💡 关键洞察
- 发现 Z 规律

- [ ] 明日任务 A
- [ ] 明日任务 B
```

### 蒸馏到长期记忆
```markdown

**来源:** 2026-03-06 内容更新  
**置信度:** 0.90 | **日期:** 2026-03-06

**核心观点:**
- 观点 1
- 观点 2

**相关记忆:**
- [[TOPIC-YYY]] - 相关主题
```

## 🎯 最佳实践

### 写什么
- ✅ 重要决策和原因
- ✅ 项目进展和里程碑
- ✅ 技术洞见和教训
- ✅ 用户偏好和要求
- ✅ 系统配置变更

### 不写什么
- ❌ 临时性信息 (用日常笔记)
- ❌ 敏感数据 (密码、密钥)
- ❌ 过长对话记录 (提炼要点)
- ❌ 未验证的猜测

### 记忆组织
- 使用数字前缀分类 (SYS-001, PROJ-002)
- 添加置信度评分 (0.0-1.0)
- 建立交叉引用网络
- 定期审查和更新
