# 任务风险等级定义

**版本:** v1.0  
**创建时间:** 2026-03-12 09:15  
**目的:** 明确什么任务算"高风险"，需要方案确认

---

## 🔴 高风险任务 (必须方案确认)

### 定义
**高风险任务:** 可能导致数据丢失、系统故障、不可逆后果的任务

### 判断标准 (满足任一即为高风险)

| 标准 | 说明 | 示例 |
|------|------|------|
| **数据删除** | 删除文件或数据 | `rm -rf`, 批量删除 |
| **系统修改** | 修改核心配置 | 修改 `.gitignore`, 系统配置 |
| **外部操作** | 发送邮件/消息/推文 | 对外沟通，公开内容 |
| **不可逆操作** | 无法撤销的修改 | 覆盖文件，强制推送 |
| **权限变更** | 修改访问权限 | 共享设置，权限调整 |
| **生产部署** | 部署到生产环境 | 上线，发布 |
| **财务相关** | 涉及金钱/支付 | 购买，转账 |
| **隐私数据** | 处理敏感信息 | 密码，密钥，个人信息 |

---

## 🟡 中风险任务 (建议复述确认)

### 定义
**中风险任务:** 可能引起误解，需要确认理解正确的任务

### 判断标准

| 标准 | 说明 | 示例 |
|------|------|------|
| **多步骤** | ≥5 个子任务 | 重构系统，整理大量文件 |
| **模糊需求** | 需求不明确 | "优化一下"，"改进性能" |
| **跨系统** | 涉及多个系统 | Git+Feishu+ 本地文件 |
| **长时间** | >30 分钟 | 复杂分析，大量数据处理 |
| **依赖外部** | 依赖 API/网络 | 调用外部服务 |

---

## 🟢 低风险任务 (直接执行)

### 定义
**低风险任务:** 安全、可逆、明确的任务

### 判断标准

| 标准 | 说明 | 示例 |
|------|------|------|
| **查询类** | 只读操作 | 天气查询，文件列表 |
| **创建类** | 新建文件 | 创建空白文件，新建文档 |
| **小修改** | 局部修改 | 修改单个文件，添加内容 |
| **整理类** | 组织文件 | 移动文件，重命名 |
| **分析类** | 数据分析 | 日志分析，统计报告 |

## 📊 风险决策树

```
用户指令
    ↓
是否删除数据/文件？
├── 是 → 🔴 高风险 (方案确认)
└── 否 → 继续判断
    ↓
是否修改核心配置？
├── 是 → 🔴 高风险 (方案确认)
└── 否 → 继续判断
    ↓
是否外部操作 (邮件/消息)?
├── 是 → 🔴 高风险 (方案确认)
└── 否 → 继续判断
    ↓
是否不可逆操作？
├── 是 → 🔴 高风险 (方案确认)
└── 否 → 继续判断
    ↓
是否≥5 个子任务？
├── 是 → 🟡 中风险 (复述确认)
└── 否 → 🟢 低风险 (直接执行)
```

## 📝 确认流程

### 🔴 高风险任务流程

```
1. AI 识别为高风险
   ↓
2. 输出方案文档
   - 任务目标
   - 执行步骤
   - 风险评估
   - 回滚方案
   ↓
3. 用户确认
   ↓
4. 执行 (每 30% 进度汇报)
   ↓
5. 验证结果
```

### 🟡 中风险任务流程

```
1. AI 识别为中风险
   ↓
2. 复述任务 + 验收标准
   ↓
3. 用户确认 (默认同意)
   ↓
4. 执行 (关键节点汇报)
   ↓
5. 验证结果
```

### 🟢 低风险任务流程

```
1. AI 识别为低风险
   ↓
2. 直接执行
   ↓
3. 输出结果 + 验证
```

## 🔍 示例

### 示例 1: 高风险

**用户:** "删除所有测试文件"

**AI 响应:**
```
🔴 高风险任务识别

**风险:** 数据删除 (不可逆)

**方案:**
1. 识别测试文件 (模式：*.test.*, test_*)
2. 移动到回收站 (非永久删除)
3. 生成删除清单

**回滚方案:** 从回收站恢复

**确认:** 是否继续？[是/否]
```

---

### 示例 2: 中风险

**用户:** "优化工作流"

**AI 响应:**
```
🟡 中风险任务识别

**任务理解:**
- 目标：优化工作流效率
- 范围：用户命令执行流程
- 验收：效率提升≥10%，满意度≥4/5

**计划:**
1. 收集基线数据
2. 设计测试方案
3. 执行测试
4. 生成报告

**确认:** 理解是否正确？[是/修正]
```
