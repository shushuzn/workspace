**位置:** 老城区巷弄深处  
**类型:** 老式居民楼，60 平米  
**布局:**
```
┌─────────────────┐
│   阳台 (晾晒)    │
├───────┬─────────┤
│ 卧室  │  卧室   │

├───────┼─────────┤
│  客厅 + 餐厅      │
│   (餐桌 + 电视)   │
├───────┴─────────┤
│    厨房 + 卫生间   │
└─────────────────┘
```

**环境描写:**
- 巷口：张奶奶乘凉处、赵叔叔修车铺

- 屋内：简朴整洁，墙上贴满林砚奖状

**象征意义:** 市井生活的缩影，林砚修行起点

## 🧭 修行体系

### 九境修行

| 境界 | 年龄 | 核心任务 | 破障关键 | 达成标志 |
|------|------|----------|----------|----------|
| **启蒙学徒** | 12-15 | 破蒙昧、立习惯 | 专注守心 | 成绩中游，初立向学之心 |
| **筑基熟手** | 16-18 | 固学识、练章法 | 坚持破瓶颈 | 升学成功，考入重点大学 |
| **专精行家** | 19-22 | 精一技、通原理 | 深耕原理 | 学士学位，专业技能精通 |
| **架构能手** | 23-25 | 拓视野、建体系 | 谋全局 | 技术架构师，统筹项目 |
| **驭人管理者** | 26-28 | 学驭人、通协作 | 放权赋能 | 部门经理，团队 KPI 达标 |
| **资源操盘者** | 29-31 | 通资源、善运筹 | 整合破壁垒 | 业务总监，行业资源网络 |
| **战略制定者** | 32-34 | 观大势、立规则 | 远见破短视 | 企业高管，行业标准制定 |
| **自由修行者** | 35-37 | 弃功利、守本真 | 热爱续征程 | 三重自由实现 |
| **传承宗师** | 38+ | 传智慧、育新人 | 厚德载苍生 | 精神永续，泽被后世 |

### 心魔体系

#### 十重心魔

| 心魔 | 出现境界 | 表现 | 破障方法 | 破障金句 |
|------|----------|------|----------|----------|
| **怠惰** | 启蒙 | 拖延、沉迷玩乐 | 定时专注、每日复盘 | "今日事，今日毕" |
| **浮躁** | 启蒙 - 筑基 | 浅尝辄止、急于求成 | 深耕原理、反复推演 | "学贵有恒，不求速成" |
| **焦虑** | 筑基 | 压力过大、自我怀疑 | 劳逸结合、专注过程 | "但问耕耘，莫问收获" |
| **畏难** | 专精 | 面对难点退缩 | 拆分问题、逐个击破 | "难者不会，会者不难" |
| **自满** | 专精 - 架构 | 小成后骄傲 | 对标顶尖、持续学习 | "山外有山，人外有人" |
| **细节执念** | 架构 | 陷入细节忽略全局 | 谋全局、不拘小节 | "全局既定，细节自明" |
| **事必躬亲** | 管理 | 不信任下属、代劳 | 放权赋能、培养团队 | "成人之美，管理者之功" |
| **功利心** | 操盘 - 战略 | 追求短期利益 | 坚守初心、长期主义 | "名利如浮云，初心是归处" |
| **短视** | 战略 | 忽视长远布局 | 观大势、谋长远 | "不谋万世者，不足谋一时" |
| **空虚** | 自由 | 自由后无所适从 | 逐热爱、续征程 | "自由非无所事事，而是有所不为" |

## 🏫 社会环境

### 教育体系

#### 塾中/小学 (6 年)
- **入学年龄:** 6 岁
- **特点:** 快乐教育，作业适中
- **林砚状态:** 贪玩，成绩中下

#### 中学 (6 年)
- **入学年龄:** 12 岁
- **特点:** 升学压力，内卷
- **林砚状态:** 觉醒，从贪玩转向向学

#### 大学 (4 年)
- **入学年龄:** 18 岁
- **特点:** 专业深耕，实践与理论结合
- **林砚状态:** 专业技能精通，项目经验积累

---

### 职场生态

#### 企业类型

| 类型 | 特点 | 林砚经历 |
|------|------|----------|
| **国企** | 稳定，福利好，晋升慢 | 未选择 |
| **民企** | 灵活，压力大，成长快 | 林砚选择 |
| **外企** | 规范，work-life balance | 曾考虑 |
| **创业公司** | 高风险高回报 | 卷六参与合伙 |

#### 职场晋升路径

```
初级技术员 → 资深专员 → 技术架构师 → 
团队负责人 → 部门经理 → 业务总监 → 
企业高管 → 行业顾问 → 传承宗师
```

---

### 行业生态 (机械自动化)

#### 产业链

```
上游 (核心零部件) → 中游 (系统集成) → 下游 (应用端)
    ↓                    ↓                 ↓
伺服电机、传感器    自动化产线设计    汽车/3C/物流等行业
```

#### 技术趋势

| 时期 | 主流技术 | 林砚角色 |
|------|----------|----------|
| 早期 | 传统自动化 | 技术执行者 |
| 中期 | 工业互联网 | 架构设计者 |
| 后期 | AI+ 自动化 | 资源整合者 |
| 成熟期 | 通用智能协作 | 战略制定者 |
| 传承期 | 人机共生 | 传承者 |

## 💰 经济体系

### 林砚收入变化

| 时期 | 年收入 | 来源 | 状态 |

| 少年期 | 0 | 父母给零花钱 | 依赖 |
