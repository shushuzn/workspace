# 第 4 章深度 AI 优化指南

**当前 AI 率:** 0.64 (HIGH)  
**目标 AI 率:** <0.30  
**主要问题:** 排比句 (0.40) + 情感太直白 (0.24)

---

## 优化策略

### 1. 减少排比句 (0.40→0.15)

**原句:**
```
每一次走神，每一次分心，每一次放弃，都在把他推向深渊。
```

**优化:**
```
他又走神了。

粉笔灰在阳光里飘着。

老师的声音忽远忽近。

他低下头，看见指甲边缘有个倒刺。

伸手去撕。

疼。
```

**技巧:** 把长排比拆成短句，增加动作细节

---

### 2. 情感通过动作呈现 (0.24→0.10)

**原句:**
```
他感到非常惊讶，非常震惊。
```

**优化:**
```
林砚的手停在半空中。

吸管离杯盖两厘米，不动了。

"你说什么？"

声音有点哑。
```

**技巧:** 用身体反应代替情感词

---

### 3. 增加感官细节 (每 300 字 1 处)

**视觉:** 红色数字、蓝色火苗、银色月光  
**听觉:** 拉链声、篮球声、鸟叫声  
**嗅觉:** 牛奶香、油条香  
**触觉:** 温热的杯子、冰冷的栏杆  
**味觉:** 珍珠的甜味、豆浆的淡香

---

### 4. 对话加入打断/省略

**原句:**
```
"你今天怎么样？"江越问。
"我很好，谢谢关心。"林砚回答。
```

**优化:**
```
"你今天......"
"还行。"
江越看着他，没说完的话咽回去了。
```

**技巧:** 真人对话不完整，有停顿

---

### 5. 删除过渡词

**删除:** 然后、接着、于是、就在这时、突然  
**替换:** 直接下一句，或用空行分隔

---

### 6. 删除章节末尾总结

**原结尾:**
```
这就是林砚的第一次心流体验，他从中明白了专注的重要性。
```

**优化:**
```
林砚闭上眼睛。

明天，又是新的一天。
```

**技巧:** 留白，让读者自己体会
