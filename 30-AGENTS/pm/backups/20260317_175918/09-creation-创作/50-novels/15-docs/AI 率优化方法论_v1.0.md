### 2. 有效优化策略

#### 2.1 减少排比句 (效果：⭐⭐⭐)
**方法:** 将长排比拆分为短句

**原句:**
```

```

**优化:**
```

```

**效果:** AI 率 -0.05 到 -0.10

#### 2.3 感官细节 (效果：⭐⭐⭐⭐⭐)
**方法:** 每 300 字增加 1 处感官描写

**感官类型:**
- 视觉：红色数字、蓝色火苗
- 听觉：拉链声、篮球声
- 嗅觉：牛奶香、油条香
- 触觉：温热的杯子、冰冷的栏杆
- 味觉：珍珠的甜味

**效果:** AI 率 -0.10 到 -0.20

---

#### 2.4 对话自然化 (效果：⭐⭐⭐)
**方法:** 加入打断/省略/停顿

**原句:**
```
"你今天怎么样？"江越问。
"我很好，谢谢关心。"林砚回答。
```

**优化:**
```
"你今天......"
"还行。"
江越看着他，没说完的话咽回去了。
```

**效果:** AI 率 -0.05 到 -0.10

---

#### 2.5 删除过渡词 (效果：⭐⭐)
**方法:** 删除"然后""接着""于是"

**原句:**
```
然后他拿起笔，接着开始写字，于是答案出来了。
```

**优化:**
```
他拿起笔。
写字。
答案出来了。
```

**效果:** AI 率 -0.05

---

#### 2.6 开放结尾 (效果：⭐⭐⭐)
**方法:** 删除章节总结，用场景/梦境结尾

**原结尾:**
```

```

**优化:**
```

明天，又是新的一天。
```

**效果:** AI 率 -0.10
