## 📊 设计理念

### 新派三原则 (v3.0 升级版)

1. **隐蔽性** - 伏笔像生活细节，不像设计
2. **多义性** - 一个伏笔多个解读，不单一
3. **情感性** - 绑定情感记忆，非事件对应
4. **文化性** - 引经据典自然融入，不掉书袋 (新增)


## 🎯 使用原则

### 伏笔

1. **不点明** - 让读者自己发现
2. **不急于回收** - 让时间发酵
3. **多义解读** - 不单一寓意
4. **情感绑定** - 非事件对应

### 小巧思

1. **重复出现** - 至少 5 次形成记忆点
2. **演变升级** - 每次出现有不同内涵
3. **呼应主题** - 服务于核心立意
4. **不说教** - 让读者自己体会

### 引用

1. **自然融入** - 人物自然说出
2. **情境契合** - 与当时情境匹配
3. **多义解读** - 不同阶段不同理解
4. **不解释** - 让读者自己体会
