## 📝 命名规范

**文件命名:** `NOVEL_标题_日期_v 版本.md`

**示例:**
- `NOVEL_三体外传_2026-03-09_v1.0.md`
- `CHAR_主角设定_2026-03-09_v1.0.md`
- `WORLD_魔法体系_2026-03-09_v1.0.md`

---

## ✍️ 创作流程

1. **构思** → `world-building/` 记录设定
2. **角色** → `characters/` 创建档案
3. **草稿** → `drafts/` 写作初稿
4. **修订** → 版本迭代 (v1.0 → v2.0)
5. **完成** → 移动到 `published/`
