---

## 📋 项目概述

整合 NewsHub、agentic-bpm 和 patrol-agent，构建一个智能新闻驱动的工作流引擎。
系统能够自动获取新闻、分析重要性、触发相关工作流任务，并推送结果。

---

## 🎯 目标

1. **信息获取自动化**: 定时抓取多源新闻
2. **智能分析**: AI 分析新闻重要性、分类、情感
3. **工作流触发**: 基于新闻内容自动创建并执行任务
4. **闭环反馈**: 执行结果反馈到分析模型，持续优化

cd 80-PROJECTS/news-workflow-engine
pip install -r requirements.txt

# 配置
cp config.example.yaml config.yaml
# 编辑 config.yaml

# 初始化数据库
python -m news_workflow init

# 启动服务
python -m news_workflow run

# 或使用定时任务
