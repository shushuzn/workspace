# 头脑风暴工作流：旧版 vs 新版 对比分析

**分析日期:** 2026-03-20  
**目的:** 识别差异、优势、改进点

---

## 📊 概览对比

| 维度 | 旧版 (v1) | 新版 (v2) | 改进 |
|------|-----------|-----------|------|
| **流程结构** | 线性流程 | 双环迭代 (发散→收敛) | ⭐⭐⭐ |

| **学术诚信** | 硬编码数据 | 真实 arXiv API | ⭐⭐⭐ |
| **注册状态** | 部分注册 | 完整注册 (workflow+ 工具) | ⭐⭐⭐ |

## 📋 流程对比

### 旧版流程 (线性)

```
┌──────────────┐
│ 1. 定义主题   │ brainstorm_define.py
│    - 输入主题 │    (手动输入)
│    - 设定目标 │
└──────┬───────┘
       ↓
┌──────────────┐
│ 2. 发散想法   │ brainstorm_diverge.py
│    - 手动输入 │    (每行一个想法)
│    - ≥10 个   │    ⚠️ 效率低
└──────┬───────┘
       ↓
┌──────────────┐
│ 3. 收敛筛选   │ brainstorm_convergent.py
│    - 简单评分 │
│    - Top 5    │
└──────┬───────┘
       ↓
┌──────────────┐
│ 4. 行动计划   │ brainstorm_action.py
│    - 待办列表 │
└──────┬───────┘
       ↓
┌──────────────┐
│ 5. 批判者审查 │ auto-critic_v7.py
│    - ≥80 分   │    ⚠️ 标准过高
└──────┬───────┘
       ↓
┌──────────────┐
│ 6. Git 提交   │
└──────────────┘

总时间：不确定 (通常 60-120 分钟)
迭代：无
```

**问题:**
- ⚠️ 手动输入想法 (效率低)
- ⚠️ 无时间控制
- ⚠️ 无迭代机制
- ⚠️ 批判者标准过高 (≥80 分)

```
                    ┌─────────────────┐
                    │  头脑风暴会话    │
                    │  brainstorm_    │
                    │  facilitator.py │
                    └────────┬────────┘
                             │
         ┌───────────────────┴───────────────────┐
         │                                       │
         ↓                                       ↓
┌─────────────────┐                     ┌─────────────────┐
│   发散环         │                     │   收敛环         │
│   (30 分钟)      │                     │   (25 分钟)      │
│                 │                     │                 │
│ D1: 灵感触发    │                     │ C1: 初步筛选    │
│   - arXiv API   │                     │   - 快速评分    │
│   - 自动收集    │                     │   - 淘汰<3 分    │
│                 │                     │                 │
│ D2: 联想爆发    │                     │ C2: 轻量验证    │
│   - 链式联想    │                     │   - ≤3 篇文献    │
│   - ≥20 想法    │                     │   - 可行性检查  │
│                 │                     │                 │
│ D3: 强制连接    │                     │ C3: 影响力评估  │
│   - 跨领域组合  │                     │   - 2x2 矩阵     │
│   - 突破常规    │                     │   - 优先级排序  │
│                 │                     │                 │
│ D4: 逆向思考    │                     │ C4: 快速批判    │
│   - 挑战前提    │                     │   - critic-lite │
│   - 发现机会    │                     │   - ≥60 分       │
│                 │                     │                 │
│ D5: 快速记录    │                     │ C5: 行动规划    │
│   - JSON 输出   │                     │   - Top 3 计划   │
│   - 结构化      │                     │   - 工作量估算  │
└────────┬────────┘                     └────────┬────────┘
         │                                       │
         └───────────────────┬───────────────────┘
                             │
                             ↓
                   ┌─────────────────┐
                   │  需要更多灵感？  │
                   └───────┬─────────┘
                           │
                  ┌────────┴────────┐
                  │                 │
                 是               否
                  │                 │
                  ↓                 ↓
            回到发散环          结束会话
            (新一轮)          (生成报告)

总时间：≤90 分钟
```

**优势:**
- ✅ 自动收集想法 (arXiv API)
- ✅ 时间盒控制
- ✅ 迭代机制
- ✅ 轻量批判者 (适合创意)
