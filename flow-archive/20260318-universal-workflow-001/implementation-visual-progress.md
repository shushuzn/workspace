## 🛠️ 技术实现

### 颜色系统
```python
class Colors:
    RESET = "\033[0m"
    BOLD = "\033[1m"
    GREEN = "\033[92m"    # 完成
    YELLOW = "\033[93m"   # 进行中
    RED = "\033[91m"      # 错误/阻塞
    BLUE = "\033[94m"     # 当前步骤
    CYAN = "\033[96m"     # 标题
    GRAY = "\033[90m"     # 等待
```

### 进度条算法
```python
def print_progress_bar(current, total, width=40):
    percentage = current / total
    filled = int(width * percentage)
    bar = "█" * filled + "░" * (width - filled)
    
    # 颜色根据进度变化
    if percentage < 0.3:
        color = Colors.RED
    elif percentage < 0.7:
        color = Colors.YELLOW
    else:
        color = Colors.GREEN
```

### 时间估算算法
```python
def estimate_remaining_time(completed_steps, total_steps, elapsed_time):
    # 平均每步时间
    avg_time_per_step = elapsed_time / len(completed_steps)
    
    # 剩余步骤
    remaining_steps = total_steps - len(completed_steps)
    
    # 估算剩余时间
    remaining_time = avg_time_per_step * remaining_steps
    
    return remaining_time
```
