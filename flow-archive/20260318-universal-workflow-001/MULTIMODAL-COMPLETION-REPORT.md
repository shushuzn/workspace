## 📈 系统统计

**图像处理:**
- 格式：JPG, JPEG, PNG, GIF, BMP, WEBP
- 分析：物体检测、OCR、场景分析、颜色提取
- 元数据：文件大小、修改时间、格式

**音频处理:**
- 格式：MP3, WAV, OGG, M4A, FLAC
- 分析：语音转录、时长、说话人、情感、关键词

**文档处理:**
- 格式：PDF, DOCX, XLSX, PPTX, TXT, MD
- 提取：文字、表格、图片、元数据、目录

**多模态融合:**
- 类型：combined, summary, correlation
- 能力：跨模态关联、统一表示、洞察生成

## 🛠️ 使用示例

### 命令行
```bash
# 分析图像
py multimodal_agent.py --image "photo.jpg"

# OCR 识别
py multimodal_agent.py --ocr "scan.png"

# 处理音频
py multimodal_agent.py --audio "meeting.mp3"

# 解析文档
py multimodal_agent.py --doc "report.docx"

# 解析 PDF
py multimodal_agent.py --pdf "paper.pdf"

# 多模态融合
py multimodal_agent.py --fuse "MM-0001,MM-0002"

# 查看状态
py multimodal_agent.py --status
```

### Python API
```python
from multimodal_agent import process_file, fuse_modalities

# 自动处理
result = process_file("any.file")

# 多模态融合
fusion = fuse_modalities(["MM-0001", "MM-0002"])
```
