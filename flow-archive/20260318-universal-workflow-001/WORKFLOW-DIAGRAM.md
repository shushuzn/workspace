## 🛡️ 5 层防护介入点

```
任务开始
    ↓
[第 1 层] 规则定义防护
    - check_tool_rules.py 扫描
    - 违规 → 阻断
    ↓
[工作流启动]
    ↓
[第 2 层] 工具调用防护 (步骤 1,4,6)
    - tool_executor.py 统一入口
    - 未注册工具 → 阻断
    - 直接调用 → 阻断
    ↓
[第 3 层] 工作流强制防护 (步骤 5)
    - workflow_enforcer.py 检查
    - 跳步 → 阻断
    - 回退 → 阻断
    ↓
[第 4 层] 质量保障防护 (步骤 9,10)
    - auto-critic_v7.py 审查
    - quality_gate_check.py 评分
    - 质量问题 → 阻断
    ↓
[第 5 层] 数据完整性防护 (步骤 7,8,12)
    - checkpoint.json 自动保存
    - execution-log.json 防篡改
    - Git 预提交钩子
    - 数据不完整 → 阻断
    ↓
任务完成
```
