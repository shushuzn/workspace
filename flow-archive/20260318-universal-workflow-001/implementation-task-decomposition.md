## 🛠️ 核心功能

### 1. 复杂任务自动分解

**功能:** 将复杂任务自动分解为可执行的子任务

**使用:**
```bash
# 使用模板分解
py task_decomposer.py --decompose "开发 AI 智能体多模态理解功能" \
  --template development \
  --priority urgent

# 输出:
# ✅ 任务已分解
#    任务 ID: TASK-0001
#    子任务数：5
#    预估时间：19 小时
```

**分解结果:**
```
TASK-0001: 开发 AI 智能体多模态理解功能
├─ TASK-0001-1: 需求分析 (2 小时)
├─ TASK-0001-2: 设计架构 (3 小时) [依赖：1]
├─ TASK-0001-3: 编码实现 (8 小时) [依赖：2]
├─ TASK-0001-4: 测试验证 (4 小时) [依赖：3]
└─ TASK-0001-5: 文档编写 (2 小时) [依赖：3]
```

### 2. 子任务依赖关系图

**功能:** 定义子任务之间的依赖关系

**依赖类型:**
- **串行依赖:** 任务 B 必须等任务 A 完成
- **并行依赖:** 任务 B 和 C 可以同时进行
- **多依赖:** 任务 D 需要 A、B、C 都完成

**示例:**
```json
{
  "id": "TASK-0001-3",
  "name": "编码实现",
  "dependencies": ["TASK-0001-2"],
  "estimated_hours": 8
}
```

**依赖检查:**
```bash
# 自动检查依赖是否满足
# 只有依赖任务完成后，子任务才可执行
```

### 3. 执行优先级排序

**紧急/重要矩阵:**

| | 紧急 | 不紧急 |
|---|---|---|
| **重要** | 🔴 立即执行 | 🟡 计划执行 |
| **不重要** | 🟠 委托/简化 | 🟢 可选 |

**优先级设置:**
```bash
# 紧急重要 (立即执行)
py task_decomposer.py --decompose "修复生产环境 bug" --priority urgent

# 重要不紧急 (计划执行)
py task_decomposer.py --decompose "学习新技术" --priority important

# 紧急不重要 (委托/简化)
py task_decomposer.py --decompose "回复邮件" --priority normal

# 不紧急不重要 (可选)
py task_decomposer.py --decompose "整理文件" --priority low
```

**智能排序:**
- 优先执行 🔴 紧急重要
- 其次执行 🟡 重要不紧急
- 自动推荐下一个可执行任务
