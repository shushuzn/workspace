### D4: 逆向思考 (反向优化)

**如果让工作流更慢:**
- 每步都等待人工确认 ❌ → 自动化确认 ✅
- 所有步骤必须顺序执行 ❌ → 支持并行 ✅
- 无状态保存，失败重头开始 ❌ → 断点续跑 ✅

**如果让工作流更复杂:**
- 硬编码所有参数 ❌ → 配置化 ✅
- 无文档，靠口头传承 ❌ → 自动生成文档 ✅
- 无版本控制，随意修改 ❌ → Git 集成 ✅

**如果让工作流更脆弱:**
- 工具失败直接崩溃 ❌ → 降级策略 ✅
- 无验证，错误数据传递 ❌ → 每步验证 ✅
- 无超时，无限等待 ❌ → 时间盒控制 ✅

```python
def execute_tool(tool_id, fallback_tools=None):
    try:
        return call_tool(tool_id)
    except Exception as e:
        if fallback_tools:
            for fallback in fallback_tools:
                try:
                    return call_tool(fallback)
                except:
                    continue
        return manual_mode()
```

```python
def execute_step(step):
    result = execute(step)
    score = critic_v7(result)
    if score < 80:
        rollback(step)
        raise QualityError(f"质量不达标：{score}分")
    return result
```
