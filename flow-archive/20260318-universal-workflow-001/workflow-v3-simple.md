# 主工作流 v3.0 - 简化版 (10 步核心)

**创建日期:** 2026-03-20  
**目标:** 让工作流简单易记，100% 执行

---

## 📋 10 步核心流程

### Phase 1: 准备 (Steps 1-3)
```
Step 1: 上下文加载 (7 文件，<100KB)
Step 2: Flow ID 绑定 (20260318-universal-workflow-001)
Step 3: 任务解析 (目标 + 验收标准)
```

### Phase 2: 执行 (Steps 4-7)
```
Step 4: 工具选择 (从 tools_registry.json)
Step 5: 工具执行 (通过 tool_executor.py)
Step 6: 集成验证 (测试通过)
Step 7: 批判者审查 (≥95 分)
```

### Phase 3: 收尾 (Steps 8-10)
```
Step 8: 会话压缩 (<5KB)
Step 9: Git 提交 (必须包含压缩笔记)
Step 10: 记忆更新 (MEMORY.md + 当日笔记)
```

## 🛡️ 强制执行规则

### 规则 1: 任务开始必须绑定 Flow ID
```markdown
**Flow ID:** 20260318-universal-workflow-001
```

### 规则 2: 每个任务必须显示 10 步检查清单
- 使用上面的快速启动模板
- 每完成一步打勾 [✓]

### 规则 3: Git 提交前必须检查
- Step 8 会话压缩完成 (<5KB)
- Step 10 记忆更新完成

### 规则 4: 违反规则的后果
- 第一次：警告
- 第二次：暂停任务，重新执行工作流
- 第三次：删除任务成果，重新开始
