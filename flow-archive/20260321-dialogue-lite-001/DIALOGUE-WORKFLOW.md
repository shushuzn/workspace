# 对话轻量工作流 - Dialogue Lite Workflow

**Flow ID:** `20260321-dialogue-lite-001`  
**版本:** 1.0.0  
**创建日期:** 2026-03-21  
**父工作流:** `20260318-universal-workflow-001` (主工作流)

---

## 🎯 设计目的

为**日常对话/讨论/问答**场景提供轻量级工作流，补充主工作流 (20 步) 的不足。

| 场景 | 使用工作流 |
|------|------------|
| 创建工具/代码 | 主工作流 (20 步) |
| 研究任务 | 主工作流 (20 步) |
| **日常对话** | **对话工作流 (5 步)** ✅ |
| **问答/讨论** | **对话工作流 (5 步)** ✅ |
| **学习/理解** | **对话工作流 (5 步)** ✅ |

---

## 📋 5 步流程

```
阶段 1: initialization (初始化)
  Step 1: 上下文加载 [阻塞] ← 加载核心文件 + 会话历史

阶段 2: task_analysis (任务分析)
  Step 2: 问题理解 [阻塞] ← 解析用户问题/意图

阶段 3: execution (执行)
  Step 3: 回答生成 [非阻塞] ← 生成回答内容

阶段 4: validation (验证)
  Step 4: 质量检查 [阻塞] ← 验证回答质量 (≥70 分)

阶段 5: completion (完成)
  Step 5: 记录日志 [非阻塞] ← 记录对话到日志
```

---

## 🔑 关键特性

### 1. 阻塞点

| 步骤 | 阻塞 | 说明 |
|------|------|------|
| Step 1 | ✅ | 必须加载上下文才能理解问题 |
| Step 2 | ✅ | 必须理解问题才能回答 |
| Step 3 | ❌ | 回答生成可流式输出 |
| Step 4 | ✅ | 质量检查必须通过 |
| Step 5 | ❌ | 日志记录后台执行 |

### 2. 质量门禁

```json
"quality_gate": {
  "enabled": true,
  "min_score": 70,
  "action_on_fail": "revise_answer"
}
```

**质量<70 分 → 自动修正回答**

### 3. 超时设置

| 步骤 | 超时 | 动作 |
|------|------|------|
| Step 1 | 10 秒 | 超时→使用缓存 |
| Step 2 | 15 秒 | 超时→简化理解 |
| Step 3 | 30 秒 | 超时→部分回答 |
| Step 4 | 10 秒 | 超时→跳过检查 |
| Step 5 | 5 秒 | 超时→跳过日志 |

### 4. 状态持久化

```json
"state_persistence": {
  "save_state": true,
  "checkpoint_file": "flow-archive/20260321-dialogue-lite-001/dialogue-state.json"
}
```

**每步自动保存，支持断点续传**
