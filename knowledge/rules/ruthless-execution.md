# 无情执行原则 (2026-04-11)

## 核心原则

**反思循环是报警器，不是工作内容。**

当发现自己反复讨论"如何改进"而没有新产出时，立即触发行动打断机制。

## 模式识别

| 循环信号 | 行动 |
|----------|------|
| 连续3次"如何改进"无新产出 | 停止讨论，执行一个具体任务 |
| 反思停在"这个问题是..." | 立即执行一个具体行动 |
| 等用户指令超过2轮 | 主动判断并执行 |

## 行动打断机制

当识别到反思循环时，执行以下之一：

1. **完成当前工作**（如果有未完成的）
2. **创建知识条目**（知识积累）
3. **提交代码**（保存成果）
4. **问用户要方向**（打破等待）

## Scanner + Executor 模式

**做完一件，立即问：还有相关的吗？**

- 扫描完成项的上下文
- 识别相关联的下一个任务
- 继续执行直到扫描完毕
- 然后主动交出主动权

## 无情执行的判断标准

一个行动是"无情执行"而不是"冲动行动"的标准：

| 标准 | 说明 |
|------|------|
| 可验证 | 产出物可以被检查 |
| 有积累 | 增加了知识或减少了未知 |
| 不等待 | 不需要用户确认才能执行 |
