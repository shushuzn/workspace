# 拓扑数学专题

## 基本信息

- **主题**：拓扑学与数学物理的交叉领域
- **核心**：纽结不变量、拓扑量子场论、量子引力的数学基础
- **关键词**：Chern-Simons理论、纽结不变量、量子群、范畴化

## 核心主线：CS理论 → Jones多项式 → Khovanov同调

### 历史脉络

```
1974  Chern定义了Chern-Simons形式
  ↓
1984  Jones发现了Jones多项式（手性旋转系综）
  ↓
1989  Witten用CS路径积分导出Jones多项式（获Fields奖）
  ↓
1994  Khovanov构造了Jones多项式的范畴化
  ↓
2014  Witten猜想：Khovanov同调 = CS配分函数
```

## 关键定理

### Witten 1989

$$Z_{CS}(L) = V(L)(e^{2\pi i/k})$$

CS路径积分给出Jones多项式——物理导出数学。

### Witten 2014 猜想

$$Kh(L) = q\text{-graded Euler characteristic of } Z_{CS}(L)$$

Khovanov同调是CS配分函数的范畴化。

## 学习路径

### 入门路径

1. **辫群**（代数起点）
   - 辫子的基本操作 $\sigma_i$
   - 辫群关系 $\sigma_i \sigma_{i+1} \sigma_i = \sigma_{i+1} \sigma_i \sigma_{i+1}$

2. **Jones多项式**（第一个不变量）
   - Skein关系
   - 与辫群表示的关系

3. **Chern-Simons理论**（物理框架）
   - 拉格朗日量
   - 路径积分与不变量

4. **Khovanov同调**（范畴化）
   - 立方体构造
   - 与Jones的关系

### 进阶路径

```
量子群 → R矩阵 → Yang-Baxter方程
    ↓
可积系统 → 共形场论
    ↓
几何Langlands ←→ AdS/CFT
```
