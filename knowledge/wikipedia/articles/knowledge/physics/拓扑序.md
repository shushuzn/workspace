# 拓扑序

## 基本信息

- **原文**：Topological order
- **提出者**：Xiao-Gang Wen (1989)
- **本质**：超越对称性保护的量子物态新分类
- **意义**：颠覆了朗道对称性破缺理论统治的物态分类框架

---

## 核心概念

### 朗道对称性理论的局限

朗夫理论用**对称性**和**局域序参量**分类物态：
- 铁磁相 / 顺磁相（自发对称破缺）
- 超流相 / 正常相（U(1)对称破缺）

**局限**：无法区分具有相同对称性但不同拓扑性质的态。

### 拓扑序的定义

**拓扑序**是一类新的量子物态，由**拓扑量子场论（TQFT）**完全描述：

| 特征 | 描述 |
|------|------|
| 基态简并 | 基态数由流形拓扑决定，与系统尺寸无关 |
| 边界态 | 有边界时出现无能隙边界态 |
| 编织统计 | 激发态服从任意子（anyon）统计 |
| 拓扑纠缠熵 | $S = \alpha L - \gamma$（$\gamma$是拓扑熵） |

---

## 拓扑序的数学描述

### 拓扑量子场论（TQFT）

拓扑序的低能有效理论是 TQFT：

$$Z = \int \mathcal{D}A \, e^{iS_{CS}[A]}$$

- **Chern-Simons 理论**：最简单的 TQFT，描述整数/分数量子霍尔态
- **非阿贝尔 CS 理论**：描述更复杂的拓扑序

### Reshetikhin-Turaev 构造

从 Hopf 代数（量子群）构造三维 TQFT：

$$Z(M^3) = \langle V, \mathcal{R} \rangle$$

- $M^3$：三维流形
- $V$：着色纽结（colored link）
- $\mathcal{R}$：R-矩阵

## 与拓扑物态的关系

### 拓扑序的分类层级

```
拓扑序
├── 拓扑量子霍尔态（Chern-Simons）
│   ├── 整数量子霍尔态（陈数=整数）
│   └── 分数量子霍尔态（陈数=分数）
├── 拓扑超导体（p+ip 超导体）
└── 拓扑绝缘体（对称保护拓扑态，不属于拓扑序）
```

### 拓扑序 vs 对称保护拓扑态（SPT）

| | 拓扑序 | 对称保护拓扑态（SPT） |
|---|---|---|
| 保护机制 | 无（内在拓扑序） | 对称性（时间反演、粒子-空穴等） |
| 基态简并 | 有（由拓扑决定） | 无 |
| 边界态 | 有 | 有 |
| 例子 | FQHE, 拓扑超导 | 拓扑绝缘体 |

**关键区别**：拓扑序没有对称性保护也能存在；SPT 必须依赖对称性。

## 与量子计算的关系

### 拓扑量子存储

拓扑序的基态简并可以用来存储量子信息：

$$|0\rangle, |1\rangle \rightarrow \text{不同的拓扑基态}$$

- 拓扑保护：环境噪声无法翻转拓扑量子比特
- **拓扑量子内存**：编织操作实现量子门

### 编织门

非阿贝尔拓扑序的编织操作实现量子门：

$$B_i : \text{Braiding anyons} \rightarrow U_i \in U(d)$$

## 与其他学科的联系

### 数学基础

| 数学结构 | 作用 |
|----------|------|
| 纽结不变量 | 描述拓扑序的激发 |
| 量子群 | 构造 TQFT 的代数结构 |
| 范畴论 | 拓扑序的数学框架 |
| 黎曼几何 | 拓扑序的边界态理论 |

### 与量子引力的联系

**AdS/CFT 对偶**：
- 边界：共形场论（CFT）
- 体内：反德西特空间（AdS）上的引力

边界拓扑序 ↔ 体内引力，拓扑序可能是量子引力的关键结构。
