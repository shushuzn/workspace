# 表面码

## 基本信息

- **原文**：Surface code / Topological code
- **类型**：拓扑量子纠错码
- **提出者**：Kitaev (1997), Freedman & Meyer (2001)
- **本质**：用二维晶格上的拓扑自由度编码量子比特

---

## 核心概念

### 量子纠错的基本问题

量子比特受环境噪声影响会退相干。纠错需要：
1. **错误检测**：测量不破坏量子叠加态
2. **错误纠正**：从测量结果恢复正确态

### 表面码构造

二维正方晶格上的表面码：

```
    Z-边界（缺陷）
    ┌───┬───┬───┐
    │ ● │ ● │ ● │  ← Z型 stabilizers
    ├───┼───┼───┤
    │ ● │ ● │ ● │
    ├───┼───┼───┤
    │ ● │ ● │ ● │
    └───┴───┴───┘
    ↑   ↑
    X-边界（缺陷）  数据量子比特（●）
```

### Stabilizer formalism

| 算子 | 类型 | 作用 |
|------|------|------|
| $X_i X_{i+1}$ | X-type stabilizer | 检测位相翻转 |
| $Z_i Z_{i+1}$ | Z-type stabilizer | 检测比特翻转 |

## 拓扑保护机制

### 与拓扑序的关系

表面码等价于 **toric code**（二维拓扑序）：

$$H = -J_e \sum_{\text{vertices}} A_v - J_m \sum_{\text{plaquettes}} B_p$$

| 符号 | 含义 |
|------|------|
| $A_v$ | 顶点算子（$X$算子） |
| $B_p$ |  plaquette算子（$Z$算子） |
| $J_e, J_m$ | 耦合常数 |

### 拓扑量子比特

| 拓扑量子比特 | 物理实现 |
|-------------|---------|
| 逻辑量子比特 | 缺陷对的融合通道 |
| 量子门 | 缺陷编织 |
| 错误纠正 | stabilizers 测量 |

| Amazon | 量子计算云 | 表面码路线 |

### 距离与纠错能力

量子码的距离 $d$ 越大，纠错能力越强：

| 距离 $d$ | 可纠正错误 | 代码率 |
|-----------|-----------|--------|
| $d=3$ | 1个任意错误 | $1/9$ |
| $d=5$ | 2个任意错误 | $1/25$ |
| $d=7$ | 3个任意错误 | $1/49$ |

### 阈值定理

表面码的**阈值**：

$$p_{th} \approx 1\%$$

当物理错误率 $p < p_{th}$ 时，增加码距 $d$ 可以无限降低逻辑错误率。

## 与Anyon的关系

表面码的激发是 **阿贝尔任意子**（与Fibonacci不同）：

| 准粒子 | 统计 | 编织 |
|--------|------|------|
| $e$ (电荷) | 阿贝尔 | $\theta = \pi$ |
| $m$ (磁通) | 阿贝尔 | $\theta = \pi$ |
| $\epsilon = e \times m$ | 非阿贝尔？ | 复合粒子 |

表面码的激发是**阿贝尔**的，所以不能直接用于通用量子计算——但可以用于量子纠错。

## 优势与挑战

### 优势

| 优势 | 说明 |
|------|------|
| 高阈值 | ~1% 物理错误率容忍 |
| 本地操作 | 仅需最近邻相互作用 |
| 鲁棒性 | 拓扑保护对局部错误免疫 |
| 可扩展 | 晶格结构适合大规模集成 |

### 挑战

| 挑战 | 当前瓶颈 |
|------|---------|
| 物理比特开销 | 需要 ~1000 个物理比特 / 逻辑比特 |
| 测量速度 | stabilizer 测量需要高频 |
| 连通性 | 缺陷编织需要长距离移动 |
