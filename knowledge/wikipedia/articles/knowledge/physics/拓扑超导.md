# 拓扑超导

## 基本信息

- **原文**：Topological superconductor
- **本质**：体内超导、表面/边界有拓扑保护的金属态
- **特征**：体内超导配对 + 表面金属态（Majorana零模式）
- **保护机制**：粒子-空穴对称 + 时间反演对称

---

## 分类

### 对称性分类（Altland-Zirnbauer 十类）

| 类别 | 对称性 | 拓扑分类 | 维数 |
|------|--------|----------|------|
| D | 粒子-空穴 | $\mathbb{Z}$ | 1D, 2D |
| DIII | 粒子-空穴 + 时间反演 | $\mathbb{Z}_2$ | 1D, 2D |
| BD-I | — | $\mathbb{Z}_2$ | 1D |

### 一维拓扑超导

**p波超导线**（Kitaev链）：

$$H = -\frac{\mu}{2}\sum_i c_i^\dagger c_i - \frac{t}{2}\sum_i(c_i^\dagger c_{i+1} + h.c.) + \frac{\Delta}{2}\sum_i(c_i^\dagger c_{i+1}^\dagger + h.c.)$$

末端出现 **Majorana 零模式**（马约拉纳零能模）：

$$|\psi\rangle = \gamma |0\rangle + \gamma^\dagger |1\rangle$$

- Majorana 算符：$\gamma = \gamma^\dagger$（自身是反粒子）
- 满足 $\gamma^2 = 1$
- 两个 Majorana 模式组成一个量子比特（非局域编码）

### 二维拓扑超导

**p+ip 超导体**：
- 对称性：p波自旋三态配对
- 边界：Majorana 边缘模式（手征）
- 陈数：$\pm 1$

---

## Majorana 零模式

### 物理性质

| 性质 | 描述 |
|------|------|
| 自共轭 | $\gamma = \gamma^\dagger$（Majorana条件） |
| 零能 | $H|\psi\rangle = 0$ |
| 非局域 | 量子信息编码在两个末端之间 |
| 编织 | 交换两个 Majorana 产生 $\pi$ 相位 |

### 编织统计

Majorana 费米子服从 **非阿贝尔任意子统计**（non-Abelian anyon）：

$$\psi_1 \psi_2 = \psi_2 \psi_1 \quad \text{（普通费米子）}$$
$$\gamma_1 \gamma_2 = -\gamma_2 \gamma_1 \quad \text{（Majorana）}$$

编织操作对应量子门：
$$\sigma_i \rightarrow e^{i\pi/4} \begin{pmatrix} 1 & 0 \\ 0 & i \end{pmatrix}$$

## 与拓扑量子计算的关系

### Majorana 量子比特

| 传统量子比特 | Majorana 量子比特 |
|-------------|------------------|
| 两能级系统 | 两个 Majorana 模式 |
| 退相干 | 拓扑保护 |
| 门操作 | 编织（braiding） |

### 量子门实现

Majorana 编织实现量子门：
- **编织**：交换两个 Majorana 模式
- **融合**：测量判断融合结果（0 或 1）
- **单比特门**：通过braiding实现旋转

### 微软 Majorana 项目

- **Platform**：InAs/Al 纳米线 + 超导 + 磁场
- **目标**：实现拓扑保护的量子比特
- **现状**：2023年声称观测到 Majorana，但争议较大

## 与拓扑序的关系

| | 拓扑超导 | 拓扑序 |
|---|---|---|
| 基态简并 | 有（由流形拓扑决定） | 有 |
| 激发统计 | 非阿贝尔（Majorana） | 任意子 |
| 有效理论 | $p+ip$ 超导 BCS 理论 | Chern-Simons TQFT |
| 对称性 | 粒子-空穴对称 | 无 |

## 物理实现

### 半导体-超导异质结

**理论 Platform**：
- InAs 纳米线（自旋轨道耦合强）
- Al 超导体（s波配对诱导）
- 外加磁场（Zeeman分裂）

**实验观测**：
- 零偏压电导峰（Majorana特征）
- 量子化输运

### 铁基超导体

**Fe(Te,Se)**：
- 拓扑表面态 + 超导配对
- 体内即可观测 Majorana
- 无需外加纳米线结构
