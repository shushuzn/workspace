## 💡 Lessons Learned (Phase 5)

**[P5-001] LLM Integration Speed**
- Faster than expected (1h vs 4-6h)
- Reusable OllamaClient pattern
- Template fallback essential

**[P5-002] Test Coverage**
- 16 tests in 30 min
- Mock external dependencies
- Integration tests critical

**[P5-003] Integration Strategy**
- Minimal changes to existing code
- Try/except for graceful fallback
- Feature detection (LLM availability)

**[P5-004] Live Testing**
- Test in production (self-improving engine)
- Immediate feedback
- Cycle 6: LLM worked perfectly!

**[P5-005] Windows Path Handling**
- Forward slashes work better
- Use `replace('\\', '/')`
- Raw strings prevent escape issues

**[P5-006] UTF-8 Encoding**
- Always specify `encoding='utf-8'`
- Windows console needs `reconfigure()`
- Emoji in docstrings require UTF-8

**[P5-007] Subprocess Isolation**
- Import testing in subprocess
- Cleaner error messages
- Better isolation

**[P5-008] Test-First Development**
- Write tests before implementation
- Catches edge cases early
- 100% pass rate from first run

**[P5-009] Complexity-Based Generation**
- Low: Basic execute
- Medium: + analyze
- High: + optimize + validate
- Scales with requirements

**[P5-010] DNA Encoding Strategy**
- Numeric for continuous traits
- Categorical for discrete choices
- Boolean for on/off
- Mutation rates by type

**[P5-011] Fitness Function Design**
- Weighted sum is effective
- Impact (40%) + Novelty (30%)
- Feasibility (20%)
- Complexity penalty (10%)

**[P5-012] Tournament Selection**
- Size 3 provides good pressure
- Stochastic prevents convergence
- Balances exploration/exploitation

**[P5-013] Elitism Importance**
- Preserves best individuals
- Prevents degradation
- 20% elite count optimal

**[P5-014] Mutation Balance**
- 10% per-gene rate
- Gaussian for fine-tuning
- Maintains diversity

**[P5-015] Crossover Strategy**
- Single-point is simple
- Preserves gene blocks
- 70% rate optimal
