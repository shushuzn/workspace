### 步骤 2: 查找数据 (15 分钟)

**每篇论文只需查找:**

1. **打开 PDF**
2. **按 Ctrl+F 搜索:** "conductivity" 或 "resistance"
3. **找到数字和单位**
4. **抄录下来**

**示例:**
```
Lin 2014:
- 功率：10.6 W
- 速度：50 mm/s
- 电导率：1.2×10^5 S/m

Karimi 2021 Table 1:
- 8W, 40mm/s → 500 Ω
- 8W, 60mm/s → 600 Ω
- 12W, 40mm/s → 300 Ω
...

Murray 2021:
- 9.5W, 45mm/s → 1000 Ω/sq
...
```
